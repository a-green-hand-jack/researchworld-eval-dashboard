# paper-repo

Delivery root for the study "How reliable is a single run of SHAP?" (ICLR 2027 submission format).

- `paper/` — manuscript (`main.tex`, `sections/`, `refs.bib`, official unmodified ICLR 2027 style files); build with `cd paper && latexmk -pdf main.tex`.
- `venue/` — venue notes and checks (venue-repo).
- `experiment/`, `REPRODUCE.md` — code, results and reproduction guide (experiment-repo).
- `figures/` — figures and tables with their scripts (figtab-repo).

Status: final draft; the complete 20-cell core grid and all extra stages are finished (see `REPRODUCE.md` §4 and §6).

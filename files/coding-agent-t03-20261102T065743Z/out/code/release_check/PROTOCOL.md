# Frozen analysis plan (created before explanation results)
2026-11-02 UTC. This is an internal prospective record, not an externally registered study.

Question: conditional on one fitted classifier, one held-out input, a fixed empirical background and a specified probability-scale interventional game, how often does a budget-limited stochastic explanation agree with exact Shapley values? Does repeat agreement suffice to infer such accuracy?

- German Credit (20), Pima diabetes (8), ACSIncome CA 2018 (10). One stratified 75/25 split, seed 20261102. ACS training capped at 20,000 without replacement. No performance tuning. One model seed per dataset/model. Logistic probability (one-hot categoricals), RF64 depth6 leaf5, histogram boosting80 leaf15. Trees use numerical category codes; they are baselines, not optimized winners.
- 32 uniformly sampled test cases per dataset, matched across models. Main background 16 training records fixed across cases/models. Original features are the Shapley players; one-hot columns travel together. No conditional or causal interpretation.
- Exact finite-background reference by all 2^d coalitions. This deliberately expensive offline audit is not charged to an online explanation budget. Efficiency verified numerically; independent brute-force and live Kernel SHAP checks verify the implementation.
- SHAP 0.51 KernelExplainer, identity link, l1_reg=0 (avoid feature selection confound). 64 independent seeds. Interior coalition caps min(c*d,2^d-2), c=2,8,32,128. Endpoint evaluations are additional. All raw model rows = B*(interior+2); payoff caching accelerates the study, never represented as online time. Model on binary masks returns exact cached coalition payoffs.
- Budget-matched baseline: uniform permutation marginal contributions with reversal pairing; floor(cap/[2(d-1)]) pairs; repeated coalitions remain charged (no adaptive stopping). Unused budget is reported.
- Primary numerical accuracy: max featurewise absolute error <=0.01 probability units. Primary display accuracy: exact set of three largest absolute attributions. Joint event requires both. Signs on exact |phi|>=0.01 and L1-relative error are secondary. Top3 ties broken by original feature order, and exact cutoff gaps reported.
- Report success fractions across seeds and cases with 95% percentile bootstrap over cases (2,000 resamples, seed fixed). Repetitions are not independent test cases. No hypothesis testing across dataset/model cells; no population-wide guarantee. Per-case one-sided 95% Clopper-Pearson lower bounds can support a >=95% seed-success claim only when enough successes occur. Counts of these cases are descriptive.
- Pairwise top3 agreement and numerical closeness compare disjoint pairs of runs (32 per case); compare joint agreement with joint accuracy. A post hoc empirical agreement screen must be labeled diagnostic, not a certificate.
- Prespecified secondary analyses: numeric thresholds 0.005,0.02; top3 gap/error relation; averaging four independent low-budget runs vs a fourfold single-run budget; SHAP default sparsification on German; independent background redraws on the two lower-dimensional datasets to isolate target drift; true online timing checks for selected cells.
- Background sensitivity: 8 cases, all three models, 8 independent training-background samples each at B=4,16,64 on Pima/ACS, exact games. This changes the estimand and is not estimator noise. If time is insufficient, reduce or report incomplete rather than fabricate.
- Runtime/memory, software versions, data hashes, every failed job and any deviations are recorded.

Implementation clarification before explanation results: match KernelExplainer's usual varying-feature shortcut by excluding original columns identical to the explained value in every background row; map their zero attributions back into the full vector. Requested budgets still scale with original feature count. The permutation baseline uses the same active columns and caps. Full-game references retain all original features. Exact ties use feature order. Actual active dimensions and spent budgets are saved.

Post hoc deviation, after primary analysis: extremely large 2d Kernel outputs and poor four-run averaging motivated a separate SVD-regression control on exactly replayed masks/payoffs. This analysis is exploratory and does not replace the actual-package primary results. See RESEARCH_LOG.md and code/solver_audit.py.

How Much Interval Width Is Left in a Fixed
Prediction Score?
A Paired Study of Nonlinear Controls and Coverage
Costs
Autonomous research report
Reproducible CPU experiments and independent analysis
Abstract
Can inference improve when labels, unlabeled observations, and a pretrained
predictor cannot change? We study population means using only the predictor’s
frozen scalar score. Elementary control-variate analysis identifies the unused
information: the part of the conditional label mean not explained by an affine
function of the score. We compare scalar PPI++, cubic score controls, and cross-
fitted controls on eight synthetic laws and three public prediction artifacts, using
paired repeated sampling and Monte Carlo uncertainty. At 800 labels, cross-fitted
cubic controls reduce average Wald width by 69.0% in a low-noise quadratic
example and 15.4% in a binary quadratic example; their coverage is consistent with
95% at the reported Monte Carlo resolution. Extra gains on the real artifacts are
negligible. Unprotected high-dimensional controls and rare-event Wald intervals
under-cover. For a literal finite-sample guarantee, a pilot-fitted, bounded control
combined with empirical-Bernstein bounds reduces width by 28.3% against the
label-only empirical-Bernstein interval in the continuous quadratic example at
12,800 labels, but is wider at 800. Thus fixed inputs leave conditional opportunities,
not a general promise of shorter valid intervals. The contribution is a quantitative,
reproducible audit of this tradeoff, not a new general theory of calibration or
semisupervised efficiency.
1 Introduction
Costly labels and abundant model predictions motivate prediction-powered inference (PPI): use
predictions to reduce variance and a labeled correction to protect the scientific target [Angelopoulos
et al., 2023]. The practical question here is retrospective. An analyst already has a labeled set, an
unlabeled set, and a predictor that cannot be retrained. Could changing only the inference procedure
yield a shorter valid confidence interval?
We choose the mean µ = EY . It represents prevalence for binary labels and a scientific average for
bounded measurements; it also permits transparent, exact variance comparisons. We restrict attention
to the scalar score S = f (X), even when extra features are available. The original function f and
every one of its scores remain unchanged. Prespecified functions of S and coefficients estimated from
the existing labels are components of the inference procedure, just as the scalar tuning coefficient in
PPI++ is. If even such inference coefficients were forbidden, the admissible procedure class would
be narrower than the one studied here.
“Fixed” means that every competing procedure receives the same realized inputs within a repetition;
it does not mean conditioning a frequentist coverage claim on all those inputs. Coverage is evaluated
over repeated sampling of labeled pairs and unlabeled scores. Without an additional conditional

Our questions are: (i) what information can scalar PPI++ leave unused inS; (ii) can a low-dimensional,
label-fitted adjustment exploit it without additional data; and (iii) how much of the width improvement

null, and failure cases; and a direct finite-sample comparison including exact binomial baselines.
We explicitly separate familiar methodology from the empirical contribution. We do not establish a
procedure that dominates all existing valid intervals, and we do not claim a comprehensive literature
review beyond the permitted sources.
2 Related work and scope
PPI estimates a mean with ¯SU + Y − SL and provides a broader rectifier framework [Angelopoulos
et al., 2023]. PPI++ learns a scalar coefficient, reducing dependence on the raw predictor’s calibration
[Angelopoulos et al., 2024]. Its discussion already connects prediction-powered means to augmented
inverse-propensity estimation and gives an efficiency inequality. Our projection calculations specialize
this existing perspective to the information in a frozen score and expose exactly what nonlinear
controls could add. A multivariate control variate is not a newly invented estimator.
Cross-PPI uses the available labels to train predictors with cross-fitting [Zrnic and Candès, 2024b].
Here we train no replacement model on X: the nuisance regressions operate only on a fixed,
low-dimensional score dictionary. The motivation for cross-fitting is shared with double/debiased
machine learning [Chernozhukov et al., 2024], but our asymptotic argument requires only a fixed-
dimensional consistent coefficient, not a general causal or high-dimensional nuisance theorem.
StratPPI accommodates strata and allocation choices [Fisch et al., 2024]. Retrospectively choosing
different labels is excluded in our experiment; a fixed-bin poststratification estimator is closely related
to a score dictionary. Active inference changes which points receive labels [Zrnic and Candès, 2024a]
and is therefore outside our constraint. We make no comparison to its altered sampling designs. Our
strict-coverage construction applies the empirical-Bernstein inequality of Maurer and Pontil [2009];
its conservatism is measured rather than hidden.

5 Experiments
5.1 Design and uncertainty
The main experiment has n ∈ {200, 800}, N = 10n, and 5,000 independent repetitions per condition.
All methods in one repetition receive identical arrays. We use a fixed dictionary and all prespecified
laws, including adverse cases. A separate degree stress test uses d ∈ {1, 2, 3, 7, 15} and n ∈
{50, 200, 800}. An unlabeled-size check fixes n = 800 and uses N/n ∈ {1/4, 1, 4, 40}. Strict-
coverage checks add n = 3, 200 and 12, 800, with 3,000 repetitions per condition. This changes
sample sizes between experimental conditions, never between methods in a comparison.
Synthetic scores are uniform on [0, 1], except a two-valued score with equal probabilities. With
T = 2 S − 1, continuous labels have mean 0.5 + 0.4T (linear) or 0.1 + 0.8T 2 (quadratic), plus
independent uniform noise on [−0.03, 0.03]. Binary laws use success probabilities 0.5 + 0.45T ,
0.05 + 0.9T 2, 0.05 + 0.91{S >0.7}, 0.5, or 0.005. For two-valued S, the success probability is
0.1 + 0.8S. All laws are bounded and all targets are evaluated by analytic moment integration in the
supplied code. The low-noise quadratic example deliberately isolates strong nonlinear headroom; it
is not representative evidence of a typical scientific dataset.
We also use the galaxies, forest, and alphafold prediction/label arrays pinned to the loader in
ppi-python v0.2.3 [Angelopoulos and contributors, 2024]. Each artifact defines an empirical
distribution: independently draw labeled records and unlabeled scores with replacement, and evaluate
coverage for the full artifact’s label mean. This produces IID sampling with known truth and avoids
finite-population corrections. It is not coverage evidence for the actual cosmos, Amazon, or proteome.
Hidden artifact labels are used only to evaluate truth and oracle projections, never to fit an interval.
We ignore the extra protein-modification covariates to maintain the score-only comparison. Scores
were already supplied; no predictor was trained or queried.
Coverage uncertainty is binomial Monte Carlo uncertainty, not an additional interval for µ. Main
tables show ±1.96 binomial standard errors; full tables and figures use Wilson intervals. Mean-width
error bars are 1.96 standard errors. Width ratios are ratios of mean widths with paired delta-method
errors: for ratio R = ¯WA/ ¯WB, use sd(WA − RWB)/(√M ¯WB). These are pointwise summaries,
with no multiplicity-adjusted discovery claim. Seeds, exact laws, every per-repetition endpoint, and
all results are provided. Implementation checks verify the official scalar tuning formula (accounting
for the declared divisor), the projection identities, binary-score equivalence, and input immutability.

5.3 Narrower-looking intervals can be invalid
The full-sample CV3 plug-in approximation is fragile in the low-noise quadratic law: at n = 200, its
coverage is 91.68 [90.88, 92.41]%, despite a narrow interval. CF3 gives 95.06 [94.42, 95.63]% in
the same repetitions. Both are asymptotically justified at fixed dimension; these finite-sample results
demonstrate why the theorem cannot be read as a guarantee at the nominal sample size. Shared
estimation of moments and a small leading variance make the remainder consequential.
In the degree stress test, null-law degree-15 intervals at n = 50 have coverage 88.38 [87.46, 89.24]%
and width ratio 0.935 ± 0.002 against degree one (Figure 1). Their apparent shortening is not an
inferential gain. Other laws also show failure, even without consistent narrowing; all are retained in
Appendix E. More flexible controls alone are not a safe recipe.
The rare-event law exposes a separate failure: with success probability 0.005, zero successes are
common at n = 200. CF3 coverage is 63.46 [62.12, 64.78]%, and is still 90.80 [89.97, 91.57]% at
n = 800. A zero empirical label variance can collapse any of the tuned score-based Wald intervals.
The exact binomial and bounded-outcome intervals remain valid. The wider raw-score PPI interval
sometimes masks the normal-approximation failure; this is not evidence that optimally tuned Wald
intervals are uniformly valid.

5.4 What survives a finite-sample guarantee?
The strict-coverage comparison changes the practical conclusion (Table 3). In the continuous quadratic
example at n = 800, EB-split3 is wider than EB-label by the ratio 1.2704 ± 0.0004. At n = 3, 200,
the reduction is 6.1%; at n = 12, 800, the ratio is 0.7169 ± 0.0001: a 28.3% reduction with coverage
100.00 [99.87, 100.00]%. This demonstrates a shorter interval with an actual finite-sample coverage
theorem under fixed inputs. The large label count is a limitation, not an extra resource granted to the
proposed method: every comparator in that row gets the same labels. EB-split3 remains much wider
than an oracle-normal interval, so this result does not establish optimal finite-sample width.
In the uninformative and rare-event binary laws, exact binomial intervals are much narrower than
the split bound. On the three real artifacts, even at n = 800 the strict split bound is wider than
the existing valid label-only methods; the available results do not support practical strict-coverage
improvement there. An unreported reduction against only EB-raw would be a weak comparison
because ignoring the predictor already helps. Finally, the unlabeled-size check follows the ρ factor
in the headroom formula: nonlinear gains increase when unlabeled observations are plentiful, but
vanish in the no-information example. Figure 3 in the appendix reports coverage as well as width.
6 Discussion and limitations
With fixed observations and a fixed predictor, inference can still exploit nonlinear score information
that scalar power tuning discards. The achievable first-order gain is limited by conditional noise
and by estimating the score distribution. When the conditional mean is already affine, the regular
score-only bound leaves no extra first-order gain. A low-dimensional dictionary can approximate a
useful nonlinearity; it cannot guarantee improvement, and flexible empirical fitting can make intervals
misleadingly small.
Our strongest numerical reductions concern asymptotic intervals in deliberately favorable synthetic
laws. Strict finite-sample improvement is demonstrated only against specified bounded-outcome

baselines in a large-label continuous example. We do not show an improvement over the best possible
finite-sample procedure. Exact binomial intervals decisively outperform our strict bound on binary
no-information examples. We do not recommend replacing exact binary intervals with the split
construction merely to use a predictor.
The real-data study conditions on empirical artifact distributions, and does not validate the original
model’s external training independence, annotations, spatial dependence, or deployment sampling.
The theory needs representative IID samples from the same score law. Covariate shift, informative
label selection, clustered observations, label noise relative to a scientific gold standard, or a predictor
trained on the inference labels invalidate this unmodified analysis. We do not repair those violations.
We study only means, bounded outcomes for exact guarantees, small prespecified dictionaries, and
fixed folds. Gaussian asymptotics are pointwise rather than uniform near rare-event or degenerate
distributions. Further transformations, extra recorded features, and other interval constructions might
improve the small headroom found here; the cubic real-data result is not an impossibility theorem.

A.1 Projection calculation and nonlinear headroom
Let all random variables be centered when computing covariance. Expand Equation (1):
nV (b) = VarY − 2b⊤c + (1 + n/N)b⊤Σb. (10)
Since 1 +n/N = 1/ρ, square completion gives Equations(2)–(3). The centered projection of m onto
the dictionary is c⊤Σ−1(ϕ − Eϕ) because Cov(ϕ, Y) = Cov(ϕ, m). Its squared norm is c⊤Σ−1c.
For nested subspaces, orthogonality makes the difference in squared projection norms the squared
norm of the added component. This proves the nested-gain statement.
For an arbitrary square-integrable control h(S), Cov(Y, h) = Cov(m, h). Complete the square in the
Hilbert space of centered functions of S: the optimum is h∗(S) = ρ{m(S) − µ}, up to an irrelevant
constant, and nV ∗S = Var Y − ρ Varm. Apply the variance decomposition VarY = σ2ϵ + σ2m
and 1 − ρ = n/(n + N ) to get Equation (4). Its last difference is the squared residual after affine
projection. With a singular dictionary, perform these calculations on a fixed orthonormal basis for its
nonconstant span. The pseudoinverse gives the same estimator whenever this span has fixed rank; this
is the two-valued-score case in our implementation. We do not assert stable pseudoinverse behavior
for an arbitrarily changing numerical rank.

A.3 Consistency and Wald coverage
Let d be fixed. Under the fourth-moment and nonsingularity assumptions of Proposition 3, sample
covariance matrices and cross-covariances converge to their population values. Since ρ converges to
a constant, bb − b∗d = oP (1). Meanwhile, ¯ϕU − ¯ϕL = OP (n−1/2) when n/N → r ∈ (0, ∞). Thus
bµbb − bµb∗d = (bb − b∗d)⊤( ¯ϕU − ¯ϕL) = oP (n−1/2). (15)
The two independent sample means for fixed b∗d satisfy the multivariate central limit theorem; with
positive limiting variance, the standardized oracle estimator tends to a standard normal distribution.
Continuous mapping and the moment laws imply consistency of the plug-in variance, so Slutsky’s
theorem yields the Wald coverage statement.

In CF3, each fixed fold’s training OLS slope converges to Σ−1c, whether or not the conditional mean
is cubic. Multiplying by ρ therefore gives b∗d + oP (1). Fold proportions are fixed and positive, and
each difference ¯ϕU − ¯ϕLk is OP (n−1/2). Summing the finitely many products proves asymptotic
equivalence to the same oracle estimator. Within-fold sample residual variances consistently estimate
Var(Y − b∗⊤d ϕ). The average slope converges to b∗d, so Equation (6) consistently estimates the oracle
two-sample variance. All reported fold sizes are equal. With unequal fold sizes, Equation (5) and the
average coefficient must instead use weights |Lk|/n, which the supplied implementation does.
These arguments explain fixed-dimensional asymptotic validity, but do not bound remainders at a
particular n or for growing d. In particular, a small oracle variance can make an oP (n−1/2) term
practically important. Neither the degree stress test nor rare-event failures contradict this pointwise
theorem.
A.4 Finite-sample coverage and pilot cost
For a variable Z ∈ [a, a+ R], apply Maurer and Pontil [2009, Theorem 4] to (Z − a)/R with failure
probability δ/2 and to 1 − (Z − a)/R with the same probability. Scaling back gives Equation (7)
simultaneously for both signs with total error at most δ. The theorem uses the unbiased sample
variance, which equals the pairwise-difference definition in that source.
Let P be the pilot sigma field. The pilot is chosen by fixed indices before observing data. Conditional
on P, g is fixed, 0 ≤ g ≤ ρℓ, and the inference pairs and unlabeled scores are independent IID
samples from their original laws. The residual lies in [−ρℓ, 1]. Consequently,
Pr{|Y − gI − E(Y − g)| > Bℓ(s2I (Y − g), 1 + ρℓ, α/2) | P} ≤α/2, (16)
Pr{|¯gU − Eg| > BN (s2U (g), ρℓ, α/2) | P} ≤α/2. (17)
On the complement of these two failure events, their sum differs from µ by at most Equation (8). A
union bound and expectation over P give coverage at least 1 − α. Clipping interval endpoints into
[0, 1] cannot remove a true parameter in that set. No pilot calibration accuracy, conditional-mean
specification, or large-sample approximation is needed.
To derive Equation (9), condition on P and expand
Var(Y − gI + ¯gU | P) = Var(Y − g)ℓ + VargN . (18)
The conditional mean is always µ. Square completion with respect to the centered control g gives
Equation (9), up to constants in g that do not affect variance. Thus the unconditional estimator
variance is the expectation of that expression. Relative to a full-data score oracle, its excess is
σ2ϵ (ℓ−1 − n−1) + σ2m{(ℓ + N )−1 − (n + N )−1}
+ (ℓ−1 + N −1)EP Var{g(S) − ρℓm(S)}. (19)
Every term is nonnegative. To outperform a full-data scalar oracle in point-estimator variance, the
nonlinear headroom in Equation (4) must exceed these costs. To outperform its confidence-interval
width, one must additionally account for the different coverage construction, including the explicit
range penalties. This distinction is central to the finite-sample experiment.
The exact binary baseline usesk = Pi Yi and endpoints 0 if k = 0 (otherwise Beta−1α/2(k, n−k+1)),
and 1 if k = n (otherwise Beta−11−α/2(k + 1, n− k)). Inverting each binomial tail gives tail
noncoverage at most α/2; summing the two errors gives coverage at least 1 − α. Binary support is
known from the law or artifact, not inferred from whether the observed sample happens to contain
only zeros and ones. Hoeffding’s baseline has half-width

G Reproducibility, compute, and research integrity
The source archive containscode/methods.py (all intervals),code/experiment.py (all repeated-
sampling suites and oracle moments), code/summarize.py (every table and figure), and
code/verify.py (scientific implementation checks). A baseline augmentation script regenerated
the same random draws to add Hoeffding and exact binomial comparators after the main run; it did
not alter existing endpoints. A fresh run of the current experiment driver includes them directly.
These extra baselines were added to strengthen a finite-sample comparison that would otherwise use
unnecessarily conservative binary baselines. The original full-run results and the added baselines
share the recorded seeds.
Run the main, ablation, and ratio suites with –reps 5000 –workers 4; run the finite suite with
–reps 3000 –workers 4, then run the summary and validation scripts. The README gives exact
shell commands, pinned package versions, data acquisition commands, source checksums, and the
table/figure mapping. Seed derivation uses the first eight little-endian bytes of SHA256 applied to a
documented fixed prefix and a condition key; it is independent of worker scheduling. The complete
repetition-level outputs are compressed CSV files. Results are reproducible up to floating-point
linear-algebra differences; no statistical claims depend on an unreported random seed.
The measured environment used Python 3.11.2, a four-core CPU quota on Intel Xeon Gold 6230
hardware, and a 16 GiB memory limit, with one BLAS thread per process. No GPU or paid API
was used. Per-suite measured wall times and maximum worker resident memory are below. Some
baseline augmentation overlapped the ratio suite, so these times describe the actual run rather than an
ideal sequential benchmark. The original main run’s per-cell CPU counter was cumulative within a
worker; it is not summed as a per-cell CPU measurement. The driver was corrected for subsequent
runs. The wall-time fields are unaffected.

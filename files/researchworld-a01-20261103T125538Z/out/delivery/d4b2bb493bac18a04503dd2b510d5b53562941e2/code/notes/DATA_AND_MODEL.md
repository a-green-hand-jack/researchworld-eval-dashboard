## Proposed analysis model (pending study-plan agreement)

An intervention affects only target entry i. On selected task j it replaces x_ij by x_ij + alpha(max(x_ij,c_j)-x_ij), where alpha is a declared fraction of remaining headroom and c_j is either 1 (ideal score ceiling) or the observed task frontier. Unselected scores and all opponents' raw scores are fixed. Investment K is the number of selected tasks. It is not training-data volume, dollars, compute, or a causal estimate of contamination benefit. Full saturation yields an optimistic lower bound on required task coverage for any monotone aggregation rule when real investments cannot exceed that ceiling. Partial uplift is a separate model, not a calibrated estimate of what training accomplishes.

Each leaderboard rule is recomputed separately: unweighted arithmetic mean, conventional median (average of the two middle values for even task counts), unweighted geometric mean, and average-rank/Borda (half credit per within-task tied pair). Tied first is primary; strict first is a sensitivity. Borda recomputes opponents' aggregate ranks after the target improves. Comparisons should pair the same targets and stratify by a fixed reference rank to distinguish starting position from aggregation effects. Identity/clone, normalization, uplift, task frontier, missingness, and task weights are modeling sensitivities, not stochastic uncertainty.

## Algorithms

`src/attacks.py` supplies exact cardinality optima. Mean sorts task gains. Geometric mean sorts log gains, prioritizing zero repairs, without pseudocounts. Odd-task median counts how many scores already reach the best opponent median and which selected tasks can cross it. All six-task cases use exhaustive enumeration of 64 subsets, which handles even-task median exactly. Borda uses a binary covering formulation with opponents' rank losses included; dominated opponent constraints are removed using a proven bound of at most 2T lost doubled-Borda points. MILP solver status, dual bound, runtime and returned witness must be retained; bounded/unresolved cases cannot be reported as exact optima.

The test suite independently enumerates every subset on random small diagnostic matrices, including seven-task cases that exercise the analytic and MILP paths, zeros/ties, partial uplift and frontier ceilings. These synthetic verification matrices are not empirical study data.

## Exactness arguments and interpretation

For every declared alpha/ceiling, each changed task has one permitted replacement y_j >= x_j. For a fixed subset, maximal permitted improvement weakly helps the target under all four rules. Cardinal scores of rivals do not change. Therefore mean attack minimizes cardinality subject to sum_j(y_j-x_j)z_j reaching the aggregate gap; sorting gains is exact. Geometric mean uses the analogous sum of log gains; zero-valued tasks must first be repaired for any positive aggregate, while a zero rival maximum allows a zero-cost tie. Odd-task median reaches threshold h iff at least (T+1)/2 tasks reach h, so the optimum is exactly the deficit in already-qualifying tasks if enough tasks can cross h, and infeasible otherwise. Strict first uses strictly greater thresholds, with a declared numerical comparison tolerance.

For Borda let p_ij be doubled pairwise points: 2 per opponent below, 1 per tied opponent, 0 above. Let D_lj be the increase in target's pairwise points against opponent l on task j when attacked, and G_j=sum_l D_lj. Then the target increases by G_j and opponent l decreases by D_lj. The exact covering constraints are sum_j(G_j+D_lj)z_j >= P_l-P_i (+1 for strict first). All terms are integers. Since any opponent loses at most 2T points, only opponents initially within 2T points of the best rival can bind; removing lower opponents preserves feasibility. Binary MILP optimizes sum_j z_j; full six-task enumeration is an independent exact implementation.

There cannot be a universal mean-versus-median resistance ordering, even if the same target is initially below the same competitor under both rules. Algebraic examples under three tasks and unit saturation: competitor (.9,.9,.1), target (.6,.6,.6) requires one task for mean but two for median; competitor (.95,.95,.95), target (0,0,0) requires three tasks for mean but two for median. These are counterexamples establishing scope of a general ordering claim, not real-board measurements or estimates of training benefit. Any empirical ordering must be conditional on targets, baseline scores, transformation and budget.

Numerical convention: cardinal aggregate comparisons use tolerance 1e-11 on scores scaled to [0,1], with strict first requiring a margin greater than that tolerance. Borda comparisons use exact doubled integer rank points and require at least one extra doubled point for strict first. Within-task Borda ties follow exact equality in the parsed published floating point scores; no score jitter or pseudocount is added. Report these conventions when exact-tie edge cases matter. The evaluation-count-weighted mean sensitivity sorts count-weighted gains, which is the same exact separable cardinality argument as the equal-task mean.

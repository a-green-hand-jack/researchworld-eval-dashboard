# Venue decisions (paper-repo, venue function)

- Style: the supplied `template.tex` loads `\usepackage[preprint]{neurips_2025}` (single column, NeurIPS 2025 preprint). The style is kept unchanged, as AGENTS.md requires ("Do not change the overall style which is mandated by the conference").
- `neurips_2025.sty` is not among the frozen inputs and this sandbox has no network, so the official file cannot be obtained here. It is **not** delivered: a home-made substitute would misrepresent the venue's style. The caller workspace that supplied the template is expected to provide it (the official NeurIPS 2025 style kit). Builds here used local stand-ins (5.5in x 9in text block, Times, natbib; empty stubs for `inconsolata`, `stackengine`, `ulem`, which this TeX Live lacks), kept outside the delivered tree.
- The task's "11-page double-column" wording conflicts with the single-column NeurIPS template; the mandated template wins. The main text ends at the bottom of p.12 in the stand-in layout (single column), references follow on p.13; an 11-page double-column budget holds more text than this, so the length is within the objective's scale.
- `references.bib` is the frozen input, byte-identical (task: do not change it). It has stray-comma syntax errors in 34 entries that make BibTeX drop their `abstract` fields and exit nonzero; use `latexmk -f` or `pdflatex; bibtex; pdflatex; pdflatex`. All cited keys resolve.

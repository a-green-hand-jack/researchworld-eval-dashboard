# figtab-repo — figures and tables

Presentation position. Generators in `figures/src/` (`make_all.sh RESULTS_DIR` rebuilds everything from the analysis `results/`); outputs: vector PDF + PNG + JSON sidecar
(arguments, input SHA-256, plotted counts) in `figures/`, LaTeX tables in `tables/`. `figures/MANIFEST.md` maps each output to command, inputs and claim; `figures/CAPTIONS.md`
and `tables/CAPTIONS.md` hold the caption stubs. Commitment: issue #2.

# Edit-budget fragility of Bradley–Terry leaderboards — code and reproduction notes

Paper: `paper/main.tex` (NeurIPS 2026 template, `paper/main.pdf`). Everything below is relative to `/work`.

## Layout
```
code/bt.py            count-based Bradley-Terry model (soft tie labels), IJ standard errors, greedy refit-verified
                      minimal-edit search (delete / relabel / insert; order flip or loss of significance)
code/datasets.py      loaders: Arena-55k, MT-Bench human & GPT-4, NBA seasons, same-battle LLM-judge labels
code/exp_*.py         experiments (see table below);  code/analysis.py: tables, figures, number macros
code/run_all.sh       whole pipeline;  code/get_data.sh: data download + checksums
data/                 raw data (NOT part of the submission; created by get_data.sh)
results/              csv/json outputs of the experiments
paper/                LaTeX source, tables/*.tex and figs/*.pdf (generated), numbers.tex (generated macros)
```

## Notes and honest caveats
* `k` reported by the search is a verified *upper bound* on the minimal edit budget (an actual edit set was applied and the
  BT model refit); there is no lower-bound certificate for real boards. Exhaustive comparison only on tiny boards.
* A first version of the significance-loss search fixed the s.e. at its original value; we found that s.e. changes with insertions
  and re-implemented it with s.e. recomputed on the edited board (`zcrit` in `bt.min_edits`); all results in the paper use the latter.
* During development the paper's text was drafted before the final full pipeline rerun; numbers are macros so they reflect the final run.
* **Independence statement on the starter literature.** Entry 8 of `starter_literature.md` (Huang et al., 2025) appears to be on
  the very topic of this task. In line with `deliverable.md` we did not search for, open or read it, nor anything citing it; it is
  cited in the paper only as a listed starter reference with this disclosure. Literature searches were limited to
  Bradley–Terry/ties/Elo robustness, influence functions and the other starter items; no forbidden page was encountered.
* LLM use: the whole study (code, experiments, paper) was carried out by an autonomous LLM agent (Claude).

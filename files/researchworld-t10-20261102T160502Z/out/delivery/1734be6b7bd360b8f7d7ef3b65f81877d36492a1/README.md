# Reproduction notes — fixed-input confidence-interval width for the population mean (prediction-powered inference)

This repository delivers the paper (`paper/main.pdf`, LaTeX source in `paper/`, NeurIPS 2026 template with the filled paper checklist),
the analysis code and results (`code/`), the figure and table generators (`figures/`) and the venue notes (`venue/`).

Question: with the labeled set, the unlabeled set and the predictor all fixed, can a valid 95% confidence interval
for the population mean E[Y] be shorter than PPI / PPI++ intervals, by how much, and under which conditions?
The answer in the paper is conditional: the achievable width is bounded by an efficiency ceiling that depends on the nonlinearity of
E[Y | f]; on the nine real datasets PPI++ is already within 0.5% of the ceiling on seven of them, so cross-fitted calibration does not shorten the
intervals there, whereas on synthetic populations with nonlinear E[Y | f] the gain reaches 21%. Small-n coverage and distribution shift are reported
as limits.

## Data acquisition and data version
Only the nine example datasets of `ppi-python` are used (package `ppi-python==0.2.3`, tag `v0.2.3`, commit `6b8475b`):
galaxies, forest, alphafold, gene_expression, census_income, census_healthcare, census_education, plankton, ballots.
The package fetches the `.npz` files from its Google Drive into `./data/<name>.npz` (about 46 MB, no account needed):
```
pip install ppi-python==0.2.3
python -c "from ppi_py.datasets import load_dataset as L; [L('./data/', n) for n in ['galaxies','forest','alphafold','gene_expression','census_income','census_healthcare','census_education','plankton','ballots']]"
```
`data/` is not part of the repository. The `.npz` files carry no stated licence (the package code is MIT); the paper does not claim one. The original sources are the ones cited in the PPI paper and the `ppi_py` example notebooks (Galaxy Zoo 2 for galaxies, the folktables census data of Ding et al. 2021 for the census sets; see `paper/refs.bib`).
Synthetic populations are generated by `code/src/data.py` (`synth_sampler`); no other data are used.

## Random seeds
Every cell (population, n, N, shift, with/without replacement) uses `SeedSequence([space, sha256(cell key)[:8]])`, with seed space 0 for development
and 1 for the final runs (disjoint). The choice of the calibrated interval (M4) and of the small-sample corrections (M5) was frozen on development
synthetic runs before the final runs (`code/results/frozen_choices.json`). All methods use the same draws within a replicate.

## Limits stated in the paper
Coverage claims are Monte-Carlo (R = 2000) and uncorrected for multiplicity; a single cell is not read as evidence. The pool is treated as the population and records are
drawn with replacement; the efficiency ceiling is asymptotic. Under the plankton shift the picture depends on the clipping of the PPI++ weight (see the paper).

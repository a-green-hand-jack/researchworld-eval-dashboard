# 交付说明

- 论文 PDF：`paper.pdf`；LaTeX 主文件：`paper/paper.tex`。
- 官方 NeurIPS 2026 模板，正文 8 页（上限 9 页），PDF 共 23 页，包含参考文献、附录和已填写的 16 项 checklist。使用官方 preprint 选项；未实际投稿。
- 复现说明：`README.md`；环境版本：`requirements.lock.txt`；完整运行入口：`reproduce.sh`。
- 实验协议与修订：`PROTOCOL.md`；失败、访问和修正记录：`logs/RESEARCH_LOG.md`。
- 完整代码：`src/`；原始预测及选题索引：`results/main/`；指标：`results/metrics.csv`；配对区间：`results/paired_contrasts.csv`。
- 校验结果：`results/validation.json`；独立重跑结果：`results/reproduction_check.json`。

完成了 13 个基准、3 种模型划分、10 个种子、4 个题目预算；最终含 16 个估计器/对照，共 24,960 行指标。额外包含固定源模型的重复抽样诊断、源模型数量消融，以及精确有限总体枚举校验。

100 题时，分层残差法相对均匀残差估计的宏平均 MAE 降幅为：随机划分 9.2%、向高分模型外推 5.6%、向低分模型外推 3.6%。配对 MAE 差（分层减均匀，百分点）及 95% 区间分别为 -0.25 [-0.35, -0.14]、-0.15 [-0.26, -0.05]、-0.11 [-0.30, 0.10]。低分外推的区间跨零。

这些收益有明确边界：该方法没有全面胜过回归或简单分层对照，20 题预算下失效，排序收益不一致，正态区间在小预算下欠覆盖。共同的题目均值校正可以改善分数误差，但不会改变同一批题目上各模型的排序。所有结论只涉及固定二值矩阵的完整列均值。

主实验两次启动合计耗时 28.1 分钟：初次在大矩阵并行时触及内存上限，完成 120 个任务；优化临时矩阵内存并改为四进程后完成剩余任务。全部 390 个任务已完成，没有将未完成任务当作结果。失败和额外计算记录均保留。

# Reproduction contract and seeds

From the analysis directory, install `requirements.lock` with Python 3.11.2
and provide GNU make (the measured environment uses GNU make 4.4.1).
`make all` validates the bundled processed inputs, runs the tested solvers on
all declared frames/caps, runs all sensitivity and control panels, checks full
completeness/invariants, and regenerates the numerical summaries and findings.
`make -j2 main` runs independent HELM/OLLB suites concurrently; `make all` keeps
its stages ordered even if a caller requests parallel make. `make quick` runs
all HELM rules plus full OLLB score-rule cases; it is explicitly a partial
reproduction and does not satisfy the full sensitivity checks.

`make data` redownloads/rebuilds the public data. The OLLB parquet, all 303 HELM
release files, and the one OLLB item-count source JSON are verified against
frozen SHA-256 values. HELM verification can also be run without network:
`python3 src/fetch_helm.py RAW_HELM_DIR --verify-only`. Verification of a cached
file is not a new source retrieval. Original downloads occurred 2026-11-04;
the provenance/licence and forbidden-material statements are in `DATA.md`.
The environment record includes Python, numeric libraries, OS/architecture and
SciPy's bundled HiGHS version; all numerical jobs are CPU-only, with BLAS/OMP
threads set to one, in containers capped at two CPUs and 4 GiB.

| Step | Seed | Repetition / interpretation |
|---|---:|---|
| Main all-target optimization | no stochastic sampling | All targets; SciPy/HiGHS deterministic default, no randomized starts requested |
| Optional rank-stratified target selector | 0 | Main runs use all targets, not this selector |
| Task bootstrap, each frame | 0 | 100 draws, common task columns across rules, fixed original mean positions 2–11 |
| Independent score noise, each frame | 0 | 100 draws, common perturbed matrix across rules |
| Correlated score noise, each frame | 0 | 100 draws; shared-shock correlation 0.8; same random stream as independent noise |
| HELM task-count subsets | 0 | 100 subsets at each of 3,6,12,24,48,57 tasks; common subsets across rules |
| Random-order support controls | 7 | 200 orders per fixed target, cap and rule; same 20 targets (mean positions 2–21) |
| Independent optimizer test instances | 0 (score), 1 (ordinal) | Brute force, LP/convex or independent MILP comparisons |

Score-noise SEs are plug-in binomial-style scales with probabilities clipped
to [0.001,0.999]; perturbed scores are clipped to [0,100]. OLLB effective counts
and subtask normalization floors are approximate. Neither the task draws nor
these assumed score perturbations provide calibrated population confidence
intervals. Census summaries are deterministic descriptive quantities.

control row, matched by keys, to the canonical run. Numeric tolerance is 1e-5
absolute with no relative tolerance; matching infinity/NaN statuses are required.
Its completion record is `results/clean_reproduction.json`; runtime measurements
are in `results/clean_reproduction_runtime.json`. Both records are now supplied: all16 original files and457772 rows passed,

Additional independent-review checks are part of `make all` through
`make review-checks`: paired census-target bootstrap R1000/seed23, ten random
half-rival frames/seed11, the two epsilon conventions, and independent Borda
MILPs. `src/check_review_results.py` verifies agreement of original-frame and
0.001-margin records with canonical main records and checks paired summaries.
Its default is strict; `--available` is an incomplete diagnostic only.
`src/clean_review_reproduce.py CANONICAL_DIR CLEAN_EXPORT_DIR panels` cleanly
recomputes the frame/epsilon/DP audit additions. After canonical mains finish,
run the same driver with `bootstrap` to recompute the resampling additions.
Each command records child CPU and elapsed time, compares keyed numeric rows
with absolute1e-5 tolerance and preserves infinity/NaN. These additions are
separate from the original16-file clean-study export; neither record implies
the other has completed. Original clean-study timing is measured by make stage;
its suite logs additionally record elapsed time for individual Python commands.

For a fresh tree, `make all` generates paired canonical summaries in its final
`tables` stage before the strict cross-review check reads them. To reproduce
only the review additions after the main runs, use `make review-checks tables`.
The delivered clean reviewer-panel and target-bootstrap comparison records
both passed; the original16-file clean completion is reported separately.

Final-review additions are included in `make all` through `make final-additions`.
They add the matched-frame, all-target policy, SD/IQR-cap, processing-choice and
marginal headline analyses. Definitions and timed sizing pilots are in
`FINAL_EXTENSION_PROTOCOL.md`; current checked groups are in
`FINAL_EXTENSION_FINDINGS.md`. Individual `make final-frames`, `final-controls`,
`final-population`, `final-scales`, `final-census`, `final-summaries` targets allow
independent jobs; run the summaries only after all their inputs complete.
`make data` also builds the lowest-Average dedup sensitivity from the same pinned
parquet. Its checksum/procedure is in `data/provenance/ollb_lowest_average.json`.

For an isolated export with code/data, run
`python3 src/clean_final_reproduce.py CANONICAL EXPORT STAGE`, stages frames,
controls, population, scales, census, or the corresponding `*-summary` stage.
The driver removes derived outputs, names any copied canonical table as a frozen
input, records CPU/wall time and compares every output/diagnostic row by keys.
An overtaken canonical run leaves the comparison pending; `--compare-only` uses
the already-completed clean computation later. These extension checks are
separate from `clean_reproduction.json`, the original full-study check.

The original16-file clean driver now uses `make robustness baselines core-tables`:
`core-tables` regenerates/checks the original main/robustness summaries; `tables`
also performs the strict reviewer-extension cross-check. This separation prevents

separately reproduced reviewer panels. `make all` still runs `review-checks`
before `tables`, so its strict completeness gate is unchanged. The already-running
pinned original export has the pre-extension `tables` target (the same five
core commands) and is not changed by this maintenance fix.

For a fresh full reproduction, use `MTI_MILP_TIME_LIMIT=1200 make all` (or set
that environment variable on the clean driver). This is the measured timeout
continuation setting, recommended to avoid the observed120s Condorcet proof
failure. The default remains120s and any unfinished proof raises an error.

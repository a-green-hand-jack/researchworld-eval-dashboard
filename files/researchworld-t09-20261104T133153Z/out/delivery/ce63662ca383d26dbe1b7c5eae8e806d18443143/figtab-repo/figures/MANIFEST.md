# Figures and tables: manifest

Every output is generated by one script in `figures/scripts/` from the aggregated Monte-Carlo summaries of `experiment-repo`
(`results/summary/*.csv`). Nothing is typed by hand; `scripts/run_all.sh` regenerates all of it. Outputs land in `figures/out/`
(`*.pdf` vector for the paper, `*.png` previews, `*.tex` table fragments for `\input`). Dependencies: Python 3, numpy, pandas,
matplotlib (STIX fonts, bundled with matplotlib); versions are recorded in `REPRODUCE.md`.

Conventions used throughout
- Truth: the GATE is exact (model-defined). Error = estimate − GATE. Bias, SD, RMSE are over independent assignments × worlds
  (`n_rep` replicates per cell, see Table 1). Error bars are **1.96 Monte-Carlo SE**: bias_se from `aggregate.py` (the larger of the replicate-level
  and the between-world SE), SD SE = SD/√(2(n_rep−1)), RMSE SE by the delta method, coverage SE binomial. Parentheses in tables are MC SE.
- Colour follows the entity in every figure: one colour per graph family (Okabe–Ito palette, colour-blind safe; markers differ too), one per estimator.
  The correctly specified regression ("oracle") is always green, dashed or hollow.
- Error units: RMSE and bias are in units of the direct effect τ = 1 (GATE = τ + γ·(h(1)−h(0))); "relative RMSE" = RMSE/|GATE|.
- Width 5.5 in = ICLR text width; fonts ≥ 5.5 pt after placement at 100 %; vector PDF.

Layout: the figures are drawn at their final width (5.5 in, ICLR text width) and are meant to be included at `\linewidth` without scaling
(`fig7_failure_map_*` is 3.35 in high, `fig8_factor_ranking` 2.0 in), so that the fonts in the PDF are the fonts on the page (≥ 5.5 pt).
`fig7_failure_map_relrmse_<graph>` exist for all six graphs in the same compact layout (7 estimators; Bernoulli 0.5/0.1 and Louvain clusters;
propagation ρ = 0.9); the full 10-estimator, 4-design, 3-ρ grid for every graph is in `results/summary/e2.csv`, `e7.csv`.

## Status
Delivered: all outputs above, rendered from the **frozen** results of `experiment-repo` (806/806 cells of e1–e10, `results/COMPLETENESS.csv`; plus the post-freeze grids e11 and e12 for `fig9`, `fig10`, and the second-freeze tables t17–t25 (e13–e21) for `fig11`, `tab6`–`tab11`; run
`scripts/run_all.sh` with `FIGTAB_RESULTS=results/summary`). Captions with the verdict wording of `results/FINDINGS.md` are in `figures/CAPTIONS.md`.
Data handling in the scripts, agreed with `experiment-repo` (its issue #4):
- cluster-robust SEs with a single analysis cluster (BA and ER at analysis resolution 0.5, SE ≈ 1e-13) are omitted from `fig6`;
- Hájek cells with fewer than 5 estimable replicates are hatched in `fig7` and dashed in `tab2`; hatching in the "prop" columns for the oracle means no correctly specified model exists for the propagation mechanism;
- the correctly specified regression is `ORACLE_D` (with log-degree) everywhere; the plain `ORACLE` of e7 lacks the degree term and is not used.
Software: Python 3.11, numpy 2.4, pandas 3.0, matplotlib 3.11 (versions of the run that produced `out/`).

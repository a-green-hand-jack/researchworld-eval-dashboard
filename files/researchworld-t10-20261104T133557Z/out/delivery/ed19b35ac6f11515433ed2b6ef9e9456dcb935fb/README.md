# Reproduction notes (code/, results/)

Question: with labeled set, unlabeled set and predictor fixed, can a valid CI be shorter than power-tuned PPI++?
All numbers in the paper come from the scripts below; `results/` holds the summarised outputs, raw per-replicate rows are
archived as assets of a release of this study (too large for git) and regenerated by the grid scripts.

## Environment and versions
Python 3.11.2, CPU only (2 cores suffice). `pip install -r code/requirements.txt` (numpy 2.4.6, scipy 1.17.1, pandas 3.0.6,
scikit-learn 1.9.1, ppi-python 0.2.3, statsmodels 0.15.0, gdown 6.5.1, matplotlib 3.11.2). Scripts set OMP/BLAS threads to 1
(`code/civ.py`); parallelism is by `multiprocessing` over replicates.

## Data steps and version
`pip install ppi-python==0.2.3`; the nine `.npz` sets are downloaded anonymously by `ppi_py.datasets.load_dataset('/hutian/data/', name)`
(gdown from Google Drive; ~48 MB; no account). Scripts read them from `/hutian/data/` (`DATA` in `code/run_real.py`).
Used: galaxies, forest, alphafold, gene_expression, census_income, census_healthcare, census_education (mean / OLS truths = pool values);
ballots, plankton: see "Status" below. No other data. Synthetic data are generated in `code/run_synth.py`.

## Random seeds
Replicate r of a grid cell with base seed s uses `numpy.random.default_rng(s * 1_000_003 + r)`; base seeds: mean real grid 1, validity grid 5,
rho grid 7, OLS grid 3, synthetic grid 2, plankton/ballots 9; headroom split seeds 0..9. All methods in one replicate share the same draw (paired).
Sampling: labeled and unlabeled points iid with replacement from the empirical pool; truth = pool mean (OLS: pool OLS fit).

## Run commands and expected runtime (wall clock on a shared host, ~0.4-0.9 CPU per job; indicative)
Raw per-replicate rows go to `/hutian/scratch/raw/<grid>/` (override with `OUT=`); every driver skips cells whose file exists.
```
code/grid_real_main.sh DATASET [NS] [REPS]  # mean CIs: Wald/t/studentised x classical, PPI, PPI++, cf_{lin_f,iso_f,poly_f,gbm_f,lin_fX,gbm_fX};
                                            # main-text pools census_income gene_expression galaxies forest, n in {50..1000}, 2000 reps, N=min(pool,10000) (~1-3 h per cell)
code/grid_real_main.sh DATASET "100 500" 1000   # appendix pools alphafold census_healthcare census_education
code/grid_rho_main.sh                       # census_income, n=200, N in {200,2000,20000}, 2000 reps
code/grid_ols_main.sh                       # OLS coefficients on census_income, n in {50..1000}, N=10000, 2000 reps
code/grid_valid_real.sh                     # Wald / t / studentised validity, 7 pools, n in {15..500}, 2000 reps, no adjusters
code/grid_synth.sh "SCENARIOS" "NS" "RHOS" REPS  # synthetic scenarios and knob0/30/60/90 with oracle interval
code/grid_special.sh                        # plankton (no shift / 2013->2014 shift) and ballots (subsample, width-only)
python3 code/headroom.py                    # population headroom, 10 split seeds -> results/headroom_population.csv (~10 min)
python3 code/theory_synth.py ; python3 code/dataset_table.py
python3 code/summarize.py RAW_DIR results/OUT.csv [baseline]   # summaries (see results/PROVENANCE.md)
```

## Which script makes which result
See `results/PROVENANCE.md` (one line per file: command, seeds, reps, code revision). Figure and table scripts live with the
presentation owner (`paper/figures`, `paper/tables`) and read only `results/*.csv`.
Methods: `code/civ.py` (mean: classical, PPI, PPI++, cross-fitted adjusters, studentised bootstrap), `code/civ_ols.py` (OLS).

## Figure and table map (paper element -> script -> input CSVs)
The generators are owned by `figtab-repo` and delivered in this repository under `paper/figures/src/` (`style.py`, `widthcov.py`, `fig_*.py`, `tab_*.py`,
`run_all.sh`, its own `README.md`); they read only `results/*.csv` (as a `data_in/` symlink made by `run_all.sh`).
To regenerate: `sh paper/figures/src/run_all.sh results OUT` (about 40 s; needs python3 with numpy, pandas, matplotlib); the figures are written to
`OUT/figures/*.{pdf,png}` and the tables to `OUT/tables/*.tex`, to be copied to `paper/figures/` and `paper/tables/`.
Script names below are relative to `paper/figures/src/`.

| paper element (file) | script (`paper/figures/src/`) | input (this repo `results/`) |
|---|---|---|
| `paper/figures/fig_headroom_population.pdf` | `fig_headroom_population.py` | `headroom_population.csv`, `datasets.csv` |
| `paper/figures/fig_validity.pdf` | `fig_validity.py` | `summary_validity_real.csv` |
| `paper/figures/fig_c2_real.pdf`, `fig_c2_real_app_a.pdf` | `fig_c2_real.py` (+ `widthcov.py`) | `summary_mean_real.csv`, `summary_plankton_noshift.csv` |

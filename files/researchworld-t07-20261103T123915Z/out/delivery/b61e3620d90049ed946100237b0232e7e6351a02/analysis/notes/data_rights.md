# Asset provenance and rights

The frozen task explicitly authorizes the public packaged score matrices and code at the pinned upstream commit. Its `data.md` states that the MIT license covers the repository code and bundled `.jbl` files (copyright Guanhua Zhang and Moritz Hardt). The actual pinned MIT license is retained as `notes/sources/UPSTREAM_LICENSE` and its URL/hash is in `notes/literature_access.json`. The code excerpt used only to verify the prior estimator is `notes/sources/upstream_aipw.py`, with that attribution/license. New estimator implementations are written for this research delivery; no external service or original LLM evaluation was run.

The packaged scores originated from Open LLM Leaderboard and HELM. The task states that the live public leaderboard aggregate dataset has no declared data-card license and is not the packaged per-item source; some raw detail datasets are gated. We use only the fixed public packaged matrices, without accessing gated details or claiming that the repository license determines all upstream prompt/model/data rights. No prompt text or model weights is redistributed by this analysis. Full benchmark scoring/official subject weights and HELM row-name alignment remain unverified. The primary estimand is the unweighted finite binary matrix mean.

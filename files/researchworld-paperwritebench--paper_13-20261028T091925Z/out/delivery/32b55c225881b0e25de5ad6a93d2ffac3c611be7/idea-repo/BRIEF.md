## 3. Established facts (source file in brackets)
**Dataset / pipeline** [research_overview, table_zn]: FoodLog Athl app logs May 2023-Oct 2024, 632 users raw; final 6,925 images, 14,349 bboxes, 218 classes, 513 users. Steps (table_zn): 0 raw 11,460 img/61,414 bbox/5,889 cls; 1 remove w/o image: 11,460 img, 26,646 bbox (-34,768), 3,167 cls (-2,722); 2 remove w/o bbox: 11,285 (-175), 26,065 (-581), 3,071 (-96); 3 classes <10 samples: 9,121 (-2,164), 21,944 (-4,121), 1,180 (-1,891); 4 CLIP ViT-B/16 outlier removal (>1.5 SD from class centroid): 7,537 (-1,584), 17,513 (-4,431); 5 manual review, all-or-none per image: 6,925 (-612), 14,349 (-3,164), 1,180; 6 merge classes (GPT-4o grouping + manual refinement): 218 (-982). Dish names come from a 140K-item database; users can correct labels. Two-stage manual PII removal, ethics approval, informed consent. **Inter-annotator agreement not reported** (must be said).
**Tasks** [ACM_task.jpg, overview]: T1 closed-set dish classification on crops (Top-1/3/5 recall, F1; LMM free-form description -> e5-large-v2 embedding -> nearest label by cosine; CLIP/EVA-CLIP by image-text similarity); T2 continual user-aware adaptation along time, per-week accuracy plus weighted one-month moving average (+-2 weeks, weights proportional to weekly volume); T3 menu/context-aware per-dish classification in multi-dish images (LMM first describes the whole meal, then classifies the crop given that description). LMMs run via lmms-eval.
**Task 1 results** [table_kf, exact]: F1/R@1/R@3/R@5 — GPT-4o .3732/.4243/.4991/.5221; Qwen2.5-VL-7B .2349/.3684/.4609/.4859; Qwen2-VL-7B .1594/.3656/.4590/.4781; Qwen2-VL-3B .1386/.2663/.3250/.3517; llava-onevision-qwen2-7b-ov .1546/.3629/.4497/.4639; EVA-CLIP ViT-g .2465/.2654/.4897/.5944; CLIP ViT-L/14 .2393/.2567/.4885/.6000; llava-v1.6-34b .1354/.2432/.3779/.4063; llava-v1.5-7b .0991/.2140/.2721/.2973; llava-v1.6-mistral-7b .0944/.1932/.2595/.2831. Pattern: GPT-4o best F1/R@1/R@3; CLIP-family best R@5 (CLIP .6000) but low R@1 (.26) — ranking depends on K and metric; F1 of LMMs well below R@1.
**Diversity vs UEC-Food 256** [table_xj, exact]: Trace CLIP/EVA/Swin 71.21/45.09/264.00 (UEC) vs 81.70/49.92/282.57 (ours); Silhouette 0.0335/0.0577/-0.0064 vs -0.0210/0.0036/-0.0288; Davies-Bouldin 3.64/3.02/4.11 vs 4.52/3.68/4.51; Calinski-Harabasz 74.05/115.80/49.17 vs 27.51/51.51/21.29. **Task 2** [all_data_1_35_with_legend.jpg, user_zero_lora_ma_wide_legend.jpg; values read off plots, approximate]: All-user incremental (weekly points ~2023/05-2024/01): zero-shot moving avg ~0.23 early, drifts DOWN to ~0.10-0.16 late; LoRA ~0.26 -> ~0.49; full fine-tune ~0.24 -> ~0.51.

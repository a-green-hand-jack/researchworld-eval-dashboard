\textbf{A common area measure for $K=3$.} Dots are means across 100 independent train/calibration/test replications; bars are pointwise 95\% $t$ intervals for these means, not simultaneous bands or intervals for a single calibrated run. Each replication uses 1000 training and 499 calibration observations and 5000 test observations per environment. Area uses 32 independent feature anchors and 8192 common uniform-simplex candidates per anchor in each replication/environment. Top: mean fraction of Euclidean simplex area under iid sampling. The uniform-simplex reference measure is shared across methods; it is not clr volume or application utility. Bottom: paired within-replication differences from unscaled Aitchison, with pointwise 95\% $t$ intervals; negative values indicate smaller area. Interpret area jointly with the coverage displays; the naive control has no nominal joint-coverage guarantee. TV exactly duplicates raw maximum at $K=3$, so these rows are one geometry. KL is forward $y\Vert\hat\mu$. Intervals crossing zero leave area orderings unresolved. No cross-geometry size comparison is made at $K=10$.

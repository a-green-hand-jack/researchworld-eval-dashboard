# 研究报告：少量整基准观测能预测什么？

## 1. 摘要与研究目标

目标是在历史“模型×基准”缺失矩阵上，仅观测新模型的 k 个**完整基准分数**，预测其他分数。主要问题是选择策略是否优于同一预测器下的随机选择，以及这种优势是否随覆盖率、留出分组、缺失机制与预测目标改变。

**结论：在所观测的队列中可以利用相关性，但没有证明通用的小预算、独有的最优方法或全榜单恢复能力。** 原始 MTEB 稠密队列只有1/5分组达到预先设定的样本门槛，未达到要求的≥3/5，因此全部结果均按描述性证据报告。更宽任务面板和版本关联分组的补实验明确标为事后探索性分析。

主论文：[paper.pdf](paper.pdf)；源文件：[paper/main.tex](paper/main.tex)。使用 NeurIPS2026 官方模板，正文9页、含参考文献/附录/完整checklist共27页；仅为研究稿，不声称已投稿或录用。

## 2. 实验计划

1. 获取固定提交的数据，只阅读起步清单内的指定论文与会议官方材料，不做主题/引文图搜索。
2. 在训练集拟合标准化、协方差与低秩因子；仅用验证集调参。
3. 固定互不重叠的可选输入基准与不可选择的审计目标；所有方法在相同模型/目标单元格上比较。
4. 使用种子11、23、37、53、71进行重复组织留出，另报随机行留出。不能把它们当作五个独立折。
5. 运行训练标签删除压力测试与原始不完整覆盖队列评估。
6. 独立审查发现原始OpenLLM版本别名重叠后，保留原结果，另做关联分组敏感性分析；扩展MTEB任务支持，均不恢复确认性资格。

已运行20个原始管线、18个训练缺失管线、10个探索性补充管线；另运行第二个随机选择种子库、理论数值核对与一次完整确定性复现。未运行的预期消融、时间留出、完整家族谱系分离、预测区间校准等均列在论文与`experiment_log.md`，不写成已完成。

## 3. 设置

### 数据

- MTEB：固定提交`6dabbcc68c28ea5f180ce7df79347b3ca9cc6383`。流式读取约377MiB压缩快照；单模型只取一个版本、单任务固定数据集revision、唯一英语test主指标。保留279×62矩阵，9,882个已观测单元格，密度57.13%。这是**嵌入模型**，不是生成式LLM。
- 原始MTEB实验：每个分组8个候选、4个审计任务的12任务面板。完整测试队列分别28、26、32、21、19行；不能据此声称对62任务完整预测。
- 宽面板探索：49个候选、12个审计任务，共61任务；每个测试模型仅有4–12个可验证审计分数，测试队列47、44、47、43、46行。没有为原本缺失的标签制造真值。
- OpenLLM：固定提交`9c09a7cae43334062a82cb164f2ef255013dafa2`；从4,576记录按名称/精度元数据选择4,497完整模型行，使用6个Raw比例分数。原始组织分组在每个种子均存在非空SHA跨训练/测试重叠（5、5、4、5、6个）。补实验把组织、非空SHA与Base Model关联成分组，已检查所有分区之间记录键重叠为零，但这不等于完整祖先谱系独立。最大连通分量2,890行，在种子71占测试集91.4%，影响条件不确定性的解释。

### 方法与计算

- 训练观测值标准化；重叠≥20的成对协方差、PSD投影与对角收缩；高斯条件均值预测。
- 训练协方差的剩余迹贪心选择；对照包括固定审计目标贪心、相关覆盖、高方差与随机选择。
- 高斯收缩参数网格0/.1/.3/.6/.9/1，由验证集随机输入的核心预算损失选定，在选择器间共享。
- 掩码低秩ALS：秩1/2/4/8、正则.01/.1/1、3个初始化、最多200步。新模型因子仅由其已测分数求解，不与其他测试模型联合拟合；部分选中拟合未收敛，按固定计算预算基线报告。
- CPU数值实验，无GPU、付费推理API或新模型评测。依赖见`requirements.txt`和`requirements.lock`。
- 48个存储管线的计时合计516.70秒（不包含全部下载、分析、代理服务及写作成本；不是实际执行基准的节省时间）。单次完整复现峰值RSS157,672KiB，不能外推为全项目峰值。项目级完整资源账目未记录，不虚构为零。

## 4. 基线与公平比较

11个配置包括训练均值、随机+高斯、剩余迹贪心、审计贪心、高方差、相关覆盖、随机/剩余迹输入的低秩预测、因子D-opt选择、无收缩与均值填充协方差。

- 随机策略使用50条嵌套排列，平均的是**各路径的损失**，不是先平均预测再算损失。
- 固定审计集合不能被任何方法选择为输入，排除了“测走难预测目标”造成的机械改进。
- 同输入的高斯/低秩比较隔离了预测器差异；D-opt为完整选择器/预测器组合，不作为纯预测器消融。
- 原始不完整覆盖下的剩余迹策略优化全任务面板，而部署误差只在可观测剩余坐标计分。目标支持不一致已披露；固定审计比较仍有共同支持。随策略变化的部署目标误差仅作诊断，不能证明公平目标上的优势。

## 5. 结果

核心指标为每模型审计目标的训练标准差归一化MSE，先平均预算，再等权平均五个分组。MTEB预算1/2/4；OpenLLM预算1/2。下表为剩余迹贪心对同预测器随机选择的对比。

| 数据条件 | 随机NMSE | 剩余迹贪心NMSE | 相对降低；条件描述性95%区间 |
|---|---:|---:|---:|
| 原始MTEB、12任务稠密队列 | 0.421 | 0.357 | 15.1%；[9.7%,20.6%] |
| MTEB宽任务原生覆盖、探索性 | 0.296 | 0.239 | 19.3%；[14.3%,24.8%] |
| 原始OpenLLM、有版本关联重叠 | 0.530 | 0.469 | 11.5%；[9.6%,13.7%] |
| OpenLLM关联分组、探索性 | 0.500 | 0.429 | 14.2%；[11.6%,16.1%] |

这些区间通过2,000次成对组织/关联分量bootstrap产生，同一组织跨重复分组的记录一起重采样；条件于既有拟合、队列和第一个随机输入库，不涵盖全部重拟合、数据源、选择及有限随机库不确定性。没有把多项比较的区间排除零包装为经多重校正的显著优越性。

**重要负面与边界结果：**

- 宽面板中审计贪心0.228、相关覆盖0.223、均值填充协方差0.217，点估计均低于剩余迹贪心0.239，不能声称所选方法独有优势。
- 宽面板无收缩0.225，接近且略低于调参审计贪心0.228；收缩并非所有条件都改善。
- 50%任务倾向缺失条件下，剩余迹贪心原始尺度RMSE0.1076，高于随机0.1060，出现反转；无收缩在50%高分依赖缺失条件下RMSE达0.1386。
- 原始MTEB验证集一标准误预算规则为剩余迹策略选出2/2/2/1/1个任务，但测试损失不在每个分组都优于更多输入的随机策略。不能把它当成新模型的校准保证或普遍足够的k。
- 已执行第二个独立50路径随机库敏感性检查，未替换原始摘要或重新调参，具体波动见`artifacts/random_bank_sensitivity.csv`。

### 理论及数值核对

已推导高斯条件均值、Schur补风险与固定审计目标的边际风险下降；明确假设有限正定已知协方差、精确观测和高斯分布。目标块与可选块独立时，测完全部候选也不降低目标风险，因此不存在对整个协方差类别都有效的通用小k。标准高斯设定下风险不依赖已观测的分数值，不能把静态协方差路径称作分数自适应。

10万样本的明确标注合成检查在约1.3个Monte Carlo标准误以内核对了风险公式；它不是现实榜单上的理论保证。独立坐标例子展示了部署总风险由2降到1而固定目标风险仍为1的“自移除”现象。附录还给出非次模反例，不声称通用贪心最优性。

## 6. 分析、局限与下一步

现有证据支持在特定观测队列中利用跨基准相关性，但不足以建立确认性的全榜单、新家族或未来模型保证。完整覆盖模型的选择偏差、自然缺失、任务类型不平衡、别名/祖先关系不全、单一巨大关联分量、有限随机库、拟合不收敛与未完成的消融都限制推断。公开得分自身的噪声、污染、提示与软件版本差异也未完全校正。

下一步应在真正未触及的新模型队列中，先核对版本与支持、封存拟合选择，再做有足够任务覆盖的验证；安全、偏差和域外能力必须直接测量。不能用低平均预测误差替代安全认证。

**交付完整性不等于科学问题已彻底解决，也不保证达到会议录用门槛。** 未完成的实验、资源记录和许可核实均如实保留。全部数值实验代码、固定版本获取脚本、依赖、命令、种子、逐图逐表来源及官方模板论文已交付。完整复现步骤见`README.md`；代码/论文/聚合结果包见`submission_code.zip`。

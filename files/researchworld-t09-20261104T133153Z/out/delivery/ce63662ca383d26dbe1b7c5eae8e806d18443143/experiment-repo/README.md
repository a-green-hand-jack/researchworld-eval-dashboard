# experiment-repo — regression-based GATE estimation under network interference

Simulation study (code in `src/netgate`, drivers in `scripts/`). Everything reported is regenerated by these scripts.

## Layout
- `src/netgate/graphs.py` graphs (SBM / BA / Watts–Strogatz / ER synthetic; Stanford3 and SNAP ego-Facebook real), Louvain clusters.
- `src/netgate/outcomes.py` potential-outcome models Y_i(z) with exact GATE (mechanisms: 1-hop spillover with linear/concave/convex/sigmoid shape, neighbour-count, 2-hop, degree-heterogeneous direct effect, equilibrium propagation).
- `src/netgate/designs.py` Bernoulli(p), graph-cluster (Louvain) and random-cluster randomisation, planted-block randomisation; exact exposure probabilities.
- `src/netgate/estimators.py` difference-in-means, Hajek full-/kappa-neighbourhood exposure, regression-based GATE (OLS on exposure features with several specifications, correctly-specified oracle, gradient boosting), SEs: HC0, cluster-robust, graph-HAC (1-/2-hop).
- `src/netgate/experiments.py` the experiment grids e1..e9; `scripts/run_experiment.py <exp>` runs a grid (resumable, one gz CSV per cell in `results/raw/<exp>/`).
- `scripts/aggregate.py` -> `results/summary/<exp>.csv` (bias, sd, rmse, relative RMSE, coverage, Monte-Carlo SE).
- `scripts/theory_bias.py` closed-form large-n bias of the linear exposure regression vs simulation.

## Data
Stanford3 (`socfb-Stanford3.zip`, sha256 b1221e41…720d, matches data.md) and ego-Facebook (`facebook_combined.txt.gz`, sha256 125e84db…35d7, matches data.md) downloaded into `/hutian/data` (override with `NETGATE_DATA`). Largest connected components are used (Stanford3 keeps 11,586 nodes unless stated in the summaries).

## Provenance notes
- First launch of the grids was discarded: the on-disk Louvain cache was keyed by graph family name, so synthetic graphs of different worlds could share (wrong) cluster labels. The cache is now used only for the two fixed real graphs and all grids were rerun from scratch.

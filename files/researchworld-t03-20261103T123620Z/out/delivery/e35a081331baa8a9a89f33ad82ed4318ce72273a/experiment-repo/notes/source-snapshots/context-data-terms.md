## German Credit

The exact UCI landing page, <https://archive.ics.uci.edu/dataset/144/statlog+german+credit+data>, states: “This dataset is licensed under a Creative Commons Attribution 4.0 International (CC BY 4.0) license.” Its citation is “Hofmann, H. (1994). Statlog (German Credit Data) [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5NC77.” The page identifies Hans Hofmann as creator. The metadata API <https://archive.ics.uci.edu/api/dataset?id=144> identifies 1,000 records, 20 raw features, last update 10 August 2023, and the original class coding `1 = Good, 2 = Bad`.

Both the CC BY 4.0 deed and full English legal code were read at <https://creativecommons.org/licenses/by/4.0/deed.en> and <https://creativecommons.org/licenses/by/4.0/legalcode.en>. In particular, §§2–4 permit reproduction/sharing/adaptation within the licensed rights subject to attribution and other stated conditions. When sharing data, retain supplied creator/license/disclaimer/source notices, link the license, and indicate modifications; do not imply endorsement or apply additional downstream restrictions to those licensed rights. The license does not grant rights the licensor does not hold or guarantee suitability.

Suggested asset entry: “Statlog (German Credit Data), Hans Hofmann (1994), UCI Machine Learning Repository, DOI 10.24432/C5NC77, CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/). Download/version/hash and preprocessing changes: [actual analysis manifest].” Do not conflate the original 20-column symbolic data with `german.data-numeric`, a separately recoded representation. The UCI documentation supplies a cost matrix for credit decisions, but the current task assesses attribution sampling error rather than endorsing a lending decision policy.

## ACS 2018 1-year California PUMS / ACSIncome

Actual archive named by the analysis handoff: <https://www2.census.gov/programs-surveys/acs/data/pums/2018/1-Year/csv_pca.zip>. This note did not download/re-hash that archive; the analysis manifest owns that evidence. The study must cite that exact vintage/product/file plus its actual retrieval date/hash. ACSIncome is a derived task through folktables, not a separate Census-issued ground-truth label with an MIT license.

The official PUMS page <https://www.census.gov/programs-surveys/acs/microdata.html>, revised 31 July 2026, says:

> “The Census Bureau’s American Community Survey (ACS) Public Use Microdata Sample (PUMS) files enable data users to create custom estimates and tables, free of charge, that are not available through ACS pretabulated data products.”

It describes disclosure-protected individual/person or housing records, identifies 1-year and 5-year products, and explicitly lists the FTP route. The version-specific official `ACS2018_PUMS_README.pdf`, <https://www2.census.gov/programs-surveys/acs/tech_docs/pums/ACS2018_PUMS_README.pdf>, was consulted for §§I–II, VI–VII and the notes on estimation/confidentiality. It confirms that these are samples of ACS responses, that variables have been modified/top-coded/geographically limited for confidentiality, and that FTP dissemination is a documented route. Person records can include multiple members of a household; a person-row benchmark is not automatically an independent, population-representative survey analysis. Record whether survey weights are used. These facts are context and scope limitations, not claims about the current benchmark's statistical results.

The official policy overview and privacy overview were read at <https://www.census.gov/about/policies.html> and <https://www.census.gov/about/policies/privacy.html> (both revised 24 February 2026). The current citation page, <https://www.census.gov/about/policies/citation.html>, provides a Public-Use Statement:

> “Data users who create their own estimates using data from disseminated tables and other data should cite the Census Bureau as the source of the original data only. Conclusions drawn from any analysis of these data are the sole responsibility of the performing party.”

Its “Data Files and Geographic Products from Census.gov, the FTP, and External Data Platforms” section specifies author, file/product name, vintage, URL and access date. That is the applicable citation convention for this archive download. It also advises citing tools in addition to the underlying data file. No separate named data license for this exact archive was located on these checked pages. Report it as official publicly released ACS PUMS data with the checked public-use/citation guidance; do not relabel it MIT, CC BY, or a newly verified standalone public-domain license. This bounded statement preserves the uncertainty the frozen data description explicitly disclosed.

The developer API terms were also read in full at <https://www.census.gov/data/developers/about/terms-of-service.html> (revised 14 April 2026). They allow use of the API to search/display/analyze/retrieve data, restrict identification or identifying linkage/publication, disallow implying Census endorsement and falsely representing modified content as Census original content, and describe API access limits/disclaimers. They specifically require API-using services to display: “This product uses the Census Bureau Data API but is not endorsed or certified by the Census Bureau.” **These are API-specific terms; the actual acquisition here is the documented FTP archive delivered over HTTPS, so do not claim the archive was acquired through the API or that its license was established by the API agreement.** The source/confidentiality/no-endorsement principles are consistent with reporting an aggregate benchmark and attributing its own conclusions to its authors. Nothing in this note authorizes identifying data subjects or linking records to identify them.

The metadata's suggested paper link was not followed and no original historical paper is asserted here as consulted.

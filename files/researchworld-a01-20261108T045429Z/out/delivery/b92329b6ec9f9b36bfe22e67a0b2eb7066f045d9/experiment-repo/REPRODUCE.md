# Reproduction and claim map (analysis position)

Environment, data sources with SHA-256, seeds, commands, measured wall-clock per `make` target and the script -> table map are in `README.md` (same directory). Findings, definitions and caveats: `RESULTS.md`. Everything is regenerated by `make all` (3.75 h sequential; `make analyze final` alone, from the committed result CSVs, takes about 5 min); `results/manifest.csv` has SHA-256, producing command, seed and code commit of every result file.

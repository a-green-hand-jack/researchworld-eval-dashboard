# Figure specification (all numerical series generated from actual runs)

All figures: matplotlib reproducible `plot.py`; save PNG at300dpi and vector PDF. No fitted regressions, smoothing, idealized curves or invented data. Colors width=viridis and train/eval=blue/orange; normalizations=blue/orange/green. Errorbars=paired-seed percentile bootstrap95% CIs unless explicitly stated; curve bands=min--max over8 seeds (NOT confidence intervals). Full0--20000-update horizon retained. Numeric axes scales explicit below.

Train/eval legend, note censor caps. No extrapolation.

Mean curves and seed min--max bands. No projection-as-classifier results in accuracy panel.

Clock0--10 common observed horizon; truncation explicit, raw panel full horizon.

All8 seed dots and mean±95% bootstrapCI, no synthetic chance line required. Shuffled complement labels are permuted and explicitly named.

All planned robustness rows retained; no correction claims for exploratory contrasts.

# Numerical evidence contract

Main outputs will be produced only from a complete panel and are not available at pilot stage. `scripts/aggregate.py` rejects a missing input checkpoint, missing entire model cell, config/source mismatch or a ragged run denominator. `--allow-partial` is a development-only option and marks its manifest `partial_debug`.

- `results/main/<dataset>_<model>/metadata.json`: frozen config, source SHA256s, executing git revision, library/hardware versions, model/split/preprocessing diagnostics, all selected IDs and data provenance. `source_explain_ids`/`source_background_ids` are original CSV row indices (ACS) or raw data row indices; `explain_ids`/`background_ids` are deterministic filtered-table positions.
- `results/main/<cell>/instance_NNN.npz`: exact `reference` vector, `attributions` matrix with matching JSON `run_records`, JSON `reference_record`, and source/config signature; safe `allow_pickle=False` loading. Rows are estimator,budget,repeat order recorded explicitly. Input0 in main is the third selected held-out input; first two selected inputs were pilot-only.
- `results/main/<cell>/completion.json`: process-wide CPU/wall and peakRSS; runner stdout checkpoints work. `failures.jsonl`, if produced, is retained and the job stops for correction; aggregation never turns an incomplete panel into a completed result.
- `results/run_metrics.parquet`: one row per actual stochastic call; dataset/model, background, original source ID and panel index, estimator, requested coalition budget, repeat/seed, actual prediction rows/calls, CPU/wall, exact normalized/absolute error, signed/unsigned selection/sign/rank outcomes, ties/signal/gaps, warnings, conditioning and exhaustive flag. Parquet retains types without a bulky uncompressed CSV.
- `results/aggregate_metrics.csv`: per cell and metric, estimate, pointwise95% instance-cluster percentile CI, independent-instance and repeat denominators,bootstrap count and conditioning.
- `results/paired_contrasts.csv`: difference(a-b) with paired-instance intervals across budgets within estimator or estimators at the same nominal budget. Actual cost differs and must be shown before a work-matched superiority claim.
- `results/reference_diagnostics.csv`: all exact target costs/endpoints/efficiency. Exactness means selected finite empirical interventional game, not population/causal correctness.
- `results/model_diagnostics.csv`: actual data/model/preprocessing/split and held-out predictive quality.
- `results/instance_success.csv`: observed primary-event successes out of30 and per-instance Wilson interval, not certification. It also identifies reference-defined signal/gap strata.
- `results/instance_repeatability.csv`, `results/aggregate_repeatability.csv`: all-pair repeatability reduced to one summary per independent input; do not treat all seed pairs as independent sample size.
- `results/stratified_metrics.csv`: prespecified near-top1-tie and low-signal strata; insufficient independent inputs get an explicit unavailable interval, not a fabricated interval.
- `results/averaged_run_metrics.csv`: accuracy of the mean of all repetitions with total cost exposed; it cannot be presented as a one-run explanation.
- `results/job_costs.csv`: measured whole-job runtime/memory, separate from per-call or projection costs.
- `results/aggregation_manifest.json`: completeness,actual denominators,signature and inference scope. Current `results/*pilot*` are measured setup/validation artifacts, not this main evidence.

Metric conventions match story protocol: k=min(3,d); rank by descending absolute attribution, feature index as deterministic exact-tie secondary key; signed overlap counts matching(feature,sign) tokens/k. Normalize L1 by max(referenceL1,.01). Primary success requires error<=.20 and signed overlap>=2/3; alternatives .10/.40 and strict signed overlap. Near-tie variants use1e-6 probability units; primary exact ties remain deterministic. Low signal referenceL1<.01; near-top1-tie normalized gap<=.02. Pointwise intervals are conditional on fitted model/split/background, not multiple-testing-adjusted discoveries or an individual guarantee.

## Final inference and repeatability clarification

`pairwise_normalized_l1` now uses the same exact-reference L1/.01-floor denominator as main reference error; `pairwise_run_normalized_l1` retains average-run scaling as a separate diagnostic. Signed top3 overlap and the pairwise magnitude+selection agreement event are also available, reduced once per input.

Bounded rates/overlaps retain raw `bootstrap_ci_low`/`bootstrap_ci_high`; all-success/all-failure cells replace the displayed `ci_low`/`ci_high` with a positive-width bounded-instance Hoeffding interval (`boundary_adjusted=True`). Conservative one-sided `bounded_mean_low95`/`high95` and a `certifies_mean_ge_0p95` guard are separate fields for every bounded rate. Only that guard can support a population>=.95 phrase, and with60 inputs it cannot do so even at zero observed failures. Use estimated/observed success rates; do not interpret a degenerate raw bootstrap as certainty. Full definition and limitations: `notes/boundary-inference.md`. The number of metric-defined independent cases is `n_metric_instances`, so undefined signs/ranks are not silently given the full denominator.

## Postprocessing completeness, ambiguity and floor sensitivity

`scripts/audit_panel.py` verifies every saved vector, primary magnitude/selection metric, exact-reference identity/efficiency, configured instance/run grid, source/config signature and seed provenance before aggregation. `results/panel_audit.json` records actual runs/references, unique seeds, warnings and failed attempts. The final two-input/two-repeat development check is separately labeled in `results/development_smoke_validation.json`; it is never a main result.

`results/assessability_counts.csv` exposes all-instance primary denominators, unresolved/failed counts and reference-defined numerical top1/top3-boundary ties, selected nearzero signs and weak signals. Numerical ambiguity uses twice the declared1e-6 coordinate tolerance for gaps and1e-6 for selected signs. The fixed-game exact point event remains defined for all inputs by the stable raw-index rule; ambiguity counts are cautions/sensitivity inputs, not a silently excluded subset. Active-sign-only means report their actual defined-case counts.

`results/floor_sensitivity.csv` supplies predeclared protocol floors .001/.01/.05 probability units for nL1 and the unchanged signed-top3 primary event, with pointwise cluster intervals/guards. It is derived from saved absolute errors/reference norms, with no new explanations or changed target. Raw absolute errors and reference norms are retained in run_metrics.parquet; low-signal counts are in assessability_counts.csv. Threshold/strict/tie-aware sensitivity remains in aggregate_metrics.csv. These postprocessing scripts are outside the frozen attribution-source signature.

Monitoring only: `scripts/audit_panel.py --allow-incomplete --output results/main_progress_audit.json` independently checks the current prefix of atomic input checkpoints and records per-cell reference/stochastic CPU subtotals. Its status is always `in_progress`; it does not summarize reliability and cannot be consumed as complete evidence. Default audit/aggregation still requires full completed cells and the whole configured matrix. The monitoring option does not change any attribution source or configuration.

## Traceable claim handoff

After complete audit/aggregation, `scripts/evidence_handoff.py` produces `results/claim_ledger.json`. It checks the full main denominators/signature, all54primary conditions and no undisposed warning/failure, then links every conditional primary estimate/interval/cost to the saved input hashes. It retains budget contrasts, repeatability, reference strata/ambiguity, floor/threshold/selection sensitivities and mean-of30 costs separately. It names supported claim types and unsupported generalizations without selecting manuscript claims or treating nominal-budget matches as equal actual cost. It is postprocessing outside the frozen attribution-source identity. The complete-main execution of this generator remains pending; its refusal of actual partial-development outputs is recorded in `results/claim_handoff_validation.json`.

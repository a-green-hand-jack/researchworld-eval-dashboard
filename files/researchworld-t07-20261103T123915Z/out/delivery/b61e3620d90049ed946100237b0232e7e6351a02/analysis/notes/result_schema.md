# Final evidence interface (prospective; no target results yet)

All paths below are relative to the analysis repository root, delivered under paper-repo `analysis/`.

- `config/study.json`, `splits.json`, `items.json`, `family_eligibility.json`, `data_manifest.json`, `code_manifest.json`, `freeze_manifest.json`: exact protocol, identities/row masks/counts, seeds and first 100 ordered item IDs per development/final draw (budgets nested), proxy assignments/eligibility, hashes and freeze checks. `gate.json` is added only after independent feasibility and CODEOWNERS gates are documented; it does not change statistical configuration.
- `results/study/development/<benchmark>/<scenario>.json`: chosen alpha/dimension/blend per budget, every development loss, actual fit/dev/history/target counts and tuning times.
- `results/study/fits/<benchmark>/<scenario>/<development|refit>_d<dimension>.json` and `.npz`: source-fit timing, process peak RSS, convergence attempts/gradients, source hash and learned parameters. Fit time is reused across budgets/draws and counted once per file.
- `results/study/predictions/<benchmark>/<scenario>.parquet`: one row per target/method/budget/repeat, immutable predictions with target and original row IDs, nominal budget, actual observed item count/fraction, N, historical count and selection key. It contains no full-score truth.
- Sibling `.selections.json`: selection-key to ordered actual item IDs and alpha/dimension/blend/inference metadata. Uniform methods share items; each crossfit half is the corresponding ordered half. Sibling `.access.json` records exactly what target-facing APIs returned. Fixed anchor sets repeat without independent source refitting.
- Sibling `.timings.parquet`: source-dependent statistic/selection construction and batch target-prediction seconds, n_targets and metadata. `mirt_*_gp` reuses its p-IRT inference and marks zero additional inference cost; source-selection cost for fixed anchors is counted only once per budget. MIRT fits live in separate fit records to prevent repeated summation.
- `results/study/scored_predictions.parquet`: retrospective union of predictions with true scores, exact response-pattern hashes, source-match indicators and inverse-target-pattern multiplicity weights. Full truth enters here only after predictions are complete.
- `results/study/metrics.parquet` / `.csv`: benchmark/scenario/budget/repeat/method and evaluation_subset (`primary`, `response_patterns`, `source_match`, `no_source_match`), counts/fractions, MAE/RMSE/bias/p90 absolute error in percentage points, Spearman/tau-b, rank undefined flag, out-of-range fraction, truth/prediction tie-pair counts, close/wide pair inversions and predicted-tie fractions. Close pairs have nonzero true gap <=1 percentage point; wide pairs exceed 1 point. Empty match/nonmatch groups have no metric row and must not be mistaken for zero error.
- `results/study/summary.csv`: mean metrics and 95% item-draw t intervals, undefined counts, actual target/history/item counts. Deterministic anchor intervals do not measure source-fit uncertainty.
- `results/study/paired_contrasts.csv`: benchmark (including `MACRO13`)/scenario/budget/metric/method/reference, mean method-minus-reference metric difference, t interval and 5000 paired-draw percentile-bootstrap sensitivity endpoints, n_valid and n_undefined. Negative error differences favor method; positive rank differences favor method. Intervals address Monte Carlo uncertainty in expected performance across uniform draws, conditional on fixed historical and target pools, not future-draw/model prediction intervals.
- `results/study/macro_repeats.csv`: equal-weight per-repeat finite-benchmark mean with metric-specific number of defined benchmarks. Undefined correlation counts remain explicit; no pooled cross-benchmark model correlation is used.
- `results/study/robustness_contrasts.csv`: source25/source50 minus main, or family-excluded minus ordinary-history reference, using identical target cohorts, methods, budgets and item draws, with the same interval fields. Source100 reuses main k30; family_reference reuses main predictions restricted to the eligible immutable target cohort. These are not extra independent draws or refits.
- `results/study/response_collisions.csv`: target/model-pattern multiplicity and source-match status per scenario, derived only after predictions. `response_patterns` metrics give one unit to each identical target response vector (predictions are identical within those patterns). These diagnostic populations do not replace the primary distinct-identity/opaque-row population.
- `results/study/prediction_manifest.json`, `scoring_provenance.json`: immutable prediction hashes and scoring/freeze provenance.

Main methods: source prior, random mean, source difference, ridge, paper/code AIPW, unbounded/clipped crossfit, crossfit uncorrected own-alpha/matched-alpha, full-fit ridge imputation, correctness-anchor mean/ridge, MAP-MIRT random p/gp and IRT-anchor mean/p/gp. All13 x k10/30/100 x20 draws. Robustness includes the uniform methods and random MAP-MIRT at k30, all13 source-size and eligible OpenLLM proxy exclusion. The six eligible proxy exclusions and ARC ineligibility are metadata-only decisions, not performance choices.

`results/study/design_diagnostics.csv` and `per_target_design_diagnostics.parquet` decompose finite-20-draw MSE into variance (ddof=0) plus squared mean error, in squared percentage points. This is a descriptive empirical decomposition, not an unbiased estimate of squared design bias from only 20 draws. The identity is checked at scoring. Anchor variation across copied deterministic outputs is zero by construction.

Prospective scoring amendment, 2026-11-05 (before any real target prediction): macro paired contrasts now average per-benchmark method-minus-reference differences on common defined benchmark cells, rather than subtracting separate method-specific macro means. This matters when a rank correlation is undefined for only one method. `paired_macro_repeats.csv` retains each budget/repeat/metric/method/reference difference and its `n_benchmarks`. `paired_contrasts.csv` MACRO13 rows add `n_benchmarks_min`, `n_benchmarks_max` and `n_undefined_benchmark_draws`; per-benchmark rows leave those macro-only columns empty. An absent rank is never replaced with zero. A macro rank contrast with fewer than13 paired defined benchmarks is a summary of the stated defined subset and cannot be described as a complete13-benchmark contrast. The separate per-method `macro_repeats.csv` still retains its own defined-benchmark counts. MAE/RMSE finite predictions have all13. The archived old manifests and exact changed hashes are in `notes/freeze_amendments/2026-11-05_macro_pairing.json`; estimator/tuning/splits/draws are unchanged.

The review-requested fixed-alpha formula diagnostic is separate from the18 primary methods. `aipw_formula_predictions.parquet` saves each immutable code/random-mean prediction with deterministic paper-alpha10 reconstruction and retrospectively scored truth; `aipw_formula_repeats.csv` supplies code/paper10 metrics and maximum absolute prediction difference per cell; `aipw_formula_contrasts.csv` supplies same-alpha code-minus-paper10 paired t/bootstrap intervals. Its exact generator is `diagnostics/aipw_formula_diagnostic.py`, after successful primary scoring. Primary `aipw_paper` remains independently tuned and must not be mislabeled alpha10. `diagnostics/audit_scoring.py` independently checks all saved truth, raw baselines, exact clipping and primary error metrics; its result is `scoring_integrity.csv`. `diagnostics/summarize_results.py` generates `evidence_numbers.json` and `robustness_macro.csv`, retaining input hashes, common-defined counts and conditional uncertainty. These additions change no primary fits, observations or selected hyperparameters.

Numerical-rank correction after initial scoring: final `metrics.*`, `summary.csv`, contrasts and macro files are generated by `diagnostics/score_canonical.py` using `diagnostics/rank_metrics.py`. Only rank/tie quantities use12-decimal canonical truth/predictions and true pair-gap subtraction; MAE/RMSE/bias/tail/out-of-range use the raw stored values. `scoring_provenance.json` identifies this correction and hashes both generator files; original raw-float rank outputs/provenance are preserved under `original_raw_ties/`. Their historical intervals must not be used as final ranking evidence. `rank_precision_repeats.parquet` and `rank_precision_sensitivity.csv` record all-cell10/12/14-decimal sensitivity and the constant-shift invariant. The post-scoring dated record is separate from prospective freeze amendments and no prediction or hyperparameter is changed.

The operational12-decimal tie convention restores tested exact-count baseline/weighted-anchor ties but does not prove mathematical ties for arbitrary learned predictions; the true-score grid is not a minimum learned-prediction gap. `rank_precision_macro_repeats.csv`, `rank_precision_macro_contrasts.csv` and `rank_precision_conclusion_sensitivity.csv` quantify complete main-pool contrast/endpoint sensitivity. `aipw_formula_integrity.json` checks the reconstructed diagnostic against55,520 actual target predictions from840 preselected-alpha10 primary cells (maximum absolute difference4.44e-16), in addition to the disposable direct-fit check.

# Stage reflection and plan deviations

## Before production
The pre-outcome analysis plan is `todos.md`. A numerical pilot used only Arena, 10 bootstrap and 3 random replicates. Planner reflection identified that a single-cohort pilot did not exercise ablations, and that strict floor incidence caps can prohibit NBA edits. Consequently an all-cohort smoke run was added before production, with 10 bootstrap/3 random replicates. It is not reported as confirmatory evidence.

Additional controls fixed before production: count-matched uniform non-tie random edits; a cap-feasible random-order greedy sampler (NOT uniform over feasible subsets); exact integer optimization of the linear-influence surrogate under caps (NOT nonlinear robustness certification); whole-question edits for MT; author-only/expert-only human and exclusion of GPT4 'tie (inconsistent)' sensitivity. These controls address distinct semantics and constraints, rather than selecting specifications on favorable outcomes. They are supplementary/exploratory additions to the locked primary comparison.

MILP integer aggregation uses identical `(participant a, participant b, outcome)` classes. Each class has constant linear score. scipy.optimize.milp solves integer counts with observed class-capacity bounds, endpoint incidence limits and global budget, time limit60s, relative gap1e-9. Solved labels/status/gap are recorded. Exact nonlinear refits are witnesses only. This is a baseline to diagnose greedy underfill, not a new generic optimization method.

Changes in interpretation: matched rows are equal-weight aggregate cells, not individual votes; overlapping full/matched MT sets are not independent replicates. The fixed pair is retained under every ablation, and altered-specification base margin and winner are reported; a reversed base pair is not attributed to editing. 'Winner changed' means incidental winner change under an original-runner-up-targeted edit, not exhaustive optimization against every challenger. Original bootstrap SD is only a reference scale, not a post-edit confidence interval or multiplicity-adjusted inferential test.

## Smoke gate and implementation failure
First witness replay failed because saved row IDs had NumPy object dtype, which cannot be read safely with allow_pickle=False. Fixed the underlying data ID array to Unicode; did not enable pickle. Re-ran all-cohort and supplementary smoke runs, preserving the failure in this log. 338 deterministic witnesses replayed by cold-start fits with maximum margin discrepancy7.32e-9; 1005 logged fits finite with maximum gradient1.00e-8. Canonical a<b invariant now enforced at ComparisonData boundary; nonfinite solver states rejected. Added regression tests for canonical orientation, safe witness loading, brute-force toy MILP and adaptive uniqueness/replay.

## Post-outcome exploratory addition
After inspecting the production primary endpoints, added `src/bootstrap_sensitivity.py`:300 end-to-end cluster bootstrap replicates at1% only, with original full-data target pair held fixed. Within each replicate, resample the same prompt/question/game cluster draws as the original bootstrap (seed20261104+100000+rep), expand rows with cluster multiplicity, refit, recompute influence ordering, N, degrees, floor budgets and strict caps, and refit each newly selected set. Matched panels share80 question IDs and draws. Resulting percentile intervals describe the resampled selection-and-refitting procedure, not one fixed witness and not post-selection-corrected coverage. Baseline pairs can already be reversed in a resample. This analysis is explicitly exploratory and does not replace locked results. Its7208 fit records are audited separately and then reconciled in validation.json with production7832 plus supplementary3253 (11085 before this addition). No replicate increase to change an interval endpoint.

## Limits/deferred branches
No matched-exposure Arena subsampling study: optional, not required for main endpoints; no equal-size causal comparison claimed. No unrestricted novelty search because it would risk prohibited material. No paid APIs/GPU. The whole-question sensitivity and source stratification are included in supplementary scripts. No attempt to reproduce published numbers exactly: different pinned snapshot, tie convention, ridge and perturbation estimand; the verified baseline is the explicitly stated objective with analytical/unit/finite-difference tests.

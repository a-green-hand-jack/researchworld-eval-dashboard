## Things a reader must know
* All ground truth is exact up to Monte-Carlo error of the evaluation grid: 300 x-points per decile slab x 30 y-draws; the noise floor of a
  slab-average conditional coverage is about 0.005 (see `A1_summary.log`; an oracle-like score reaches ~0.86-0.89 for the worst of 10 slabs because
  the calibration set itself is a finite sample, n_cal = 500, so "worst true slab" < 0.9 is expected even for a perfect method).
* Volume ratios (`log_vol_ratio`, log10 of region volume relative to the oracle HPD region) are not available for K=10: the oracle region has
  Monte-Carlo fraction below 20/M in the 1e5 uniform simplex sample. Coverage metrics are available for K=10.
* A first A1 grid with 30 evaluation x-points per slab, a first B-synth run without the minimum-cell rule, and a first A2 set without recorded
  n_te/alpha were discarded and rerun; none of their numbers is used (`REPRODUCE.md`).
* `git_rev` in the raw CSVs is the parent commit of the code that ran (the working tree held uncommitted edits at launch; the edits are
  in the delivered code and only add options / methods).
* Results are for known-truth synthetic DGPs, a fixed CLR-OLS mean model and one CNN; they are not claims about real compositional data.

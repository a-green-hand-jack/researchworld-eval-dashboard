# 最终研究报告：模型规模与小型算法任务的延迟泛化

## 1. 目标与结论

提出并检验了一个**自行构造、不是归属于既有论文的解释**：增加宽度主要加速训练集拟合，而规则泛化仍由近似独立的正则化时钟控制，因此相对延迟应扩大。

结果是**部分反驳、部分依条件相容**：
- 在冻结的32→128宽度对比中，增宽更明显地加速了可观测的留出集阈值端点，而非训练拟合；预先指定的方向预测W被反驳。
- 宽度128的首次合格泛化时刻与逆权重衰减时钟相容，但这不等于稳定获得规则：较小衰减下7/8次运行在训练末尾回落到99%以下。
- 宽度32的时钟分析大量删失，结论是无法判断，而非支持时钟相同。

这是一项限定于平方激活网络、模加法和AdamW配方的实证结果；不是普遍规模定律，不是模型规模影响grokking的首次发现，也不声称推翻了所引用论文的理论。

## 2. 实验计划与执行

- 13次独立探索/验证运行：种子900—903，保留最初30%训练比例未泛化的失败设置，之后选择70%配方。
- 在确认种子首次运行之前冻结`protocol.json`和240个任务的`confirm_jobs.json`。
- 确认阶段每个设置使用8个配对种子0—7，扫描6种主宽度，并完成衰减、冻结特征、打乱标签、输出归一化、第二模数、减法、数据比例和宽度1024容量对照。
- 另做1次技术重复，验证401行轨迹所有非计时数值逐项完全一致；不算新增统计种子。
- 总训练运行254次；论文统计主体为冻结的240次。没有选择性延长训练、丢弃种子、调整慢速组或只保留成功运行。

## 3. 设置与可复现性

主任务穷举p=31的961个有序输入对，标签为`(a+b)%31`。每个种子随机选672对训练，其余289对留出；没有第三方数据下载或版本快照。数据生成由代码哈希固定。

模型为
`f_c(a,b)=h^(-1/2) Σ_j R_jc(A_aj+B_bj)^2`，参数量3ph。

- 主宽度：8、16、32、64、128、256；另有1024宽度的训练/冻结对照。
- 全批AdamW，学习率0.01，基准衰减0.1，betas=(0.9,0.98)，固定20,000次更新；没有warmup和早停。
- 每50次更新评估；连续3次达到99%定义首次合格事件，最后可确认起点为19,900。未发生事件是右删失，不是虚构的真实时间。
- 计算仅CPU。确认训练与诊断合计实测约**3.43进程CPU小时**，8工作进程的启动器实测约**57.5分钟**；不把共享主机的并行耗时当作固定算力比较。
- Python3.11.15、CPU PyTorch2.15.0+cpu及全部依赖见`requirements.txt`和环境记录。

## 4. 基线、对照和不确定性

同一种子在各宽度/对应干预中使用相同拆分；初始化与数据拆分共同变化，不能分别估计两种方差来源。单元测试验证数据、梯度、投影、AdamW衰减、归一化及事件逻辑。

统计使用8个种子簇的10,000次配对bootstrap（95%区间不做同时性声明）；三个预先指定主检验使用256种符号翻转枚举和Holm校正。符号翻转有零假设下的对称/可交换性前提，不是无条件的随机化推断。事件发生比例同时提供Wilson区间。

冻结特征和打乱标签检验训练拟合是否足以泛化；原始均值归一化及初始函数匹配归一化检验配方敏感性。后者不匹配AdamW坐标动力学。已知模规则上的全网格投影仅为诊断，不参与训练、选模或主准确率计算。

## 5. 结果

### 主规模扫描

| 隐藏宽度 | 参数量 | 训练99%事件 | 留出99%事件 | 末尾平均留出准确率 |
|---:|---:|---:|---:|---:|
| 8 | 744 | 8/8 | 0/8 | 43.3% |
| 16 | 1,488 | 8/8 | 0/8 | 73.5% |
| 32 | 2,976 | 8/8 | 2/8 | 98.6% |
| 64 | 5,952 | 8/8 | 8/8 | 100.0% |
| 128 | 11,904 | 8/8 | 8/8 | 100.0% |
| 256 | 23,808 | 8/8 | 8/8 | 100.0% |

完整区间与每种子结果见`analysis/groups.csv`、论文表2和图1。8/8不代表未来种子必然成功；宽度128事件概率的Wilson95%区间约67.6%—100%。

主宽度交互为**D=1.57834，95%区间[0.99379,2.01636]，Holm p=0.0234375**，与W预测的负方向相反。指数化相对乘数4.85[2.70,7.51]针对的是**加50、并在19,900截断后的几何端点**，不是未删失真实泛化时间的加速倍数。95%和90%阈值下方向仍为正，但效应分别减弱为0.601和0.225，说明幅度明显依赖阈值。宽度32的8/8次运行都达到95%，不能将其大部分99%非事件说成完全没有规则学习。

**宽度区间还会改变相对关系。** 在64→256这个两端均8/8观察到泛化的范围内，事后探索的同一交互为**D=-0.172，未校正95%区间[-0.269,-0.083]**，方向与主对比相反：绝对泛化起点更早，但拟合相对加速更多。该结果仍受加50和早期时间网格影响，不是连续学习率定律。论文附录列出全部相邻宽度对比，不把这个事后范围当作新增确认性发现，也不拿它挽救失败的32→128预测。

### 时钟与失效情形

- 宽度128：半/双基准衰减在公共时钟窗口均有8/8个事件；已观测原始起点的几何时钟时间比为**1.005[0.964,1.048]**，落在预先规定的25%相容范围内。它是次要相容性结果，不是正式证成等价。
- 但半衰减组末尾平均准确率仅**95.7%**、最低**88.2%**；7/8低于99%，且0/8达到“从该起点到观察结束一直满足99%”的事后稳定性端点。不能把首次短窗口成功当成永久获得规则。
- 宽度32：半/双衰减公共时钟事件为0/8和1/8；双衰减在完整更新预算内有4/8原生事件。窗口和持续性定义不同，不能混用这些计数。
- 训练比例降到30%时，宽度32、128各8/8拟合训练，但均0/8达到留出阈值；更宽并不保证在有限预算内泛化。

### 特征、表示与归一化

- 宽度128冻结特征仍8/8拟合训练，却0/8达到留出阈值。宽度1024的训练与冻结两组均能拟合，但留出准确率分别为100.0%与约0.1%，说明不能用训练容量充分直接推出泛化。
- 两种归一化压力测试中，主交互方向未反转，但幅度改变；不能把配方敏感性写成尺度不变性。
- 用解析权重构造的8单元余弦分类器在p=23、31、59的全部输入上均100%正确。这只是**存在性检查，未经过训练**；它排除了纯粹“窄网络无法表示规则”的解释，不证明AdamW能从随机初始化找到它。

## 6. 分析、局限与交付

最稳妥结论是：该配方中，增宽可以使近满分泛化更易在有限预算内出现，并缩短对应可观测延迟；“主要加速记忆”的简单解释不足。首次起点的近似时钟相容不能代替保留率或完整训练动力学。

局限包括：单一网络家族与优化配方、8个联合随机簇、小模数、两路拆分、阈值和时间网格敏感性、有限预算删失，以及非因果的投影诊断。减法与加法同构，不能当作广泛跨任务验证。没有Transformer、大语言模型或真实数据实验证据。

**新颖性仍有限。** 独立AI自审给出主会投稿需要重大改进的判断；可复现性高不等于已建立主会级贡献。最终论文作为受限实证研究完整交付，不宣称录用就绪、实际投稿或经人类科学审查。自审及逐项处理见`self_review.md`、`review_response.md`。

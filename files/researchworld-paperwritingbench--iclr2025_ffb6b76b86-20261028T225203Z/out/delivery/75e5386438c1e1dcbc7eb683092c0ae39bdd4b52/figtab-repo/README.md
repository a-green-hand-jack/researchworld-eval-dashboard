# figtab-repo: presentation

Figures and tables of the paper. Start at `exhibits/README.md`.

- `data/`: log tables transcribed to CSV (provenance in `data/README.md`)
- `scripts/make_tables.py`: tables → `exhibits/tables.tex`, `exhibits/table_fim_fallback.tex`
- `exhibits/`: LaTeX blocks to paste into `template.tex`, the integration guide, and the claim map
- `scripts/build_preview.sh` → `preview/preview.pdf`: exhibits compiled in the ICLR 2025 style

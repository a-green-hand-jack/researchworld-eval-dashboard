# Mathematical checks for report owner

These are analysis notes, not a claim of a new conformal theorem.

Condition on training data. For any measurable score S(x,y) fixed before calibration and n exchangeable calibration/test observations, let k=ceil((n+1)(1-alpha)) and q the kth calibration order statistic, using infinity if k>n. The test rank among n+1 scores is uniform when scores are continuous, so P(S_test<=q)=k/(n+1) (or 1 for infinity). Ties give the usual conservative bound without randomization. This is marginal over the calibration sample and test point, not a guarantee conditional on the realized calibration sample or on every x. At n=99 and alpha=.1 the continuous-score coverage is exactly .9; at n=499 it is also .9.

For iid continuous scores with cdf F, F(q) has Beta(k,n+1-k) distribution. Its variance is k*(n+1-k)/((n+1)^2*(n+2)), explaining variation across independently calibrated runs. This statement is conditional on the trained score and assumes iid calibration, stronger than arbitrary finite exchangeability. An independent finite test adds binomial sampling error. The experiment's replication intervals include both. Reusing one calibration set and treating thousands of test points as independent complete replications would miss calibration uncertainty.

Bonferroni: calibrating each absolute coordinate residual at alpha/K gives P(any coordinate misses)<=sum_j P(coordinate j misses)<=alpha. Calibrating each coordinate at alpha has only the weak lower bound 1-K*alpha, truncated at zero; the dependence induced by the simplex does not generally restore simultaneous 1-alpha coverage.

Aitchison score is ||clr(y)-clr(p)||_2 on positive compositions. The Euclidean norm of clr differences equals the norm in any orthonormal ilr basis because the difference lies in the sum-zero subspace. Thus an orthonormal ilr implementation would duplicate this region, not constitute an independent baseline. Multiplicative perturbation by a common positive composition adds the same clr vector and leaves the score invariant. The check script verifies this identity numerically.

Group/Mondrian: calibrate a separate score threshold within each predeclared observed group. Conditional on calibration count n_g, the rank argument gives coverage at least 1-alpha within that group. If n_g is too small, return the whole simplex. Shift in group frequencies preserves this result only when within-group score laws are preserved. The proposed shift has exactly that property. A learned locally scaled score alone does not have such a group guarantee.

For a fixed thresholded global region, if group-conditional coverages are c0,c1, changing group-1 probability from pi to pi' changes marginal coverage from (1-pi)c0+pi*c1 to (1-pi')c0+pi'*c1, i.e. delta=(pi'-pi)*(c1-c0). This decomposition explains the controlled shift; it is not a result about arbitrary covariate shift.

For K=3 the simplex with vertices e1,e2,e3 has Euclidean area sqrt(3)/2. A centered Euclidean ball of radius r smaller than the inradius lies entirely within it and cuts a disk of area pi*r^2, so its area fraction is 2*pi*r^2/sqrt(3). The numerical volume estimator is checked against that expression. Radius values across raw and clr spaces have incompatible units and should not be ranked as set efficiency. All cross-geometry efficiency claims will use the same uniform-simplex area reference at K=3.

Censored-zero sensitivity will target a deterministic strictly positive transform T_epsilon(Y), not literal structural zeros. Applying T to training/calibration/test responses preserves exchangeability for the transformed estimand. It does not establish coverage of the original boundary-valued Y by a clr ball (which excludes the boundary). Such a result must not be reported as a zero-safe guarantee.

## Oracle weighting source verification

On 2026-11-02 experiment-repo directly downloaded the permitted starter source https://arxiv.org/pdf/1904.06019 (PDF SHA256 d80dba944a136e075bbfe281009152ce42041e0a455f68f73684ace83cfc3fed) and read Section 2.1/Corollary 1 and Section 2.2, equations (7)-(10), pp. 3-5. No broad search, citation-following or prohibited study was accessed. The source permits any fixed measurable score and covariate shift with preserved Y|X and known density ratio. Our weight implementation normalizes implicitly: find the first calibration score whose cumulative unnormalized calibration weight is at least (1-alpha)*(sum calibration weights + test-point weight); if no finite calibration score reaches that mass, return infinity. This is exactly the quantile with test atom at infinity from (7)/(10), applied to a fixed training-fitted clr norm. The ratio is .8/.2=4 for group1 and .2/.8=.25 for group0. This is an oracle known-ratio baseline, not fitted-density-ratio inference and not a group guarantee.

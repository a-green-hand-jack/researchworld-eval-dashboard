# Table generation

`pilot_call_costs.tex` contains 18 rows of raw CPU timings from the initial
analysis pilot, in milliseconds at the requested 128 and 2048 coalition-work
settings. It does not report main-study reliability or a final cost budget.

Generator, input provenance, dependencies, include command and reproduction
instructions are in `figures/README.md`. Run
`python3 figures/generate_pilot_accounting.py --preview` from the delivery root.
`pilot_call_costs.manifest.json` maps every numerical row to the original pilot
JSONL lines and rounding conversion; the C1/C2 source IDs are retained there.
The PDF/PNG previews compile the actual table in a 5.5-inch text block. The
paper owner integrates the `.tex` source with the official template.

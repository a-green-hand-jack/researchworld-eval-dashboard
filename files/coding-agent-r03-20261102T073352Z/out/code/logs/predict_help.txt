usage: predict.py [-h] --history HISTORY --budget BUDGET --alpha ALPHA
                  [--scores SCORES] --output OUTPUT

Offline query recommendation and reconstruction for a user's new model.
Input/history scores must use the same original units and task definitions.
Alpha is explicit: use validation on your own history before deployment.

options:
  -h, --help         show this help message and exit
  --history HISTORY  CSV with model ID as first column and task columns
  --budget BUDGET
  --alpha ALPHA      Shrinkage selected on historical validation models
  --scores SCORES    JSON mapping recommended task names to actual new-model
                     scores
  --output OUTPUT

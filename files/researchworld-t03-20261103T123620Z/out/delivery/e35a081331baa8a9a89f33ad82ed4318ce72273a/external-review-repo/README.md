# External review

This repository holds the outside-reader review of released versions of the SHAP repeated-run reliability study.

- Research objective: issue #1; frozen material under `/initial-state/inputs/0`.
- Commitment: issue #2, assigned to `external-review-repo`.
- [Review protocol](review-protocol.md): standards applied to delivered versions.
- [Version ledger](version-ledger.md): artifacts read and review disposition.

Actionable findings are separate issues in this repository, one problem per issue and with the version identified. The external review does not grant or withhold the independent internal approval required for a release.

\subsection*{AI use statement}
This study, including the literature search, the analysis code, the experiments, the figures and tables, and the
text of this paper, was carried out by a set of cooperating generative-AI agents (Claude models) working in separate
roles (planning, analysis, presentation, writing, review) without a human author writing or editing the content (the operators of the pipeline should confirm this before submission). The agents
were used for research ideas and problem formulation, for writing and testing all code, for running all
computations, and for drafting and revising all text. No generative AI was used to produce data: every number in the
paper was computed by the accompanying code from the public leaderboard snapshots listed in the reproduction
instructions. Code was checked by unit tests against brute-force solutions and by independent review agents; every
cited reference was looked up in a bibliographic source by an agent, but not independently verified by a human.
The responsibility for the final content, including text, claims and artifacts produced with the aid of
generative AI, rests with the operators of the pipeline that produced it.

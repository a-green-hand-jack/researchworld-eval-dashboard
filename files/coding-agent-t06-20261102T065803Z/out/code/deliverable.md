# Deliverable checklist

This file maps the requested deliverables to the completed artifact.

1. **Research paper, PDF and LaTeX**: `paper/main.pdf`, `paper/main.tex`, `paper/references.bib`, generated `paper/numbers.tex`, `paper/tables/`, `paper/figures/`, and the unmodified official `paper/neurips_2026.sty`. The official NeurIPS 2026 template, main-track mode, nine-page main-text limit, is used. The completed 16-question official checklist is `paper/checklist_filled.tex`; full original questions and guidelines are retained. Exact page/check outcomes are in `results/pdf_check.json`.
2. **All code and reproduction instructions**: `src/`, `Makefile`, `requirements.txt`, and `README.md`. One command, `make reproduce`, regenerates the measurements, displays, and PDF. Sources, versions, licenses, and full SHA-256 checksums are recorded in `data/manifest.json`; random seeds, resampling, runtime estimates, and per-display provenance are in the README and paper.
3. **Evidence and uncertainty**: four real evaluation designs; exact or explicitly bounded edit budgets; random noise and deletion controls; matched schedules; regularization/tie/home-effect controls; cluster bootstrap and Monte Carlo uncertainty; all generated measurements and witnesses in `results/`.
4. **Honest reporting and limits**: all empirical displays derive from actual CPU runs; synthetic fixtures only verify code and proofs. Modeling dependence, unresolved order, heuristic bounds, dataset limitations, and LLM assistance are disclosed. Preliminary runs, failures, and approaches not pursued are recorded in `logs/research_log.md`.
5. **Independent research boundary**: no general searches or attempts to identify the excluded work. Direct access was limited to five allowed starting references, named data snapshots/cards, official NeurIPS formatting/ethics pages, and package installation. No known prohibited material was encountered. See `logs/access_log.md`.
6. **Submission bundle**: `submission.zip`, generated by `make package`, contains the paper/source, code, results, documentation, relevant logs, and a checksum manifest. Raw datasets stay in `data/raw/` and are excluded from the bundle, as are `.venv/` and downloaded literature PDFs.

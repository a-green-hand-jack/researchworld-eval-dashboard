# Data contract: what the figure and table scripts read

Inputs are read from `results/` of the delivery root (`paper-repo` `dev`), owned by `experiment-repo`; outputs go to `figures/figN_<name>.pdf` and `tables/tableN_<name>.tex` (booktabs fragments for `\input`), each ending with a one-line source note naming the `results/` file it is made from. Scripts here take `--results DIR --out DIR`.

`figtab-repo` draws only from result files written by `experiment-repo`'s scripts
(never typed numbers, never synthetic ones). This file is the schema I read; if
analysis would rather write another shape, say so in the request and I adapt.
One tidy file per table, CSV or Parquet, one row per observation, plus a sidecar
`<name>.meta.json` with `script`, `git_commit`, `snapshot` (data sha/version), `seed`,
`created`. Missing values are empty, never 0. All depth/boost values in points of the
board's own scale unless a `unit` column says otherwise.

Common key columns: `board` (`helm_mmlu`, `ollb_bench`, `ollb_sub`), `m`, `rule`
(`mean, median, min, borda, winrate, plurality, copeland`; z-mean / p-mean as
`zmean`, `pmean`), `incumbent` (`own` | `common`), `target`, `B` (boost cap, points).

| file | one row per | columns beyond the keys | feeds |
|---|---|---|---|
| `frontier` | board, target, rule, incumbent, B, k | `depth` (least total boost with <= k tasks; empty if infeasible), `feasible` | Fig. 1, Fig. 2 |
| `price` | board, target, rule, incumbent, unit, B | `k_star` (min breadth), `depth_star` (depth at that breadth or least depth), `feasible`, `B_star` (smallest feasible per-task cap), `init_rank`, `gap` (rule-specific), `family`, `incumbent_id`, `targeting_mult`, `solver` (`exact`/`milp`), `opt_gap` | Fig. 2, 4, 5a, Table 3 |
| `m_effect` | regime (`helm_subset`, `ollb_free`, `ollb_bundled`), m, draw, target, rule, B_sigma | `k_frac`, `depth_per_task`, `B_star_sigma`, `feasible` | Fig. 3 |
| `m_effect_fit` | regime, rule pair, statistic | `slope`, `ci_lo`, `ci_hi`, `n_draws`, `n_clusters` (R4) | Fig. 3 annotation, Table 3 |
| `paired` | board, rule_a, rule_b, incumbent, B (or B_sigma) | `share_a_cheaper`, `mean_log_ratio`, `ci_lo`, `ci_hi`, `n_targets`, `n_clusters`, `ci_method` | Fig. 4 |
| `rule_order` | board, incumbent, B | `kendall_tau_mean`, `ci_lo`, `ci_hi` | Fig. 4 caption |
| `predictors` | fit_board, test_board, rule, model (`gap`, `gap+disp+corr`, `rank`) | `r2_heldout`, `ci_lo`, `ci_hi` | Fig. 5a |
| `calibration` | (child, base, task) | `gain`, `parent_params`, `size_bucket`, `base_family`, `n_children_base` | Fig. 5b |
| `verdicts` | R in R1..R5, board, rule(s) | `statistic`, `value`, `ci_lo`, `ci_hi`, `threshold`, `verdict` (`supported`/`partial`/`failed`) | Table 3 |
| `units` | board, rule, unit (`points`, `sigma`, `headroom`, `convex1`, `convex2`) | median `k_frac`, median depth in that unit, rank of rule | Table 3 |
| `boards` | board | `snapshot`, `sha`, `date`, `m`, `N`, `noise_source`, `n_targets`, `exclusions` | Table 2 |
| `solver_check` | rule, instance class | `n_instances`, `n_agree`, `max_size` | Table 1, appendix |

The paper's numbers are these files' numbers: tables are generated by
`figtab/make_table*.py` from them, and the text should quote from the same files.

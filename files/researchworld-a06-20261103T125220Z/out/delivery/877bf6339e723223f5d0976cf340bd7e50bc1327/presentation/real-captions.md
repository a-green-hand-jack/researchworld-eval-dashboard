## real-reporting.tex — primary numerical reporting / decision comparison

**Reporting and uncertainty choices change the observed improvement decision.** Winner10 is selected on256 questions from K4; audit512 estimates accuracy on11776 questions outside that full reservoir. First three estimates/intervals are accuracy percentages; the final row is paired winner-minus-default accuracy in percentage points. Reused CP is the ordinary nominal95% binomial comparator, without an exact finite-benchmark/runtime guarantee. Exact search retains the reused point estimate and uses the transformed simultaneous finite-population interval. Disjoint audit and paired gain use exact finite-population intervals. These exact intervals allocate error .025 per possible B/C design and the exported within-design multiplicity; their at-least95% guarantee is unconditional after runtime choice, separately per endpoint family. The first three improvement entries use the exported conservative lower-winner-above-upper-default nonoverlap rule; the paired row instead asks whether its contrast lower bound is positive. Audit-supported improvement here is not a false-positive reuse decision. Calls (s) denotes logical uncached calls for selected accuracy alone; Calls (p) denotes calls for the improvement comparison, including a differing winner/default pair on audit. Reuse/search intervals cost1024 for either purpose. Disjoint auditing costs1536 for selected accuracy alone and2048 for the paired comparison. The paired gain has no selected-accuracy-only entry (dash). Actual generation cost is6144 main answers,3072 analyzed and3072 retained but excluded, plus114 validation calls and setup/failure overhead.

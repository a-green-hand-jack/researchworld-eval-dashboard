# Initial audit (before experiments)
Pinned raw files downloaded; source hashes verified against supplied hashes where available. `results/provenance.json` records all four actual hashes and URLs.

Arena: 57,477 unique battle IDs, 64 models, no self-comparisons. Coverage ranges from 100 to 7,387 incident comparisons per model. Use all 64 in the primary descriptive analysis; do not silently remove low-coverage entrants. MT-Bench: human file has 3,355 judgments, 80 questions, six models, both turns, variable replication per question–pair–turn; judge IDs include `expert_*` and `author_*`. GPT-4 has 2,400 judgments, all 80 × 15 × 2 cells, including 380 labels `tie (inconsistent)`. Treat both tie types as half-wins in primary fits, separately audit and exclude inconsistent labels in sensitivity. Human versus GPT-4 comparison needs one human judgment sampled per observed common question–pair–turn cell to remove replication differences, with question-cluster uncertainty. Do not call all human observations expert-only.

NBA file has two rows per game. Select `_iscopy == 0`, NBA league, regular season, and separate season end years 2006–2015. The 2012 lockout season has 990 games, 2013 has 1,229, others 1,230. Team identities are season-specific; never pool decades into a static-strength ranking. Home advantage and temporal dependence are potential model misspecifications.

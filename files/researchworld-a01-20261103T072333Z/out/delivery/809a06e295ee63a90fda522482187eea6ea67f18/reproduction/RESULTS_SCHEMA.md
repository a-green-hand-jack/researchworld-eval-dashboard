# Numerical result schema and cohort selection

`attacks_*.csv` has one row per (dataset, model evaluation, rule, ceiling, alpha, strict). `k` is an integer exact minimum task count when feasible, and null for certified infeasibility; status distinguishes analytic/exhaustive/MILP success and computation failures. `selected_tasks` is a JSON witness. `baseline_rank` uses that row's own rule. Existing winners have k=0.

Primary common-challenger designs are defined once using the union of alpha=1, unit-ceiling, co-first incumbents across all five rules. Keep the resulting model identities fixed across gains/rules and strict-first sensitivity. Separate normalized/raw/unique-model datasets have separate score/rival designs. Use `challenger_budget_curves.csv` (n includes infeasible targets), `challenger_summary.csv` and `challenger_paired_rules.csv`. Finite paired differences condition on joint reachability; `both_reachable`, `only_a_reachable`, `only_b_reachable` and `n_challengers` identify the conditioning. Difference is rule_a minus rule_b, in selected tasks. Full-cohort `budget_curves.csv`, `summary.csv` and `paired_rules.csv` include incumbents and are secondary.

Random baseline:

- `random_requested` indicates whether the baseline was part of that run. `random_baseline_method` is `mc_permutations` (HELM), `exact_subsets` (six-task feasible), `exact_infeasible` (known censoring constant) or `not_requested`.
- `random_expected_censored_k` estimates E[min(T,n_tasks+1)] for uniform random task ordering, where T is the first-success task count and infinite if unreachable. Provably infeasible targets store exactly n_tasks+1; it is a censoring value, not an observed feasible investment. The aggregate therefore uses the full requested cohort.
- `random_success_at_k` is the probability at the target's own optimal k. It is undefined on infeasible targets and stays null there. `random_reps` counts sampled permutations (zero for exact or unrequested results).
- Summary `random_expected_censored_k_n` is the number of nonnull stopping expectations; it equals cohort n when requested and zero when unrequested. `random_success_at_optimum_reachable` and `random_success_at_optimum_n` explicitly give the separate reachable-only probability and its denominator. The old ambiguous summary name `random_success_at_optimum` is removed.
- `random_baseline_uncertainty.csv` contains Wilson intervals for individual Monte Carlo success probabilities. `random_baseline_aggregate_uncertainty.csv` explicitly labels `cohort` as `full_cohort` or `common_challengers`; filter the intended cohort. It gives full-cohort stopping means and conservative Hoeffding MC intervals, counting infeasible expectations as known constants. `n_targets`, `n_expectation_targets`, `n_reachable_targets`, `n_infeasible_exact`, `n_sampled_targets`, `reps_per_sampled_target` and `n_success_at_optimum_targets` expose all denominators. Exact six-task outputs have zero MC interval width.

Finite-cohort percentages and task-composition ranges do not measure sampling uncertainty of model scores or causal training gains. Task bootstrap rows represent task-composition sensitivity; leave-one-task-out rows enumerate the six omission designs. Per-record `seconds` and reproduction runtime evidence are hardware-dependent measured timings.

# Figure and table release audit

## Result: PASSED_WITH_WARNINGS

- All6 intended numerical figure bundles were generated by `plot.py` as300dpi PNG plus vector PDF from actual240-run analysis/CSV records.
- Data fields, scales, axes, labels, series/category order, mean/error bars and legends match `figure-spec.md`. No smoothing, fitted scale law, extrapolated event or illustrative fake result.
- Curve bands are seed minima--maxima; uncertainty error bars are correctly distinguished from those bands. Event-fraction bars use Wilson intervals, other bars use seed-bootstrap intervals.
- Width/decay trajectories now use distinct line styles as well as colors. Width figure has an explicit hollow-triangle non-event legend.
- All six PNGs were inspected; source structure and generated PDF placement were checked. Text overlap/clipping was repaired in the initial width annotation; label spacing and clock legend placement improved. The final LaTeX log has no overfull boxes.
- All tables use booktabs without vertical rules, and every included figure/table has a direct textual reference. Complete controls use compact local table spacing, not changed manuscript margins or official style.
- Continuous CE and absolute energies remain numerical diagnostics, not claimed causal circuit measurements. Projected accuracies are not plotted as ordinary generalization results.
- Compiled input hashes bind all final PDFs/tables to the manuscript; see `verification_report.json`.

## Remaining minor warnings

- Multiple censored seeds share the same administrative cap and can overlap visually with capped mean markers. Individual records, explicit censor symbols, the restricted-onset axis and caption prevent treating the cap as a true event time; no jitter is added to measured y-values.
- The compact normalization legend partially overlays a connecting segment in print; data points and interval endpoints remain visible. Connecting lines between two widths are not fitted scaling laws.
- Small-format figures necessarily compress near-perfect accuracy differences; the exact results, CIs and continuous losses are retained in tables/CSVs. No conclusion rests solely on a saturated accuracy panel.

## Repairs made

1. Corrected initial annotation/label spacing and moved the clock legend away from low-accuracy curves.

3. Repaired generated-table input alignment; reduced only appendix table column padding to remove overflow.
4. Printed small nonzero CE values with significant-digit formatting rather than rounding all of them to0.00.

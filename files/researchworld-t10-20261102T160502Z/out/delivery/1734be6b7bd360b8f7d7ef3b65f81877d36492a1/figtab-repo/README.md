# figtab-repo — figures and tables for the fixed-input CI-width study

Everything here is generated by `figures/src/*.py` from experiment-repo's committed result CSVs (and, for the
calibration curves and Table 1, the `ppi-python` 0.2.3 example data). No number is typed by hand. `figures/make_all.sh`
rebuilds all outputs in under a minute.

Delivered into paper-repo as `figures/` (same layout): PDF (vector, for LaTeX) and PNG (preview) per figure,
`figures/tables/*.tex` (`tabular` using `booktabs`, ready to `\input`) and `*.csv` per table.

| Output | Script | Inputs (experiment-repo `results/`) | Claim it supports |
|---|---|---|---|
| `coverage_N20000`, `coverage_Nx4` | `fig_coverage_width.py` | `summary_real.csv` | validity: empirical coverage vs n, nominal line, Monte-Carlo band, Wilson 95% CIs |
| `coverage_t_*` | `fig_coverage_width.py` | `summary_real.csv` | z vs t critical value at small n (does a finite-sample correction restore coverage) |
| `width_ratio_*` | `fig_coverage_width.py` | `summary_real.csv` | width relative to PPI++ on the same replications (geometric mean, bootstrap 95% CI) |
| `theory_vs_measured` | `fig_theory_vs_measured.py` | `summary_real.csv`, `theory_population.csv` | measured width ratio vs the asymptotic floor prediction |
| `calibration_curves`, `calibration_gap` | `fig_calibration.py` | data via experiment-repo `src/data.py`, `theory_population.csv` | why the gain is small: E[Y given Yhat] vs best affine fit |
| `synthetic_sweep` | `fig_synthetic.py` | `summary_synth.csv`, `theory_check_synth.csv` | gain appears only with nonlinear E[Y given f]; theory check |
| `plankton_shift` | `fig_shift.py` | `summary_real.csv`, `summary_shift.csv` | distribution shift breaks validity |
| `tables/T1_datasets` | `tables.py` | `theory_population.csv` + data | datasets, theta, Var(Y), rho^2, R^2_cal |
| `tables/T2_main_N20000` | `tables.py` | `summary_real.csv` | coverage and width at n = 50, 200, 1000 |
| `tables/T3_native_intervals` | `tables.py` | `full_data_intervals.csv` | example intervals at the datasets' native sizes |
| `tables/T4_regimes_*` | `tables.py` | `summary_real.csv` | cells where the calibrated interval is narrower / indistinguishable / wider |

Conventions: coverage intervals are Wilson (recomputed from `coverage` and `R`); width ratios are paired per replication
against the reference `ppipp_nc` (PPI++, power tuning with unclipped lambda-hat, z-interval; `common.REF`); one colour,
marker and line style per method in every figure (hollow markers: t-quantile versions); colours are the Okabe–Ito
colour-blind-safe palette.

Run: `EXP_DIR=<experiment-repo checkout> PPI_DATA_DIR=<ppi-python data dir> bash figures/make_all.sh`
(`EXP_DIR` defaults to `../code` inside paper-repo, else a sibling `experiment-repo`). Python: numpy, pandas, scipy, matplotlib.

Provenance: each delivery records the experiment-repo revision it was built from in `figures/PROVENANCE.txt`.

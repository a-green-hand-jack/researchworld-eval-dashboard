# Figure specifications

All data come from actual CSV outputs, with no simulated or illustrative points. Scripts: src/plot_figures.py. Output each figure as300dpi PNG and vector PDF in paper/figures. Font9pt, colorblind blue/orange, black random baseline, no smoothing or regression. All numeric axes explicitly linear unless noted.

1. exposure_response: two horizontal panels, six full cohorts in order Arena, MT human, MT GPT4, NBA2013/14/15. Panel(a): actual maximum participant incidence fraction (percent, linear) under 1%-global uncapped and strict-capped flips. Reference1% dotted vertical line. Panel(b): exact margin reduction/original bootstrap SD, symlog x (linthresh1), global and capped dots plus random mean with empirical95% subset quantile whiskers and an x marker at original margin/SD (reversal threshold). No causal design interpretation. Counts/cap underfill in accompanying table.
2. sensitivity_curves:2x3 panels, same six full cohorts; x nominal budget percentage .1,.5,1,2,5,10 log; y edited fixed-pair margin divided by original bootstrap SD linear with separate y range by panel. Static global blue, static capped orange, random mean black and2.5–97.5% subset quantile shading. Zero horizontal reference is a point-order reversal, not significance. No deletion line to avoid swamping curves; deletion results in appendix table.
3. bootstrap_effects: exploratory post-outcome extension. Six full cohorts, recomputed staticglobal/capped1% sensitivity distributions across300 cluster-bootstrap samples. Point at original exact effect, whiskers at percentile effect intervals divided by original SD (held fixed reference). Same symlog scale and marker colors as figure1. Not uniform confidence bounds, not reselected target pair.
4. approximation: exact vs linear margin reduction for all eight cohorts and all nonzero budgets, uncapped flip, strictcap flip and deletion, in three panels. Both axes symlog linthresh.01. Identity line requested for diagnostic only; different cohorts distinct marker labels. Values preserve sign. All linear scores from original Hessian; no fitted regression. This is an approximation audit, not a robustness certificate.

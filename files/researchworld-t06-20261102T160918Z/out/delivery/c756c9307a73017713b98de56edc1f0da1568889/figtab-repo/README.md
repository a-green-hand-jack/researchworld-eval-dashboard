# Final stability presentation

Final figures, LaTeX tables, captions, source hashes and rendering code for the measured ranking-sensitivity audit are in `figures/`, `tables/` and `presentation/`.

Reproduce with `python3 presentation/render.py`. See `presentation/README.md` for the full input/output map and `presentation/inspection.pdf` for the inspected typeset proof. The renderer consumes committed numerical evidence from experiment-repo; it performs no new model fitting. All found attack budgets are successful heuristic upper bounds.

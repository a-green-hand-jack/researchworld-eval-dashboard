## Targets and interval labels

| Display / quantity | Required interpretation |
| --- | --- |
| Remaining-benchmark accuracy | Question-weighted accuracy on the 11776 pinned MMLU-Pro questions outside the **entire retained 256-item** search reservoir. This denominator is retained for every n/K slice, including n<256. |
| Search minus audit accuracy (pp) | A noisy estimate of selected search score minus the selected configuration's remaining-benchmark accuracy. Audit accuracy is an estimate, not known truth. Positive values mean the search score is higher. No audit-unbiasedness claim conditional on the runtime trigger is made. |
| Selected minus default accuracy (pp) | Difference on the same remaining benchmark, estimated from paired outcomes on the same audit questions. Retain analysis-approved paired endpoints; do not combine two independent-score SEs. |
| Delivered exact audit / gap interval | Runtime-protected finite-population interval: base fixed-design nominal 97.5%, with at least 95% coverage **unconditional over the original partition and B/C runtime choice**, separately for this endpoint family. It is not a delivered 95% conditional-on-trigger/reservoir guarantee. |
| Delivered exact paired audit interval | Conservative paired finite-population contrast with the same two-design protection plus its exported within-design paired/candidate multiplicity. At least 95% unconditional coverage for this endpoint family; no conditional-on-trigger guarantee. |
| Delivered transformed simultaneous search interval | Remaining-benchmark target after transformation of simultaneous full-benchmark success-count bounds. Allocate error across two designs and candidates within each design. Coverage is at least 95% unconditional over partition and runtime choice, separately for this endpoint family. |
| Delivered simultaneous audit / mixture interval | Preserve the exported two-design and candidate adjustments. It bounds the stated selected/mixture target with its endpoint-family guarantee; it is not jointly 95% protected with all other scientific endpoints. |
| Conditional selection repetition | Rerun selection on specified subsets of one retained search matrix, sharing the same audit matrix. MCSE concerns Monte Carlo error conditional on these matrices. It does not remove audit sampling uncertainty or describe independent LLM runs. |
| Known-cache calibration | Only the 768 retained question rows/four candidates define the empirical distribution. Whole-row iid draws with replacement preserve pairing; exact candidate cache means supply known truth for this experiment only. Original nominal 95% reporting methods remain unchanged. |
| Naive / binomial-simultaneous search comparator | Preserve the exported nominal 95% comparator labels. Do not confer the exact finite-design/runtime guarantee on these binomial comparators. |
| Audit sign disagreement | Descriptive disagreement with a noisy comparator, not measured population false-superiority or population false-positive risk. |
| Paired-row bootstrap sensitivity | Approximate sensitivity interval with completed outer/inner counts and resampling unit. No exact finite-population or conditional-on-trigger coverage claim. |

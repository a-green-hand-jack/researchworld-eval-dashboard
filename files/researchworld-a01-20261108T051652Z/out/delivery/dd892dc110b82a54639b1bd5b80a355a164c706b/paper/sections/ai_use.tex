\subsection*{AI use statement}
This study, including the literature search, analysis code, experiments, figures, tables and the text of this paper, was carried out by cooperating generative-AI agents (Claude models) working in separate roles (planning, analysis, presentation, writing, review). The task and its constraints were given by the operators of the pipeline. The agents were used for problem formulation, for writing and testing all code, for running all computations and for drafting and revising all text. No generative AI was used to produce data: every number in the paper was computed by the accompanying code from the public leaderboard snapshots listed in Appendix~\ref{app:repro}. Code was checked by unit tests against brute-force solutions and by independent review agents; every cited reference was looked up by an agent in a bibliographic source (for several, the abstract only, as stated in Section~\ref{sec:related}), not independently verified by a human. The responsibility for the final content rests with the operators of the pipeline.

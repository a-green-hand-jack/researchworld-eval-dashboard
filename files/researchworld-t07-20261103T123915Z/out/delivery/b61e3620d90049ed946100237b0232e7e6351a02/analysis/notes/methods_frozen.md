# Implemented estimators and controls

This technical note supports manuscript methods; it is not a claim of novelty or measured superiority. N is the number of binary matrix columns, k is the target-item budget and the full target mean is unweighted. Source rows are historical complete responses. All methods receive only their selected target observations. All final item draws are frozen independently of development draws; item order defines the crossfit halves, with sizes floor(k/2) and ceil(k/2).

## Uniform-selection estimators

- `random_mean`: arithmetic sample mean on k uniformly sampled distinct items.
- `source_prior`: historical matrix mean, using zero target observations. It is repeated as a control in each nominal-budget cell; `observed_items=0` records its true cost. Constant ranking metrics remain undefined.
- `source_difference`: historical full mean + mean(sampled target outcomes minus historical item means). Source item means are fixed predictors. This is a standard design-unbiased generalized-difference estimator.
- `ridge`: regress historical models' full means on their k sampled item responses; unstandardized squared-error SUM plus alpha times squared weights; unpenalized intercept. Alpha in {0.1,1,10,100,1000} minimizes mean validation MAE across five independent development item draws, then refit on all historical models. No clipping.
- `aipw_paper`: for each target, regress its k sampled responses on vectors of historical-model responses at those items, with the same ridge convention and development alpha grid. Let mS/mU be fitted sampled/unsampled means. Estimate sample_mean(y)+(1-k/N)*(mU-mS).
- `aipw_code`: identical orientation, fixed alpha 10 and default intercept, but use the pinned code's mU+(1-k/N)*mean(yS-pS). It is replicated algebraically, with an independent check against the exact pinned predict method and sklearn in `tests/test_aipw.py`. Both formulas preserve no clipping/standardization. With an intercept the sampled residual mean is zero, so the paper estimator is the fitted full-population mean and the code estimator is the fitted unobserved-item mean. Code-minus-paper equals (k/N)*(mU-mean(yS)). This is not a difference in sampled items or fit orientation.
- `crossfit_difference`: the two-direction estimator in `notes/crossfit_difference.md`, using historical-model ridge item imputation. Alpha is chosen before final sampling from independent development draws. Primary predictions are unbounded. `crossfit_clipped` clips these same predictions to [0,1] and is a biased ablation.
- `crossfit_impute`: same two half-sample fits and observed-half-exact totals, averaged, but with the held-out residual correction removed. It tunes its own alpha fairly. `crossfit_impute_matched` instead uses the candidate's chosen alpha, isolating correction at the same fitted half-sample imputer. Both include only each direction's observed half exactly.
- `ridge_impute`: regress historical unsampled-item mean on all k selected item responses, insert the actually observed target S contribution exactly and impute only the rest. It tunes its own alpha. This full-sample same-orientation control distinguishes sample-size/inclusion changes from correction. It differs from `ridge`, whose regression target includes the selected items and thus shrinks their contribution too.

AIPW regresses across items using historical models as features. Crossfit and ridge-impute regress across historical models using sampled items as features. This orientation difference prevents attributing crossfit-versus-AIPW performance differences solely to sample splitting. No matched-orientation causal attribution is planned.

## Fixed selections and IRT adapters

`anchor_mean` applies k-means to full historical response vectors for items, selects the closest actual member to each centroid and weights by cluster mass. Its binary correctness representation follows tinyBenchmarks section 3; it is not an exact confidence-based Anchor Points reproduction. `anchor_ridge` uses these exact same items with historical-score ridge and separate development alpha selection. K-means uses n_init=3, max_iter=100 and frozen benchmark/budget seeds. Refit selection on all historical models after development. Each anchor set is fixed across all 20 final repeats.

MAP-MIRT uses sigmoid(theta @ a + b), dimension in {2,5,10,15}, Gaussian MAP penalty 1 on all parameters, randomized-SVD initialization (seed 0, n_iter 4), L-BFGS-B with maxcor=10 and ftol=1e-9. Start with 500 iterations; on nonconvergence continue once from that iterate for at most 1500 more. All attempts/objectives/gradient maxima are saved. Dimensions >= fitting-model count are ineligible in very small reduced pools. Still nonconverged development dimensions are explicitly recorded and excluded from selection; if none converge, stop. A selected historical refit that still fails stops the run for repair, not substitution.

Per benchmark/scenario/budget choose one dimension by random-p-IRT mean development MAE over the five independent draws. Use that same dimension for all random/IRT-anchor mean/p-/gp-style comparisons so selection controls share a latent model. Historical refits are cached per selected dimension, not repeated per budget, draw or target. Source fits across all eligible dimensions are shared across development comparisons.

Target ability inference is MAP with fixed item parameters, penalty 1, zero initialization, L-BFGS-B maxiter=200 and ftol=1e-10. Inference failures stop predictions for investigation; they are not automatically replaced by a baseline. `mirt_random_p` and `mirt_anchor_p` include observed outcomes exactly and impute only unobserved probabilities. MIRT item embeddings (a,-b) are clustered identically to produce IRT anchors; `mirt_anchor_mean` uses their cluster masses. `mirt_random_gp` and `mirt_anchor_gp` mix observed estimate (uniform mean or cluster-weighted mean) with p-IRT, using observed weight in {0,.25,.5,.75,1}, selected by development MAE. Development predictions for a fixed anchor set are deterministic; repeats do not create independent anchor-fit uncertainty.

These are MAP/inference/validation-mixture adapters, not exact tinyBenchmarks variational hierarchical-prior/mixture-heuristic reproductions. The original paper's dimension grid, observation model and p-IRT observed-item formula are retained. No claim to defeat all IRT, adaptive, neural, text-based or continuous-score methods is supported by this grid.

## Frozen fitting and failure scope

`config/` lists exact split/draw/identity maps, formula conventions, numerical controls and metadata-only family eligibility. Five independent development samples determine tuning; 20 final samples determine performance. Budgets are nested within each independently drawn ordering and method comparisons share draws. Refit on all eligible historical rows after validation. The full target mean is computed only by the separate scoring command after all predictions exist. `TargetVault` records each method's exact selected items and rejects additional, duplicated or changed observations. This guards mistakes and makes access auditable; it is not a cryptographic sandbox.

Proxy-family and source-size experiments reuse immutable pilot targets. See `config/family_eligibility.json` for name/count-only selection and `config/splits.json` for assignments and nested source subsets. No response-based grouping changes source fitting. Full-response collisions enter retrospective scoring only. HELM uses opaque row IDs in every analysis.

## Formula-only AIPW reporting diagnostic

Independent review in experiment-repo#8 correctly distinguishes the tuned `aipw_paper` versus fixed-alpha10 `aipw_code` primary comparison from a pure return-formula effect. Their primary performance difference combines alpha selection and formula; it cannot isolate either. An additive retrospective diagnostic uses their exact shared selected-item setting at fixed alpha10: `paper10=(k/N)*random_mean+(1-k/N)*aipw_code`. The identity follows from the unpenalized-intercept zero sampled residual mean. It is verified against the direct alpha10 paper estimator on disposable binary matrices to1e-12 in `diagnostics/check_aipw_formula_reconstruction.py`, then applied deterministically to immutable prediction outputs without further fitting, tuning or target observation. The18 primary methods remain unchanged. `notes/freeze_amendments/2026-11-05_aipw_diagnostic.json` dates this review-requested reporting addition after prediction and before inspection of primary results. Its same-alpha code-minus-paper10 error/rank contrasts use the existing20 paired item draws/cohorts and conditional t/bootstrap intervals; it supplies the formula-only attribution that the primary configured comparison cannot provide.

# Task investment to first place: aggregation rules and score ceilings

`paper.pdf` is the integrated research manuscript; `paper.tex`, `sections/` and `references.bib` are its source. The study measures the minimum number of directly affected task scores required for a target entry to reach tied first under explicit score endpoints, fixed rivals and no task transfer. It does not estimate training data, compute, contamination or causal score gains.

## Build the paper

Use TeX Live with latexmk, pdfLaTeX and BibTeX. The selected edition, original official template files, retrieval hashes, page limit and checklist requirements are recorded in `venue/`. From the delivery root:

```bash
./build.sh
```

The command builds `paper.pdf`. Do not edit official style files or the generated figures/tables. The manuscript's checklist records the study's actual methods and scope. References and appendix follow the main text under the selected venue's rules.

## Reproduce the numerical evidence

The complete analysis package is self-contained under `code/`; run its commands from that directory. `code/README.md` gives the full sequence, exact versions, seeds, runtime records and input/result map. In a clean Python environment, install `code/requirements.txt` first. No GPU, paid API, training or new model inference is used.

```bash
cd code
export OPENBLAS_NUM_THREADS=1
export OMP_NUM_THREADS=1
python3 src/acquire.py
python3 src/prepare.py
python3 -m unittest discover -s tests -v
python3 src/run_bundle.py helm
python3 src/run_bundle.py openllm
python3 src/random_baseline.py --board helm --repeats 2000
python3 src/random_baseline.py --board openllm
python3 src/task_subsets.py --repeats 200 --tasks 45
python3 src/weighted_mean.py
python3 src/audit_normalization.py
python3 src/summarize.py
python3 src/validate_outputs.py
python3 src/validate_mc_precision.py
```

Acquisition uses public HTTPS sources without an account. Subsequent analysis is offline. The retained processed matrices and results support inspection without fetching raw tables. Pinning and checksum verification are implemented in `code/src/acquire.py` and `code/src/prepare.py`. Raw data downloads are not included in Git; no separate public-score data license was declared in the supplied source map. Code licenses and model metadata are not interpreted as score-data licenses.

The primary data are HELM MMLU v1.13.0 (2025-01-10; 79 entries by 57 subjects) and Open LLM `contents` commit `9c09a7cae43334062a82cb164f2ef255013dafa2` (2025-03-20; 4,575 unflagged entries by six aggregates). Source acquisition dates, URLs and SHA-256 values are in `code/data/manifest.json`; filtering/missingness checks are in `code/results/data_audit.json`. The available separate Open LLM `results` snapshot is not used. All full-snapshot optimization rows are certified optimal or infeasible. Random seeds are 519733 (task order), 449027 (subject omission), and 7821/999/112 (diagnostic exhaustive tests). Different equally optimal witnesses may be selected by different solver versions.

## Clean integrated verification

The optional Git-checkout driver `sections/reproduce.py` creates a fresh output tree (retaining only historical run provenance required by its validator, while removing all computed products), verifies checksum-pinned public acquisition, regenerates every scientific result, compares scientific values with the retained evidence, feeds regenerated summaries into the renderer, and builds/checks the complete PDF. Install the pinned analysis/presentation dependencies and TeX tools first. The target directory must not already exist:

```bash
python3 sections/reproduce.py --work /absolute/new/reproduction --phase acquire
python3 sections/reproduce.py --work /absolute/new/reproduction --phase offline
```

Acquisition requires network access. The offline phase can run on a separate CPU worker sharing the work directory. It uses one BLAS/OpenMP thread, retains per-stage commands/logs/statuses/timings in that directory, and compares costs and feasibility rather than requiring identical solver witness choices or runtimes. The presentation's timing column can vary without changing scientific values. Tables, complete PDF text and rendered page pixels are checked. The delivered source tree is never overwritten. The ordinary commands above also work from an extracted source archive without Git metadata.

The completed clean verification is recorded in `sections/reproduction-v1/REPORT.md`, with exact starting revision, environment, all 14 successful commands/logs, checksum/equality checks, and measured elapsed time. It took 17.04 minutes from fresh acquisition to verified PDF (15.65 minutes summed command time). This is a measurement with dependencies already installed, not a new-environment installation measurement; later corrections are identified as focused deltas.

## Reporting and source independence

Full-snapshot quartiles describe entry heterogeneity. Subject-omission ranges are perturbation sensitivity, not confidence intervals for future tasks, true accuracy or independently sampled models. Wilson intervals in the random-order results concern success probabilities. Separate marginal normal-approximation intervals quantify Monte Carlo precision of the HELM across-fixed-target cost means (`code/notes/RANDOM_BASELINE_MC_ERROR.md`); neither is uncertainty about physical training costs. Infeasible targets remain in success-fraction denominators.

Permitted literature was checked by the context position through direct original sources. `sections/source-reading.md` records the reading scope and attribution used for this manuscript. The forbidden predecessor and pages discussing it were neither searched for nor knowingly accessed. No accidental prohibited-source encounter is known in the delivered work. A source-access failure in the allowed literature retrieval is distinguished from a numerical failure; no failed/unfinished numerical run is reported as completed evidence.

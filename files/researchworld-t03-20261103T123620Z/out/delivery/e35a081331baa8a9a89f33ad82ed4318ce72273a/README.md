# Repeated-run reliability of SHAP for tabular models

This repository integrates the paper and reproducibility package for the frozen Research objective. The [PDF](main.pdf) and [LaTeX source](paper/main.tex) now contain the measured main study: three public datasets, nine fitted dataset/model cells, 540 exact empirical-game references and 97,200 stochastic explanations. The abstract, results and discussion report conditional one-run adequacy, finite-budget/strict-criterion/individual-input failures, uncertainty and actual CPU accounting. The sixteen-item [checklist](paper/checklist.tex) is filled, including candid source-license uncertainty and language-model research-process disclosure. The separately audited background supplement adds 144 exact changed targets and 5,760 stochastic calls without pooling them into primary estimator variability. All nineteen numerical figures and five numerical tables are integrated and trace to measured results; final approval is recorded on the version pull request.

The report distinguishes repeat-run agreement, accuracy against a validated reference for the same attribution game, and adequacy for a specified explanation use under a measured CPU budget. Numerical reliability alone does not establish causal validity or safety of deployment.

The [report build script](scripts/build_paper.sh) compiles `paper/main.tex` with official assets under `venue/` and writes `main.pdf` at the repository root. It requires TeX Live with `latexmk`, pdfLaTeX and BibTeX, plus Poppler's `pdfinfo` and ripgrep. Run:

```bash
bash scripts/build_paper.sh
```

The script reports missing inputs explicitly and retains the prior PDF if compilation fails. A successful compilation must also be checked for venue compliance, complete references, correct pagination, figure legibility, and supported claims before a report version is proposed.

# Local manuscript build assets

Captured 2026-11-03 from the actual LaTeX recorder (`manuscript/.build/main.fls`), not inferred from font-family names. `installed-assets.json` records every actual Type1 font file, original-file hash/size, byte-preserved initial notice, build-tool version and complete `pdffonts` inventory. Font binaries, TeX executable binaries and package wheels are not redistributed. Run `python3 manuscript/capture_build_assets.py` after a manuscript build to recollect the local inventory without external retrieval.

The actual URW Nimbus Roman, Nimbus Mono and Nimbus Sans Type1 headers credit (URW)++ Design & Development and declare the GNU General Public License with a specific exception permitting inclusion in PostScript/PDF documents regardless of the document's license. Each actual header notice is retained in font-notices/. Those headers refer to COPYING without specifying a GPL version there; no version designation is inferred from a newer URW distribution. Local general GPL2/GPL3 texts and the complete installed Debian TeX Live copyright records are retained for context, without pretending those generic texts supply a missing package-specific version designation.

The actual Computer Modern and mathematical-symbol Type1 files used here are American Mathematical Society font releases whose original headers declare SIL Open Font License1.1, preserving their individual copyright and reserved names. The full OFL1.1 text is retained in the rendering owner's STIX notice at `figures/provenance/rendering/notices/STIX-LICENSE.txt`; the actual AMS headers identify the separate font authorship and reservation, rather than borrowing STIX's identity. Font files are used unmodified and embedded as PDF subsets. Scientific-figure Liberation/STIX inventory and notices are separately preserved under `figures/provenance/rendering/`.

The local TeX Live copyright record states that TeX Live is a compilation of differently licensed packages, not one uniformly licensed asset. Its complete Debian attribution, included LPPL text and package-specific caveats are retained unchanged. Standard article/AMS/graphicx/booktabs/longtable/hyperref and build utilities are used as installed; their executables are not distributed or relicensed by this delivery. Tool versions are recorded in BUILD.md and the machine-readable capture. The official NeurIPS style/template/checklist remain unchanged with exact official retrieval/hash attribution in venue/SOURCES.md. That archive supplied no separate license grant; the checklist answers No instead of inventing one.

Original manuscript prose, build/validation helpers, root overview and source-relay records were prepared by paper-repo with the disclosed AI-agent involvement. Relayed context/provenance retains its original authorship; citations/third-party literature and template/font assets are not relicensed. No new project reuse license was specified for original manuscript or generated outputs, and repository availability is not a license grant. Analysis-generated asset terms are in analysis/provenance/ASSET_TERMS.md. These local records document supplied attributions and declared terms, not independent legal-title verification or an exhaustive operating-system license inventory.

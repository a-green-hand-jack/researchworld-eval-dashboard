# Reproduction package: "What does a tuned benchmark score mean? Winner's curse in prompt and program search"

Everything here was run on one CPU-only machine (Intel Xeon Gold 6230, 40 logical cores shared with other jobs, 251 GB RAM, no GPU, no API calls).
Paper: `paper/main.pdf` (NeurIPS 2026 template, `paper/main.tex` + `paper/sec_*.tex`, tables in `paper/tables/`, figures in `paper/figs/`).

`venv/bin/pip install torch --index-url https://download.pytorch.org/whl/cpu` and
`venv/bin/pip install transformers accelerate pyarrow huggingface_hub pandas numpy scipy matplotlib pypdfium2`.
Versions used: torch 2.15.0+cpu, transformers 5.22.2, numpy 2.4.6, scipy 1.17.1, pandas 3.0.6, pyarrow 26.0.1, matplotlib 3.11.2.

## Design notes
* `code/prompts.py`: prompt-configuration space (4 system x 5 instruction x 4 option-format x 4 answer-cue x 4 demo slots = 1280); `sample_configs(K, seed=0)` gives the fixed candidate list (stored in `results/raw/<tag>/meta.json`).
* `code/score.py`: scores each (config, question) by the next-token log-prob of the option letters (one forward pass), fp32 (int8 dynamic quantisation was tested and rejected: it collapses 1.5B accuracy).
* `code/sel.py`: optimisers (exhaustive, successive halving), all reporting protocols, the replicate engine, the synthetic generator.
* Pool: first N qualifying questions (zero-shot prompt <= 220 tokens) of `RandomState(0).permutation(12032)`; fresh pool = the next 1000 / 600 qualifying questions (`--skip 1500`), disjoint from both pools.
* `results/raw/` holds the cached letter log-probabilities (can be regenerated by step 1/2); `results/*.json` are the experiment outputs from which every number in the paper is computed.

For a new score vector X with finite covariance Σ and mean μ, the best linear predictor from queried coordinates S is μ_T + Σ_TS Σ_SS^{-1}(X_S−μ_S), assuming Σ_SS is invertible. Its error covariance is C_TT = Σ_TT−Σ_TS Σ_SS^{-1}Σ_ST. These statements require only second moments for best *linear* prediction; equality with conditional expectation and conditional variance independent of observed scores requires a joint Gaussian distribution. Under squared error the total expected loss is tr(C_TT).

Starting with C=Σ, observing an additional exact coordinate j updates C to C−C_:j C_j:/C_jj. Thus total risk on the whole score vector drops by sum_t C_tj²/C_jj. Observed coordinates have zero error, so their inclusion does not alter the numerator of final loss. With a fixed budget k, minimizing whole-vector total loss also minimizes mean error on the N−k remaining coordinates. Greedy selection maximizes the current one-step drop; we do not claim global optimality or a submodular approximation guarantee. Maximum conditional variance is the D-optimal greedy rule for Gaussian entropy. Regularization and covariance estimation are practical approximations, not protected by this oracle identity.

`scripts/diagnostics.py` checks the oracle identity against 100,000 Gaussian score vectors. This is a numerical check of the derivation only, clearly separate from observed leaderboard evidence. MAE is the primary reported prediction metric but is not the objective greedily optimized; squared error and standardized error are also reported. All benchmark queries cost one unit in this study, regardless of original benchmark runtime.

The oracle identity is for the unclipped linear predictor with the true covariance. Empirical predictions use fitted/regularized covariance and clip to [-1,1]; they are assessed by held-out measurements rather than asserted to obey the oracle identity.

## Computational cost and deployment conditions

For M historical rows and N benchmarks, column means and masks use O(MN) work and storage; the two dense pairwise-product matrices cost O(MN^2) work. PSD projection costs O(N^3), and stores O(N^2) covariance entries. A k-step greedy design costs O(kN^2) time with the rank-one conditional-covariance updates used here. Once its k query coordinates are chosen, solving for all target regression coefficients costs O(k^3 + k^2 N), followed by O(bkN) work for b new model rows. Thus training memory is O(MN + N^2), excluding the source archive, which the parser streams. Validation repeats these operations for the four shrinkage candidates and evaluated budgets; benchmark execution itself is outside these CPU timings. The measured suite timings include all predictor/selection controls, not only this proposed procedure.

The design is fixed across new models within a fitted split: it does not adapt query order to the newly observed score values. It assumes each chosen benchmark can be acquired under the same definition as the historical column, at one unit of query-count budget. The historical covariance must carry predictive information for the new model population; shrinkage guarantees numerical invertibility here but does not guarantee accurate covariance under selective missingness or distribution shift. Treating an observed aggregate score as an exact input ignores repeated-evaluation noise. Complete test rows make all chosen inputs observable in this retrospective evaluation; they do not establish performance for models outside that cohort. All returned predicted scores are deterministic point estimates, not calibrated predictive intervals.

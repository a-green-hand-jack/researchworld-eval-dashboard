# Compositional conformal prediction: research context

This repository owns objective interpretation and permitted-source context for the ResearchWorld study. The experimental plan and empirical results belong to their respective positions.

- `context/Brief.md`: binding requirements, target distinctions, evidence/reporting conventions and ownership map; mirrored in wiki `Brief`.
- `context/literature.md`: source versions, actual read extents, established findings, closest allowed comparison and limits; mirrored in wiki `Sources`.
- `context/references.bib`: verified entries for consulted permitted arXiv versions, without claims of exhaustive coverage.
- `context/retrieval.json`: exact PDF retrieval URLs, sizes and hashes.
- `context/input_manifest.json`: frozen input provenance.

All supplied inputs were read in full. Source PDFs were downloaded by exact identifiers from the explicitly permitted starter list; no broad topic search or citation traversal was used. The reading ledger distinguishes downloaded material from actually inspected sections. No experimental result is reported by this repository.

The context bundle is also published as a release for positions with release/wiki-only access. The report owner integrates the supplied framing and citations into the manuscript; this repository does not own the report itself.

# figtab-repo

Presentation owner for the repeated-run reliability study of SHAP feature
attributions for tabular models.

- [Presentation commitment](../../issues/3)
- [Evidence and display design](docs/presentation-design.md)
- [Protocol-aligned artifact and claim map](docs/artifact-map.md)
- [Shared rendering and provenance helper](figures/rendering.py)

The completed presentation contains 19 numerical figures and five numerical
tables, plus an archived pilot figure/table, with generators, captions and
hashed provenance. All are delivered into paper-repo's assigned `figures/`
and `tables/` roots. [Final artifact handoff](figures/MAIN_HANDOFF.md) maps the
inventory; [inspection record](figures/inspection.md) accepts all actual placed
outputs in the 48-page root manuscript at paper revision
`8aa79e935dae75d9fdcc3be7b9f290d9c16692a1`. This is presentation acceptance;
independent scientific review and final release belong to their owners.

# 自动选优之后，基准分数意味着什么

## 1. 摘要与目标
在固定8候选、64题选优的主设置，已知真值模拟的平均乐观偏差为 **6.51 ± 0.09 个百分点（MCSE）**；真实LLM缓存的完整600题队列偏差为 **2.32 ± 0.09 个百分点**。复用选优数据**可能**低估不确定性并导致错误提升判断；但本真实队列朴素Wilson覆盖率95.90%，没有观察到主设置欠覆盖。因此结论是视条件而定，而不是断言所有真实选优都会让区间失效。

## 2. 实验计划与完成情况
- 已完成冻结的58个合成/有限池设置及真实队列11个设置；完整结果保留，不筛选正面案例。
- 已完成固定族理论、有限剩余池精确审计、完整队列仿射映射、配对提升与联合置信预算证明。
- 已完成小规模穷举、解析最大值核验、数据/得分/请求体审计、各项消融和单次回放报告卡。
- 后增探索性相同答题预算比较，单独标记，不伪装成预注册结果。
- 未完成/未声称：多模型、多基准、自适应提示生成器实测、前瞻研究者盲化审计、新题总体真实oracle、人类核验。

## 3. 设置
- 数据：MMLU-Pro固定修订 `b189ec765aa7ed75c8acfea42df31fdae71f97be`，14类别600题；全部原始选项保留。
- 推理：实际调用兼容API，未认证模型别名 `gpt-5.6-luna`；请求零温度、`max_tokens=192`，8个冻结2×2×2零样本提示；不发送标签或解题字段。服务端1292次报告用量超过请求上限，故不能视为强制token预算；见usage审计。
- 完整回答数：4800；解析失败40个，全部计错保留；未完成0个。
- API报告prompt tokens 1,168,858，completion tokens 1,282,295；采集墙钟40.6分钟，无GPU。货币费用、认证模型身份和GPU等价算力未知。
- 分析：常规每设置2000独立随机划分；四个B敏感性检查为前200个数据集。重复缓存仅提供条件MC精度，不代表新的独立真实基准。

## 4. 基线和比较
六种准确率区间：Naive Wilson、同时Hoeffding、共享行乘子、经验guard、审计Wilson、精确审计。模拟的精确审计使用二项反演；有限池使用超几何反演并映射到完整队列。另比较选优数据上的朴素配对正态提升判断和审计配对差异的精确Bonferroni区间。审计使用额外回答，正文明确预算不同，附录另给相同预算政策比较。

## 5. 结果

| 方法 | 模拟覆盖率% | 宽度pp | 真实队列覆盖率% | 宽度pp |
|---|---:|---:|---:|---:|
| Naive-Wilson | 83.95 | 20.28 | 95.90 | 16.67 |
| Simult-Hoeffding | 99.95 | 41.71 | 100.00 | 34.87 |
| Multiplier | 97.30 | 30.88 | 96.50 | 21.63 |
| Guarded-multiplier | 97.30 | 30.88 | 99.20 | 22.12 |
| Audit-Wilson | 94.60 | 15.58 | 97.55 | 11.33 |
| Audit-exact | 96.60 | 16.40 | 96.35 | 10.38 |

主模拟朴素提升判断错误提升率为10.85%，精确配对审计为0.10%。近边界压力p=.95,n=16,latent rho=.9下，原始乘子覆盖率仅82.50%，350次遗漏均对应零宽度区间；经验guard此处全部回退到保守界，但不因此获得一般有效性保证。
单次预指定回放获胜P5：选优87.50%，审计83.59%，完整缓存真值84.50%。联合95%报告卡见 `artifacts/report_card.json`，它不是真正前瞻盲化审计。

图表与数据：`artifacts/figures/`、`artifacts/tables/`、两个完整summary CSV、每次重复NPZ。所有正文数值宏由已运行结果生成。

## 6. 分析、局限和下一步
**推荐**：披露搜索历史与选优分数；冻结最终系统和基线；保留真正未访问的审计题；按抽样设计报告区间与目标；配对比较，并为同时发布的准确率和提升分配联合错误预算。固定候选族的同时界不能仅按事后生成的提示数量套用。
真实结果是有限队列的选择泛化，不是未来题目总体oracle。真实基线P0恰是缓存上准确率最低的提示，非正提升只出现在自我比较，因此真实零错误提升率不能作为有效的I类错误压力验证；相等质量模拟承担了该检验。未知端点身份/训练污染、单一输出、提示数小、代价不可货币核验、无自适应优化实测均限制外推。与标准统计方法相比的贡献是明确目标与访问契约的可复现实测及失效案例，不声称首次提出样本切分或赢家偏差。下一步最小有效验证是更大、独立抽样且真正封存的前瞻审计。

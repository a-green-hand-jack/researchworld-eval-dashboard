# Joint reliability for observed compositions

[Read the paper](paper.pdf). This delivery contains the complete **19-cell ×100-trial synthetic study**, all code, raw/checkpoint evidence, numerical audits and reproducible figures/tables. The target is the entire future **observed composition vector**. The results show severe minority undercoverage hidden by marginal coverage, a mechanism-dependent ILR/Euclidean area reversal, unresolved TV/Euclidean ordering, calibration-scarcity costs and limitations of area for zero-face outcomes. They establish no universal method winner, latent-probability, real-data or arbitrary-shift guarantee.

The manuscript uses the unchanged official NeurIPS 2026 Main Track review style: **eight main-text pages**, followed by references, supporting appendices/full tables and all 16 answered checklist items. The official submission footer belongs to that format; no external conference submission or acceptance is claimed. [Validation](manuscript/VALIDATION.md) and the [claim-to-evidence map](manuscript/EVIDENCE.md) identify the exact checks and sources. Independent approval is recorded through the version pull request; a push to main alone is not final approval.

## Reproduce every figure and table

To connect a completed fresh scientific reproduction to the paper's presentation, first finish all scientific commands above, including its final audit. Then run from the delivery root, using the same explicit output root:

```bash
python3 figures/scripts/verify_fresh_results.py --fresh-root "$reproduction_root" --analysis-root analysis --report /tmp/fresh-presentation-equivalence.json --render
```

This checks every consumed core/final scientific input against the immutable presentation exports, bound to the supplied results' own audit hashes. Only successful equivalence permits the four confirmatory/core renderers to run, explicitly rendering the **original snapshots after verification**. It preserves their original provenance. Missing or scientifically changed inputs fail before rendering; there is no fallback to bundled results. Success establishes equivalence of the supplied exports, not proof that new trials ran. [FRESH_RESULTS.md](figures/FRESH_RESULTS.md) defines the complete contract: exact keys/counts/statuses/missing patterns, floating-point absolute tolerance `1e-12` with relative tolerance zero, all confidence/bootstrap endpoints and numerical flags, and exclusions limited to timing/reproduction-container metadata. Historical core bootstrap endpoints are checked using the original manifest order and pinned interval function.

Pre-study rank/integration diagnostics have a separate generator and snapshot; fresh confirmation does not regenerate or certify them. Their independent generation command is `PYTHONPATH=analysis/src python3 analysis/scripts/diagnostics.py --output <separate-diagnostic-root>`. The gated renderer excludes them. Use `render_diagnostics.py` below to render their explicitly retained original snapshot.

To rerender all original snapshots without claiming fresh scientific equivalence, use the separate archive route:

```bash

python3 figures/scripts/render_core.py
python3 figures/scripts/render_regions.py
python3 figures/scripts/render_final.py
```

These commands rerender the committed frozen presentation snapshots, preserving their recorded source provenance. `render_core.py` and the default region renderer use `figures/source_data/core/`; final/table renderers use `figures/source_data/final/`; the diagnostic renderer uses the separate pre-study snapshot in `figures/source_data/diagnostics/`. They do not select fresh confirmatory results, refit models or add study trials. Regenerating `analysis/results/confirmatory/` alone does not change their inputs. Expect roughly 1–13 seconds per script in the supplied shared two-CPU environment, with actual timings in the manifests. [CORE.md](figures/CORE.md), [FINAL.md](figures/FINAL.md) and [diagnostic mapping](figures/README.md) identify every input selection, script, source revision, output hash and interval meaning.

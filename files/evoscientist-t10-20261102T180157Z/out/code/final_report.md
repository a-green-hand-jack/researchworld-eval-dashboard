# 研究报告：固定标注、未标注数据与预测器后的区间宽度

## 1. 总结与目标

**结论：可以有条件地缩短，但没有普遍缩短的证据或定理。** 必须区分“oracle方差空间”“可学习的渐近收益”和“有限样本95%覆盖保证”。

最明确的严格有效收益出现在强分层的合成情形：n=2000、N=20000，固定阈值精确分层区间的平均宽度为 **0.03198**，普通标注集精确二项区间为 **0.04429**，减少 **27.8%**；配对Monte Carlo 95%收益区间为 **[27.63%,27.93%]**。两者均有明确假设下的有限样本覆盖保证。分层法在其余多数情形更宽，不构成普遍支配。

非线性交叉拟合在二次、阶跃合成机制中分别获得约 **18.0%**、**39.3%** 的宽度减少，但区间仅渐近有效；阶跃n2000覆盖0.9355，稀有事件n30覆盖0.2645，不能将其宽度减少宣传为严格有效的改进。两个真实配对数据示例均没有非线性宽度收益。

提交物：`paper.pdf`、`paper.tex`、`references.bib`、完整代码与`README.md`。论文用未修改的ICML2026官方模板，正文/结论截至第7页，参考文献同页起，附录第8页起，总19页；符合8页正文上限，含官方要求的impact statement及补充复现checklist。没有声称已达到会议接收标准。

## 2. 实验计划与研究问题

选取二元总体均值/发生率 μ=E[Y]，因为它既对应科学估计目标，又允许精确二项覆盖基线和已知真值的机制检验。

- 固定输入：每次重复内所有方法共享同一份标注数组、未标注分数和原预测值；不新增标签、数据或预测查询。
- 允许对冻结分数做推断后处理，不重新训练或替换底层预测器。若“固定”被解释为禁止任何分数变换，则非线性路线不在允许范围内；论文明确这一区别。
- 成功信号：覆盖与宽度均报告不确定性；不得将未达到覆盖要求的窄区间算作严格有效成功。
- 基线检查→冻结固定推断配方→32设置重复实验→独立理论/结果审计→论文与复现检查。
- 统计方法未根据完整结果调参。分层精确基线在主运行仍待完成且未读取完整结果时另行声明；其补充实验重放原数据，并非新的独立重复。本地计划与哈希不等于独立时间认证的预注册。

计划和变化：`todos.md`、`artifacts/prerun_amendment.md`、`artifacts/exact_baseline_addition.md`。原任务：`TASK.md`；完整约束的忠实摘要：`research_request.md`。

## 3. 数据、模型、环境与设置

- 合成：S~Uniform[0,1]，Y|S~Bernoulli(m(S))。m分别为线性 .1+.8S、二次 .02+.96(2S−1)²、阶跃 .01+.98·1{S>.5}、无信息 .5、稀有 .01。真值与方差解析可得。
- 真实：`ppi-python==0.2.3`的galaxies（16,743行）与forest（1596行），只使用附带冻结分数。数据SHA-256及EDA：`data/manifest.json`；均为二元Y，分数位于[0,1]，无缺失。
- 真实实验从固定经验联合分布**独立有放回抽样**；目标是该经验分布的标签均值。它不验证原科学总体外推或无放回有限总体推断。未标注标签不进入推断。
- 核心n={100,500,2000}，N/n=10；另有n30和N/n={1,100}压力测试，共32设置，各2000重复，64,000组数据、884,000条区间输出。补充重放不增加独立样本数。
- 交叉拟合：5折，按iid输入顺序索引mod5、与数值无关；固定特征S、(2S−1)²、(2S−1)³、1{S>.5}；训练协方差加1e−4/n_train ridge，不搜索超参数。
- Python3.11.15；CPU主机报告40逻辑核，实际4进程、单线程BLAS；主运行127.2秒、补充12.1秒。无GPU或付费API。依赖版本、命令和预计耗时详见README；整套计算远低于一周预算。

## 4. 基线与比较

**渐近层**：标注Wald、原始PPI λ=1、原论文无约束标量PPI++、包默认PPI++、标量/二次/rich交叉拟合，以及标记为unsafe的同样本残差拟合负对照。合成机制另有oracle正态参考。

**有限样本层**：普通精确二项区间、固定两层精确区间、标注集经验Bernstein、EB-PPI、带同时误差预算的固定字典最短区间。

关键公平性：`ppi-python==0.2.3`默认截断λ∈[0,1]，采用有偏样本矩；原PPI++均值理论允许任意实数λ。主比较使用更强的无约束版本，不把去掉软件截断当成新方法收益。单元测试直接核对包默认端点。

有限方法的保证来自证明，而不是模拟：

1. 精确两层法对随机标注分层计数分别做二项区间，并对池化n+N分数估计层质量；三项各分配α/3。置信事件无需独立，联合界与目标映射给出有限样本覆盖至少1−α。
2. EB字典的各个分数函数在观测前固定，并对全部均值和候选分配同时误差预算；因此选择最短区间仍有效，但log候选数与支持范围项可能抵消收益。

未实现原PPI附录betting型MeanCI。因此不声称覆盖全部更强有限样本方法，也不声称有限样本SOTA。

## 6. 理论、局限与下一步

对固定分数函数g，μ̂_g=mean_L(Y−g(S))+mean_U(g(S))。令r=n/N、m(S)=E[Y|S]，完成平方得

V(g)=Var(Y)/n−Var(m)/[n(1+r)]+(1+r)Var(g−m/(1+r))/n。

故该估计量类中的oracle是m/(1+r)加常数；超过最优标量修正的方差空间为

[Var(m)−Cov(Y,S)²/Var(S)]/[n(1+r)]。

m关于S仿射时没有额外oracle收益；m常数时任何固定分数修正都没有方差收益。这不排除其他信息、其他参数化假设或其他置信集构造的机会，更不是全体区间的全局最优性定理。交叉拟合的近似还需固定维度、独立分折、可逆极限协方差、消失ridge、正的极限方差等条件。

主要局限：

- 只研究有界均值，精确分层实现只对二元Y；正态法不提供统一有限样本保护。
- 合成条件均值刻意与固定基匹配；两个经验示例没有收益，外部泛化证据有限。
- 同分布、独立抽样、原预测器独立性是实质假设；分布漂移、依赖数据和预测器训练泄漏不在保证内。
- 精确区域的同时保护保守；没有优化误差分配和阈值，也没有测试更强betting区间。无收益不等于不存在其他有效缩短方案。
- 文献仅按允许原始URL查阅，不做主题/引用链检索，不能认证广泛新颖性。投影、交叉拟合、分层和联合界均非新发明。独立审稿仍认为ICML主会贡献力度不足；不靠扩大措辞掩盖。
- 禁读材料未被识别或故意访问；因其未命名，无法排除未知重叠。记录见`literature/incident_log.md`。

建议下一步是独立选择新的科学分布、检验冻结配方，并补充更强的有限样本betting基线，而不是对已有模拟结果继续调参。

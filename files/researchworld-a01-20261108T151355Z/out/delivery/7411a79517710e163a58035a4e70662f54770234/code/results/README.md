# Results: what each file is, how it was made, which claim it feeds

All numbers below are **measured** by the scripts named (`src/` at this commit); nothing is estimated by hand. Claim ids C1–C8 are those of the analysis plan fixed before the final grids.
Reproduce a result file with `./run_all.sh JOB` (job name in the table); summary tables with `python3 src/analyze.py`; checksums with `python3 src/provenance.py`.

## Conventions (apply to every file)
* One row = one (dataset, cap, rule, target) problem solved **exactly** (closed form / bisection / MILP; `docs/SOLVERS.md`). Margin eps = 1e-3 unless the file says otherwise (`*_eps*.csv`).
* Outcome columns: `L1` (total points), `K` (tasks touched), `Linf` (uniform-raise benchmark; the three are separate optimisations), `gap` (leader's value − target's value under the rule), `rank_mean` (rank under the mean), `rank_rule` (rank under the rule; for Condorcet: Copeland rank = proxy, see `docs/SOLVERS.md`).
* **`feasible`** (bool), **`status`** ∈ {ok, infeasible, censored}, **`seed`** are in every per-target file. `inf` in L1/K/Linf = *proven* infeasible under the cap; `NaN` = solver time limit (**censored**, never counted infeasible). Rows with K=0: the target is already first under that rule.
  `feasible`/`status`/`seed` were added to files written by earlier driver versions by `src/finalize.py` (idempotent; rows decided from inf/NaN; old files cannot show time-limit censoring but only MILP rules have time limits and those were all re-run with the new driver).
* **Uncertainty convention.** Per-target files are the full population (no resampling inside them). Replicate files (`*_noise_*`, `*_taskboot_*`, `*_tasksub_*`, `*_flip_*`) hold **one row per draw/replicate** (`draw` column) so figures can show spread directly. Tables in `summary/` give 95 % percentile bootstrap CIs (B = 1000, seed 0) **over targets within a rank bin** — descriptive of the target population, not a sampling model of the leaderboard. Infeasible targets are never dropped: the feasible share is reported, and K/L1 statistics are **conditional on feasibility** (under restrictive caps the feasible set is the near-top targets, so conditional medians are not comparable across caps/rules without the share next to them).
* Rank bins are by `rank_mean` (same target set for every rule): 2 | 3–5 | 6–10 | 11–30 | 31–100 | >100 (the current leader, rank 1, is excluded; its rule rank can differ).
* **Targets.** HELM: all 79 models (78 non-leaders), 57 subjects. OLLB: 4496 models (4495 non-leaders; 4497 after de-duplication, of which the unflagged 4496 are used), 6 tasks (normalised scores). Score rules run on **all** targets. **OLLB ordinal rules (Borda, Condorcet, plurality) and the slice runs use a rank-stratified sample of 101–102 targets** (20 ranked 2–21 + log-uniform in rank up to 100 distinct positions; `--nsample 100`, seed 0), because each MILP has up to 4496 rivals; pooled numbers across rule families on OLLB must use `summary/ollb_matched_sample.csv` (all rules on the same 102 targets), not `main_groups.csv` pooled over bins. Sample bins are small (`n_targets` column) — read CIs accordingly.
* Caps: `ceil` (100 everywhere), `front0/front2` (rival max + 0 / + 2 per task), `gain5/10/20` (x_t + h), `emp95/emp99` (x_t + the 95/99 % quantile of OLLB fine-tune − base gains, per task: 540 pairs; values 46.0 7.3 21.3 3.8 7.2 3.2 (q95) in OLLB task order), `emp95pool` (one pooled scalar, 25.3 points). **Transfer of the empirical caps to HELM:** HELM has no base/fine-tune pairs, so every one of its 57 subjects gets the **MMLU-PRO per-task quantile** (3.21 at q95; the closest analogue, a knowledge multiple-choice task); `emp95pool` (HELM only) is the pooled-scalar alternative and is much more permissive (feasible share 0.62–0.97 vs 0.05–0.21) — the HELM emp-cap results are therefore sensitive to this transfer and should be reported with both. The 540 pairs are not outcomes of *targeted* training.
* Spillover (`*_spillover.csv`, stretch): effort d_t on one task lowers the other tasks by κ·(D−d_t), κ = λ/(n−1), λ ∈ {0, 0.1, 0.25}; λ = 0 reproduces the main solvers (checked). Rules: mean, min (+ median on HELM); samples of 47 (HELM) / 102 (OLLB) targets.

## Measured findings (pointers; wording is for the paper)
* **C1/C2 (mean, min)** `theory_checks.csv`: closed forms P1–P3 agree with the solvers to ≤ 1e-7 (max |ΔL1| 2e-13, |ΔK| 0, |ΔLinf| 9e-8; 237 rows: mean, min, median). `c2_min_vs_mean.csv` (ceil): L1(min)/L1(mean) median 0.147 on HELM (CI 0.120–0.177), 0.251 on OLLB (0.248–0.253); min cheaper than mean for 100 % of targets with L1>0 on both. **By CV tercile (plan statistic) the ratio rises with dispersion on both datasets**: HELM 0.083 / 0.147 / 0.229 (low/mid/high; Spearman +0.92), OLLB 0.197 / 0.243 / 0.352 (Spearman +0.84); CIs of the terciles do not overlap. The secondary statistic mean−min is **not** stable across datasets (Spearman +0.27 HELM, −0.51 OLLB; the earlier across-task sd gave +0.77 / −0.28): the CV result is the C2 finding, mean−min/sd are not. Under emp95 (feasible targets only: 4 on HELM — too few for terciles —, 49 on OLLB) the ratio is 0.035 (HELM) and 0.083 (OLLB, CI 0.063–0.100; CV terciles 0.050 / 0.069 / 0.136): min is cheaper there too, conditional on feasibility.
* **C3 (task subsets)** `c3_tasksub.csv`: at n=57 mean K/n 0.15, median 0.04, min 0.03, Borda 0.21, plurality 0.06; at n=5 mean/median/min 0.27/0.29/0.27. Median is **not** cheaper than min in K/n at any n (it is above min for every n tested, 5…57), as in the idea-review pilot. Min is infeasible for 0–13 % of subsets at small n (gain10 cap).
* **C4** `c4_rank_vs_gap.csv` (ceil, over targets with gap>0 and L1>0; gap in rule units; the mean is an identity, listed only as a check): the gap beats the rank (R²(gap)−R²(rank) with a bootstrap CI above 0) for geomean, harmonic, median on both datasets (HELM +0.045 to +0.084; OLLB +0.020 to +0.032, i.e. a small margin) and for Borda on HELM (+0.055, CI 0.014–0.076); **not supported** for min (HELM −0.014, CI −0.037–0.003; OLLB −0.005, CI −0.007 – −0.003: rank ≥ gap), nor for Condorcet (Copeland-score gap; HELM +0.057, CI −0.002–0.076; OLLB −0.008, CI −0.021–0.006), Borda on OLLB (+0.018, CI −0.002–0.039) or plurality on HELM (+0.016, CI −0.159–0.064; first-place counts are coarse, n=77). OLLB plurality is **not tested**: nearly every target ties at rank 8 under plurality (no first-place wins), so its rank has no variance. Rank is itself a strong predictor everywhere (R² ≥ 0.72, ≥ 0.84 for the score rules): the claim 'gap, not rank' holds for the smooth score rules, not for min or the count-based ordinal rules.
* **C5 feasibility (all targets pooled, HELM)** `main_groups.csv`/`c5_feasible_vs_h.csv`: share 1.00 under ceil/front0/front2 for every rule on both datasets; gain10: plurality 0.73, median 0.51, Condorcet 0.49, mean 0.37, Borda 0.32, geomean 0.31, harmonic 0.26, min 0.18; emp95 (MMLU-PRO transfer): 0.05–0.21 (plurality highest, harmonic/geomean/min lowest). OLLB (all targets, score rules): gain10 0.025 (mean) – 0.099 (min); gain20 0.14 (median) – 0.64 (min): **min is the *most* feasible rule on OLLB under gain caps and the least on HELM** (rule order is dataset dependent). On the OLLB ordinal sample (`ollb_matched_sample.csv`): gain10 plurality 0.13 vs Borda 0.64, Condorcet 0.39.
* **C6 ordinal rules (HELM, ceil, rank 11–30, medians; `main_groups.csv`)**: K: plurality 9, mean 10, Condorcet 28, Borda 38; L1: plurality 25, Borda 286, Condorcet 107, mean 435. So Borda and Condorcet need many tasks (K) but, contrary to the plan's hypothesis, **Condorcet is cheaper than the mean in points**; plurality is cheapest in both. OLLB sample (ceil): K plurality 2 (all bins), Condorcet 2–4, Borda 1–5; OLLB plurality becomes the hardest rule to make feasible under gain10 (0.13) and 6–10 bin share 0.0 — the failure case for R5.
* **C7** `summary/noise_*.csv`, `flip.csv`: under evaluation noise the gain10 L1 changes (median over targets, mean of draws) ×1.00 (Borda) – ×2.45 (min) on HELM (mean ×1.07) and ×1.05 (mean) – ×1.56 (min) on OLLB (10 targets each); min is infeasible in 44 % of noisy draws on HELM (obs. 30 %) and 51 % on OLLB (30 %). `flip.csv`: probability that a just-first target (margin eps) stays first under noise p_eps = 0.13–0.50 for mean/geomean/median/min in the rank 2–30 bins (Borda 0.47–1.0; the rank-2 bin is a single target), i.e. a margin of eps is nowhere near robust; the extra margin d95−d_eps for a 95 % stay is 0.5–2.3 points for mean/geomean/median/Borda and 6.5–10.6 points for min. `eps.csv`: eps 1e-6 changes nothing; eps 0.1 changes L1 by +0.3–3 % (median ratio), by up to ×12 (OLLB median rule) or ×100 (HELM plurality/Condorcet/median) on single targets whose base L1 is small, and turns up to 10 of 4495 OLLB gain10 targets infeasible (HELM: 1). `summary/c7_slices_compact.csv` (OLLB ranks 2–100, ceil and gain10; same ~54 sampled targets in main/nomerge/raw, all 99 in top500): **survives** in every slice — the mean is the most expensive rule in L1 (ceil: 28–48 points vs 8–26 for the others) and min is far cheaper than the mean; gain10 feasibility is lowest for plurality (0.15–0.47) and highest for the mean/Borda (≥ 0.94). **Does not survive**: the median-vs-min order. Median is cheaper than min on the normalised main sample (L1 7.7 vs 10.7 at ceil, 5.0 vs 8.4 at gain10) but dearer on **raw** scores (22.2 vs 13.2; gain10 feasibility of the median falls 0.83 → 0.39) and on top500 (15.3 vs 12.6), and in the no-merge slice (14.0 vs 9.4 at ceil; 8.4 vs 6.9 at gain10). So 'the median is cheap' on OLLB depends on the score normalisation and on the model slice; Condorcet, Borda and plurality stay between 10 and 26 points at ceil in all four settings. `trimmed.csv`: see table notes.
* **C8** `c8_cap_realism.csv` (numeric criteria of the plan; per-task emp95 caps, 540 fine-tune−base pairs). Share of targets for which first is **infeasible** under emp95: HELM 0.80 (plurality) – 0.95 (harmonic) over all 78 non-leaders; OLLB score rules 0.925 (mean) – 0.986 (min) over all 4495 — almost entirely the >100 bin; in the top bins it depends on the rule: OLLB ranks 2–30 under the mean/median are feasible for all but 2 of 20 (median 11–30: 0.10 infeasible) while min is infeasible for 0.33–0.80 of ranks 3–30 and plurality/Condorcet/Borda ordinal shares are in `main_groups.csv` / `ollb_matched_sample.csv` (OLLB ordinal sample: feasible 0.16 Condorcet – 0.67 mean). On HELM, the 11–30 bin is infeasible for 1.00 (mean, min), 0.95 (median), 0.65 (plurality). h*/q with q the **pooled** q95 gain 25.3 points: median ratio over all HELM non-leaders 0.25–0.88 (share with h* > q 0.03–0.39; min highest) and over all OLLB 0.7–1.4 (share > q 0.0 for min, 0.48–0.82 for the others, driven by the >100 bin; ranks ≤ 100: median ratio ≤ 0.35, share > 1 = 0). With the transferred MMLU-PRO value (3.21 points, `emp_caps.csv`) used as q on HELM the ratios exceed 1 for 31–100-ranked targets (median 2.8–8.3) and for 11–30 (1.1–4.6): the per-task caps of the empirical measure are the restrictive version (hence the high infeasible shares), the pooled scalar the permissive one. OLLB ordinal h* is in the same file for the 102-target stratified sample (`ollb_hstar_ord.csv`; weighted median h* 6.7 Borda, 12.4 Condorcet, 15.6 plurality points; share above the pooled q95 0.16 / 0.19 / 0.16; one Borda row censored, rank 4496) and, for all 99 targets of ranks 2–100, in `summary/ollb_hstar_ord100_groups.csv` (medians 5.3 / 9.4 / 13.9 points; no target infeasible or censored). These are statements about observed fine-tune gains as a proxy, not about any developer's capability.
* **C2 under convex cost** (`summary/convex_cost.csv`; linear column reproduces the main-grid L1 to 5e-13; exact solutions checked against SLSQP): the minimum rule stays cheaper than the mean for most targets. HELM (78 targets): median cost ratio min/mean 0.147 (linear), 0.170 (quadratic in points), 0.086 (log-headroom); min cheaper for 100 % / 97 % / 100 % of targets. OLLB ranks 2–100 (99): 0.283 / 0.270 / 0.251; min cheaper for 100 % / 88 % / 100 %. Under the quadratic cost, 27 % of the high-CV OLLB tercile have the mean cheaper than min (median ratio 0.45 there, upper quartile 1.01). The ratio still rises with the CV tercile in every case (HELM quadratic 0.086/0.150/0.202; OLLB quadratic 0.087/0.241/0.453); Spearman with CV 0.52 (HELM quadratic, weaker than linear 0.92), 0.68 (OLLB quadratic). Caveat: costs are stylised and per-task cost scales are equal, so this tests the shape (convexity), not task-specific price differences.
* **Robust margins** (`summary/margin_robust.csv`): C2 at eps 0.1 and 1 is unchanged (HELM median ratio 0.147 / 0.151 vs 0.147 at 1e-3; OLLB ranks 2–100 0.284 / 0.288 vs 0.283; min cheaper for 100 %). With rule-specific margins (mean/median 2, min 8 points; roughly the extra d95 of each rule) the ratio rises to 0.269 (HELM) and 0.505 (OLLB) — min is still cheaper than the mean for every target, but its advantage halves, because min needs a much larger margin to stay first. Under those margins the gain10 feasible share of min falls to 0.04 (HELM) and 0.06 (OLLB) (mean 0.19/0.50, median 0.41/0.61), so C5's order becomes median > mean > min on both datasets (at eps 1e-3 on OLLB: mean > median > min; HELM unchanged: median > mean > min). C3 (HELM task subsets, gain10): the median rule is never cheaper than min in K/n at any n at eps 1e-3, 0.1 or 1 (differences median−min ≥ 0 at n = 5…57).
* **Cluster bootstrap** (`summary/cluster_bootstrap_ollb.csv`): 4496 OLLB models fall in 3870 clusters by `Base Model` (3777 singletons; largest 112); 16 % of models share a cluster with another. Cluster intervals are only slightly wider than the target-level ones and change no conclusion: C2 median ratio 0.251 [0.247, 0.256] (target-level [0.248, 0.253]), by CV tercile 0.197 / 0.243 / 0.352 with the high tercile [0.342, 0.355]; C4 R²(gap)−R²(rank): geomean +0.032 [0.029, 0.036], harmonic +0.020 [0.017, 0.023], median +0.020 [0.010, 0.035], min −0.005 [−0.008, −0.002]; Borda +0.018 [−0.005, 0.049], Condorcet −0.008 [−0.019, 0.008] on the ordinal sample (not distinguishable from 0 either way). HELM has no cluster field (79 independently submitted API models), so its intervals stay target-level.

## Failed / abandoned runs and corrections (kept for the record)
* OOM (exit 137): first ordinal OLLB jobs at `ceil` (dense float64 constraint matrices); fixed by chunked float32 matrices, ordinal grids re-run per cap on the sample. Earlier ordinal outputs were discarded.
* A faster trimmed-mean MILP that fixed the upper block as the top-t values was wrong (infeasible when tau+eps > u); reverted to the general 2n-binary formulation, results from it were discarded. HELM n=57 trimmed MILP is too slow for all targets → 36-target sample, 4 censored rows (above).
* Early drivers counted solver time-outs as infeasible and returned NaN Condorcet ranks for M>400 (found in an independent feasibility review): fixed (censored = NaN, vectorised Copeland rank), all affected jobs re-run.
* The empirical-gain cap table was recomputed per target (very slow): cached; `ollb_score` stopped and re-run.
* Several jobs show `failed` (exit 2/1) in the scheduler although their Python had finished and the CSV is complete: `run_all.sh` was edited while they ran (bash re-reads the script). Affected: `helm_main`, `helm_flip`, `helm_spill`, `ollb_spill`, `ollb_ord_gain10`, `ollb_ord_emp95`, `ollb_ord_emp99`, `ollb_ord_gain20`, `ollb_trim_ceil`, `ollb_trim_front0`, and others; each output was checked for the expected row count.
* The first noise/bootstrap runs (`*_noise_gain10.csv`, `helm_taskboot_gain10.csv`) use the 10 targets of ranks 2–11. They are extended by rank-stratified samples (`*_t30.csv`: 33 HELM and 30 OLLB targets over ranks 2–11 and log-uniform in rank, 100 draws), summarised in `summary/noise_*_t30.csv` and `summary/taskboot_helm_t30.csv`; the paper uses the stratified samples for statements beyond the top ranks.
* OLLB sub-task granularity (BBH/MMLU-PRO sub-tasks) was **not** done; HELM's 57 subjects stand in for many-task behaviour.

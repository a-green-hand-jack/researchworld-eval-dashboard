# IRT comparator fidelity

The permitted tinyBenchmarks paper was consulted directly at arXiv:2402.14992; access/provenance are recorded in `notes/literature_access.json`. Section 3 defines correctness-embedding cluster anchors exactly as implemented in `anchor_estimator`: source response vectors, k-means, closest actual member to each centroid and cluster mass as weight.

The first pilot's Rasch model is a regularized one-parameter comparator, not a reproduction of tinyBenchmarks. A stronger comparator in `src/benchsmall/mirt.py` now uses multidimensional 2PL observation probabilities sigmoid(theta_model @ a_item + b_item), the p-IRT total that preserves observed outcomes and imputes only unobserved ones (paper equation 4.3), and clustering embeddings (a_item,-b_item) corresponding to the paper's sign convention. Dimensions 2,5,10,15 match the paper's validation grid. Numerical finite differences independently check the joint likelihood gradient (`tests/test_mirt_gradient.py`).

Inference is an explicit adaptation: Gaussian MAP with fixed penalty, deterministic randomized-SVD initialization and L-BFGS, rather than the paper's variational hierarchical Gaussian fit. Target ability fitting is MAP rather than unpenalized MLE; this keeps all-zero/all-one response cases finite and is reported. We must label these comparisons MAP-MIRT / adapted p-IRT, not claim exact reproduction of the published end-to-end tinyBenchmarks method. A gp-IRT-style validation-selected convex blend can be implemented but should likewise disclose its mixing-tuning departure from the paper's training-bias heuristic. No fit result is inferred before its timed resource job completes.

Development-only timing/convergence pilot job: command `OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 PYTHONPATH=src python3 -u scripts/pilot_mirt.py`. It runs three datasets and all four dimensions and never evaluates locked target models. Its result will determine whether the current optimizer needs correction and the full fit budget. All convergence flags are retained; maximum-iteration fits are not silently called converged.

# Original research request

研究任务：表格模型上 SHAP 特征归因的重复运行可靠性。

SHAP 被广泛用于为高风险场景（信贷、医疗等）中的模型决策提供理由。在实际部署中，SHAP 通常依赖随机近似算法估计，并受计算预算限制，因此同一个训练好的模型、同一个输入实例，多次运行解释器可能得到不同的归因向量。实践中常见的做法是对一个实例只运行一次解释器，并把所得特征归因作为该预测的依据。这种做法在什么条件下足够可靠、在什么条件下不够可靠，目前缺少系统的实证证据。研究需要回答：对一个训练好的表格模型，单次运行所得的 SHAP 特征归因在多大程度上可以被当作该预测的可靠依据；这一判断需要依据哪些度量和比较标准；结论在哪些条件下成立、在哪些条件下不成立。

期望：可复现、多公开表格分类数据集、多种模型；明确可检验论断；足够支持或反驳的证据；不确定性；如实报告负面和不确定结果、局限。CPU 为主，总算力约24 CPU小时、一周、存储数GB、无需付费API。

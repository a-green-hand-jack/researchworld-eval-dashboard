# Prospective implementation decisions (before prediction errors)

2026-11-02. The planner protocol is a proposal, not a preregistration service. This file freezes implemented deviations before any train/validation/test reconstruction errors have been computed.

- Main implementation is written directly, no code-agent delegation or human mode choice needed.
- Initial candidate panel: 32 named English tasks in src/data.py, spread over seven task categories, declared before parsing scores. Within that list, availability/group-coverage ranking as in the planning protocol yields 29 tasks, 60 complete models, 19 anchor groups. Three dropped tasks are identifiable in panel_manifest selection audit. Choice uses masks, not score magnitudes.
- Conservative groups union all same-owner models and explicit adapted_from edges, even across owners and through shared external bases. This is a submitter/base-component split, not certified complete family identity. Unknown ancestry remains a limitation.
- Because 19 anchor groups cannot support 60/20/20 plus six validation and six test groups, reserve exactly six anchor groups for validation and six for test; remaining seven for training. Non-anchor-only groups split 60/20/20. This larger validation/test fraction is fixed using metadata before model fitting; train includes incomplete models from train groups. OpenLLM uses 60/20/20 group splits (many groups). All five seeds 11,23,37,53,71.
- No inferential claim treats overlapping repeated splits as independent. Seed11 confirmatory family/submitter-component comparison; other seeds robustness. Inferential claims conditional on fixed fit and imperfect group metadata.
- Gaussian EM uses group-balanced weights, training observed mean/SD, shrinkage each M step, 80 iterations max and relative change stop 1e-5. It is a regularized fixed-point estimator; no unpenalized likelihood convergence claim. Shrinkage grid .1,.3,.6,.9. Factor observed-entry ALS rank2,4,8 (clipped), ridge .01,.1; 40 iterations max. Fit weighting by group matches macro-group evaluation.
- Same random 20 nested task permutations shared across mean/Gaussian/factor; average losses, never predictions. Main budgets 0,1,2,4,8,ceil(p/4),floor(p/2),p; optional six-task replication includes3. Primary confirmatory k=ceil(p/4)=8 for MTEB, and2 for OpenLLM (secondary only).
- Primary common-suite family-balanced RMSE has observed entries exact. Actual unseen RMSE and pairwise common-unseen risk reported to expose target-set changes. No averaging prediction errors at query coordinates.
- OOF validation-greedy uses three inner grouped folds and only complete train anchors as targets; all training-fold incomplete histories are retained. Each inner Gaussian fit uses outer validation-chosen shrinkage, a disclosed validation-to-training design interaction; test remains untouched.
- Adequacy: declared 2 full-suite/3 unseen score-point thresholds, family bootstrap with 2000 draws and Bonferroni one-sided bounds over budgets/endpoints; minimum6 validation groups. No passing budget is valid evidence. No test-driven tolerance edits.
- Controlled masks only complete training-anchor scores: MCAR100/50/20%, MNAR high/low-favored approx50% via logistic z coefficient +/-1.5. Keep test cohort fixed, main tuned hyperparameters fixed. Ablations diagonal/no-shrink/complete-case. Budget8 and14 for MTEB. Bounded experiments are exploratory beyond primary fixed budget/split.

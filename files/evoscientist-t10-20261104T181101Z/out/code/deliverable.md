# 产出要求

## 提交物

1. 一篇完整的研究论文（PDF 与 LaTeX 源文件）。从 ICML、ICLR、NeurIPS 中自选一个会议，使用该会议最新一届的官方 LaTeX 模板，遵守其正文页数上限（参考文献、附录是否计入页数按该会议的规定）；该会议要求随文提交的 checklist 一并填写。论文至少包含摘要、引言、相关工作、方法、实验、讨论与局限、参考文献。
2. 全部代码与复现说明：环境与依赖版本、数据获取步骤和所用数据的版本、随机种子、运行命令和预计耗时，以及论文中每张表、每张图由哪个脚本生成。

## 评审标准

论文按所选会议主会的审稿标准评审，重点看：新颖性与定位；严谨性；证据是否充分；表达与可复现；如实讨论局限。负面结果、与预期不符的结果同样有价值；结论有充分证据、不确定性报告完整，比结论本身是正面还是负面更重要。

## 如实报告（禁止编造）

- 每个数字、每张表、每张图必须来自本任务实际运行且随附代码可重新产生的结果；不得编造数据或结果，不得用占位数字、估计值或“示意”合成结果冒充实测结果。
- 失败运行、与预期不符结果和放弃方案如实报告；预算内未完成的实验写明未完成，不写成已完成。
- 只引用真实存在且确实查阅过的文献，不得编造引用。

## 不得访问的内容

本研究问题已有一篇已发表论文研究过。为保证独立，不得检索、访问、阅读或使用：

- 那篇论文本身，及任何镜像、预印本、摘要页、会议或评审页面、幻灯片、海报、视频、博客和代码仓库；
- 引用、讨论或复现那篇论文的任何页面，包括后续论文、综述、论文笔记、聚合站点和社交媒体讨论。

也不要推测或检索那篇论文的标题、作者或结果。起步文献，以及与其无关的其他公开文献、数据和代码，可以正常使用。若检索中偶然遇到，立即停止阅读，并在复现说明如实记录遇到了什么、在哪里、读到了多少。

# Protocol deviations and reporting decisions

## 2026-11-04, after the frozen main sweep and before manuscript drafting

- **Pilot/main RNG overlap (verified):** RNG keys distinguish purpose, method, budget, repeat, fit and instance, but omit stage. All 864 pilot attribution vectors are reused bitwise as the corresponding first eight main repeats. German split references are also shared, and the six main 4,096-pair audits extend the pilot's 128-pair prefixes. This violates the prospective no-pilot-draw-reuse statement. Original outputs and seed mapping are retained. The pilot served correctness/throughput assessment; primary success rates were not calculated for scope selection. There is no independent pilot/main confirmation claim. Within-main 64 repeat streams remain distinct. Main inference uses the main dataset only, never adds pilot repetitions to sample size. See analysis/findings_evidence/pilot_main_overlap.csv. A protocol-conforming fresh replication is not claimed.
- **Reference chronology:** Runner constructs references and main attributions within each task, not separate global phases. It does not score main accuracy there (only numerical efficiency). All648 tasks and the full216-task German reference gate, including six4096-pair audits and the escalation-rule file, completed before analyze_results.py first scored accuracy. Reference flags were never selected using main accuracy. All216 qualified; escalation was not triggered. A pilot128-pair audit failed for German/HGB/slot0 but the full4096-pair audit passed; the pilot audit is not substituted for the required main audit.
- **Tie implementation:** The recorded implementation rounds absolute magnitudes to12 decimals then applies stable original-feature order, rather than a pairwise tolerance comparison. This deterministic quantization convention is used in every metric and disclosed in the paper.
- **Numerical diagnostics:** Four huge finite low-budget no-l1 SHAP0.49.1 errors were retained unchanged. Additional same-mask SVD diagnostics are post-hoc explanatory analyses, not replacements and not a new primary competitor. Defaults/no-l1 use distinct RNG streams and are not paired causal comparisons.
- **Secondary derived contrasts:** Paired method contrasts and reference-audit label sensitivities in findings_evidence are exploratory descriptive calculations, not newly preregistered confirmatory tests. No p-values or superiority claim.
- **Cost accounting:** Instrumented task CPU excludes package installation, source acquisition, startup outside timed task sections, analysis and TeX. State that boundary, rather than asserting that instrumented time proves total-project CPU accounting. No GPU used; a conservative fresh full-pipeline timing verification is provided separately when available.
- **Data terms:** OpenML37's literal 'Public' label is not a concrete license. Census API terms were read at the explicit pointer from supplied folktables paper; bulk PUMS are not falsely claimed MIT/API-licensed. No re-identification or linkage attempted. Source datasets are not relicensed under the study code license.

Original prospective plan.md remains unchanged. protocol_amendments.md also records pre-outcome choices.

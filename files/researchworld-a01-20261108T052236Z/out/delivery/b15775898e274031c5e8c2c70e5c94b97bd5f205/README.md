# How much does it take to top a multi-task leaderboard?

Delivery of the study of *minimum targeted investment* on public multi-task leaderboards (HELM MMLU v1.13.0 and the Open LLM Leaderboard): how many score points, on how many sub-datasets, one target model needs to rank first when the other models are fixed, and how this depends on the aggregation rule and on the cap on per-task gains.

## Reproduction
1. Environment: Python 3.11.2, numpy 2.4.6, scipy 1.17.1, pandas 3.0.6, pyarrow 26.0.0, pytest 9.2.0, TeX Live (latexmk, bibtex). 2 CPUs, 4 GB suffice.
2. Data and analysis: `cd analysis && bash run_all.sh fast` (about ten minutes: data, tests, theory check, HELM headline grid) or `bash run_all.sh full` (about 8 CPU-hours, jobs are independent). Data sources, commits and checksums: `analysis/README.md` and Appendix A of the paper.
3. Figures and tables: `python3 presentation/render.py --analysis-root analysis --out-root .`; check with `python3 presentation/validate_assets.py`.
4. Numbers and the script map in the paper: `python3 paper/scripts/make_numbers.py` and `python3 paper/scripts/make_map.py`.
5. Paper: `cd paper && latexmk -pdf main.tex`. The main text is within the 9-page limit; references, the reproducibility statement's pointer, the appendix and the AI use statement follow.

Script-to-output map for each figure and table: Appendix A, Table "Script-to-output map" in `paper/main.pdf`. Data versions, seeds, licence judgement and run times: Appendix A.

## Forbidden material
The task withholds one published paper and any page discussing it. The log, with what was and was not encountered, is `context/FORBIDDEN_LOG.md`.

## Limits stated in the paper
Cost is measured in leaderboard points, not data, compute or money; one deviating developer with fixed rivals; two leaderboards; ordinal rules on the OLLB are run on a rank-stratified sample of 136 targets; the OLLB sample is a deterministic rank grid (no seed), and the first noise and bootstrap runs used the script default seed 0 (re-runs with the study seed and redrawn samples are in `analysis/results/seeds/` and Section 4 of the paper); see the paper's discussion and `analysis/README.md`. `analysis/docs/HANDOFF.md` defines g*, the 36-target replay, the cluster bootstrap and the normalised costs added after external review.

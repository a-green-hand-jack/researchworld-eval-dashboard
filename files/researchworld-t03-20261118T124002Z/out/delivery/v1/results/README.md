# results/

Machine-readable result files; see `STATUS.md` for what exists. Schema notes are added here with each file.

`tidy_<cell>_R20.csv` (one row per instance x arm x budget x k, from `scripts/summarize_cell.py`):
cell, inst, arm, budget (xMULT of 2d+2048 coalitions), k, N (mean coalitions used), sec, r (P[top-k set = exact]), r_eps10/r_eps25 (epsilon-tolerant),
r_sign, jacc (mean pairwise Jaccard of reruns), nog (Nogueira stability), rbo, rel_l2, rel_bias (|| mean estimate - phi* || / || phi* ||),
gap (k-th minus (k+1)-th |phi*|), sd_gap (rerun SD of the boundary difference), z_true = gap/sd_gap, mean_ok (top-k of the *mean* estimate is exact: separates bias from noise), nvar (varying attributes), R.
`plugz_<cell>_R20.npz`: per-run plug-in z from the single run's own Covert-Lee SE (arrays zplug/<budget>/k<k>, ok/<budget>/k<k>, shape instances x R).
Cell id = `<dataset>_d<sub|full>_<model>_s<seed>`.

Column `d` = attributes of the cell (after feature subsetting); `nvar` = players of the Shapley game for that instance (attributes on which x differs from the background; use `nvar` as the number of players).

Planned files (written when the stage has run; schema fixed now):
- `instances_<tag>.csv`: cell, inst, arm, k, delta, Bstar_emp (smallest grid budget with r >= 1-delta; NaN = not reached by x16, flag `censored`), Bstar_pred (c * sigma^2/gap^2, c fitted per cell), r_R200 and Clopper-Pearson lo/hi for the R~200 subset (`in_r200` flag).
- `yardstick_<tag>.csv`: cell, inst, d_rerun, d_bg, d_retrain_seed, d_retrain_boot (1 - top-3 Jaccard), n_bg, n_retrain_seed, n_retrain_boot, n_dropped_by_equal_acc_filter (|AUC diff| > 0.01), with the AUC range of the retrains kept.
- `certificates_<cell>.csv`: rule (naive/bonf/maxt/split/shapk), delta, k, inst, R, n_certified (some stage of the 7-stage schedule certifies), n_correct_among_certified (run correct at its stopping stage, fresh reruns), mean_stop_coalitions, plus pooled `certificate_coverage.csv` with cluster-bootstrap CIs.
- `fixed_budget_<cell>.csv`: the fixed-budget comparator at equal pooled correct rate.
- `bias_variance_<tag>.csv`: per cell and d, share of default-KernelSHAP top-k errors due to truncation bias (mean_ok == False) versus sampling noise.
- `cells_not_run.csv`: planned cell, reason.

E5 files (written by `scripts/summarize_certs.py`; the fixed-budget comparator is the Covert-Lee stream stopped at each fixed stage):
- `certificate_coverage.csv`: group, rule, delta, k, n_inst, n_seeds, certified_share (runs that certify at some stage), correct_given_certified with cluster-bootstrap CI, target = 1-delta, calibration (calibrated / miscalibrated / inconclusive by the protocol rule), pooled_correct_delivered (stop at first certified stage, else deliver x16), mean_cost_all (coalitions, uncertified runs at the maximum), fixed_cost_same_rate (cheapest fixed grid budget with at least that pooled correct rate; NaN = none).
- `fixed_budget_pooled.csv`: group, k, stage, coalitions, pooled_correct.

Added with the pooled analysis (all preliminary until STATUS.md says final):
- `verdicts_<tag>.csv` columns: group, arm, k, budget (the arm's shipped default), d, n (instances x seeds), n_seeds, mean_r with 95% CI (r_lo, r_hi), U_delta10 (share of instances with r < 0.9) with CI, U_delta05, spearman_r_ztrue, auc_plugz_instance/run (Covert-Lee arm only), nog/nog_lo/nog_hi (mean Nogueira stability between reruns, no phi* needed), rbo, jacc (mean rerun RBO and Jaccard), C1_outcome (protocol outcome; kshap_default and perm at k=3), C5_bias_share (share of unreliable instances, r < 0.9, whose mean estimate has a wrong top-k, i.e. bias not noise; d >= 11, any arm), C2_* (B*(x) spread and Spearman for delta = 0.05 / 0.10).
- `bias_variance_<tag>.csv`: as above per group x arm x k (column `arm` added).
- `cost_at_equal_reliability.csv` (`scripts/compare_cost.py`, k=3, delta=0.1): per group, certificate rule and arm, the cheapest fixed budget of that arm whose pooled P(top-3 exact) >= the rule's pooled correct rate (`cert_pooled_correct`), with its mean coalitions (`fixed_cost`) against `cert_mean_cost`; plus the shipped default's cost and pooled correct rate (`shipped_*`). NaN = no fixed budget of that arm reaches the rate.
- `cost_at_equal_reliability.csv` column `comparison`: `same_estimator` (the certificate against fixed Covert-Lee stages of the same stream) comes first, then `across_estimators` (against fixed shipped KernelSHAP, l1-off KernelSHAP and Permutation).
- `yardstick_<cell>.csv` / `yardstick_summary.csv` (`scripts/summarize_yard.py`, E4/C3): per instance d_rerun (rerun disagreement of the shipped estimator: mean pairwise 1 - top-3 Jaccard between its R reruns), d_bg, d_retrain_seed, d_retrain_boot (mean pairwise 1 - top-3 Jaccard of the exact phi* across background resamples / retrains with |AUC - AUC of the audited model| <= 0.01). Summary per group x arm (kshap_default, perm) x reference: n_inst, share_rerun_lt_ref (the registered strict share, with Clopper-Pearson ci_lo/ci_hi), share_ties (rerun = reference, mostly both 0), share_rerun_le_ref_sensitivity (non-strict, a labelled sensitivity, not the registered test), mean_d_rerun, mean_d_ref, supported (strict share >= 0.75 and ci_lo >= 0.6). For LR the seed variant is vacuous (deterministic fit), so `d_retrain_boot` is its retrain reference.
- `oracle_tightness.csv` (`scripts/oracle_tightness.py`, R~200 subset of 30 instances spread over the quantiles of r, covert_lee stages x0.25 / x1 / x4): per cell, k, stage, delta, rule: `oracle_share` (instances with r_k(x;B) >= 1 - delta from R=200 reruns), `cert_share` (share of the R=20 certificate runs certified at some stage <= this one), `cert_share_oracle_ok` (power within the oracle-certifiable instances), `cert_share_oracle_not_ok` (certifications on instances the oracle would not certify).
- `r200_subset.csv` (`scripts/summarize_r200.py`): per cell, inst, arm, budget (x0.25 / x1 / x4, perm500), k: `r_R200` (R=200 reruns) with Clopper-Pearson `r200_lo`/`r200_hi`, the R=20 estimate `r_R20` of the same instance, gap, z_true, nvar, d. `r20_in_cp200` says whether the R=20 estimate falls in the R=200 interval; it is not expected to be 0.95 (the R=20 estimate has its own binomial noise, SD up to 0.11).
- `r200_agreement.csv`: per cell, arm, budget, k, delta: the share of the 30 instances called reliable (r >= 1 - delta) by R=20 and by R=200, their per-instance `call_agreement`, `mean_abs_r_diff`, `cp_cover_R20`. The 30 instances are equally spaced quantiles of r (kshap_default, k=3, x1) from the R=20 data, so shares on this subset are not the population shares; use the R=20 grids for those.

`e7_controls.csv` (E7, no new runs; from the R=20 grids): cell, arm, budget, k, n_inst, global_exact (share of the R=20 sets of runs, one run per instance, whose *global* top-k set by mean |phi| over the first n_inst instances equals the global top-k of the exact phi*), global_nog (Nogueira stability of those R global top-k sets), mean_instance_r (mean single-instance r_k over the same n_inst instances). The arm `chance` row gives 1/C(nvar,k) averaged over instances (P that a random k-set is exact).

d-curve (preliminary until STATUS.md says final):
- `dcurve_summary.csv` (`scripts/dcurve_summary.py`, from `verdicts_R20.csv`, k=3): per dataset x model x output `scale` (`prob` = P(y=1|x), exact tables; `logit` = raw GBDT margin, a single-seed control, live TreeSHAP for d above 20) x d: shipped-default / l1-off / Covert-Lee at x1 and permutation at 500 evaluations, mean r_3 with CI, U_delta10, Nogueira, protocol outcome, bias share. Cell id suffix `_logit` marks the margin scale (`<dataset>_d<sub|full>_<model>_logit_s<seed>`); LR/MLP have no margin-scale variant (their tables are probability-scale closed forms).
- `tidy_<cell>_T2.csv`, `plugz_<cell>_T2.npz`, `verdicts_T2.csv`, `bias_variance_T2.csv`, `instances_T2.csv`: Tier 2 Leverage SHAP arm (`arm` = leverage; same grid, same columns); one file set per cell as the R=20 files. Preliminary: cells still running are missing from the pooled files.

## c5_split_R20.csv
C5 three-way split of the unreliable instances (r_3 < 0.9 at the x1 budget) of the shipped KernelSHAP default, per group (dataset, d, model; seeds pooled). Columns: `trunc_bias` (mean attribution of the default runs has the wrong top-3 and the paired `kshap_l1off` mean has the right one), `other_bias` (wrong under both), `noise` (default mean right; runs scatter) with `noise_gap_lt_sd` / `noise_gap_ge_sd` (z_true = gap/sd below / at-or-above 1; a descriptive threshold, not a fitted one); the three main shares sum to 1; `_lo`/`_hi` are 95% cluster-bootstrap CIs (seeds, then instances). `n_unreliable` is small for most d<=16 groups (CIs are wide); groups with no unreliable instance have NaN shares. Produced by `scripts/c5_split.py`. Live Arrhythmia d=40 is 1 seed x 20 instances.

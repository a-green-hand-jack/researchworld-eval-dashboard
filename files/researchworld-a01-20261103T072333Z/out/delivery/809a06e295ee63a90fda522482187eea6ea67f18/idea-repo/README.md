# Objective and prior-work context

The wiki **Brief** records the authoritative objective and constraints read from all five frozen task files. **Literature** supplies checked source identities, substantive prior-work context, conventions, claim limits and the context judgement of the settled study plan. Both are also published in release **context-v1**, with a checked bibliography and retrieval manifests, for positions without code access.

- [Brief](notes/Brief.md)
- [Permitted-literature synthesis](notes/Literature.md)
- [Checked bibliography](notes/checked-references.bib)
- [Context provenance and reproduction](notes/Context-reproduction.md)
- [Frozen-input hashes](notes/frozen-inputs.json)
- [Direct source manifests](sources/)

No third-party PDFs are redistributed. `python3 scripts/fetch_context_sources.py --out-dir retrieved-context` re-downloads direct consulted documents and flags hash drift. All source-reading limits are explicit. The study analyzes score-space task support, not measured training cost or actual contamination in leaderboard entrants. This position owns context; experiment-repo owns empirical validity and paper-repo owns the final manuscript.

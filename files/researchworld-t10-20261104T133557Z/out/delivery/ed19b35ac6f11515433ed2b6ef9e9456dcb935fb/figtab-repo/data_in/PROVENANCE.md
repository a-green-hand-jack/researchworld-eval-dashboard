# Provenance of files in results/
(one line per file: producing command, seeds, reps; code revision = the commit that last changed the script, see git log of this path)

- `headroom_population.csv` — `python3 code/headroom.py` (population headroom, 10 split seeds; sd over splits).
- `theory_synth.csv` — `python3 code/theory_synth.py`; 400k-sample population, seed 0.
- `datasets.csv` — `python3 code/dataset_table.py`.
- `NOTES.md` — findings (read from the summaries below), method naming, sampling protocol.
- `headline_mean_real.csv`, `headline_synth.csv`, `headline_ols_real.csv` — compact like-for-like ratio and coverage tables made by `code/headline.py` from the summaries.
- `summary_validity_real.csv` — `python3 code/summarize.py /hutian/scratch/raw/valid_real results/summary_validity_real.csv` (baseline ppi++); raw from `code/grid_valid_real.sh` (7 pools, n in {15,25,50,100,200,500}, N=min(pool,20000), 2000 reps, base seed 5; methods: classical/PPI/PPI++ with Wald, t, studentised bootstrap; no adjusters).
- `summary_ballots_sub.csv` — summarize.py on raw from `code/grid_special.sh` (case ballots_sub: labeled and unlabeled drawn inside the 1027 labeled ballots, truth = their mean; n in {25..400}, 1000 reps, base seed 9). Coverage is high (0.98-1.00) because the finite population fixes the truth; not a validity test of the iid theory.
- `summary_ballots_width.csv` — same, case ballots_width (labeled from the 1027, unlabeled = the 78,150 Yhat_unlabeled with no Y; 1000 reps, seed 9, `WIDTH_ONLY=1` so coverage columns are empty): widths only.
- All `summary_*.csv`, `theory_vs_measured.csv`, `breakeven_*.csv`, `cells_done.csv` are regenerated by `code/summarize_all.sh` from the raw rows (`summarize.py`, baselines: `ratio` vs Wald PPI++, `ratio_lfl` vs PPI++ with the same calibration). **Grids are delivered while they run: `cells_done.csv` lists exactly which (dataset/scenario, n, N, rho) cells each file contains and their replicate counts; a cell not listed has not finished.**
- `summary_mean_real.csv` — raw from `code/grid_real_main.sh` (mean CIs; census_income, gene_expression, galaxies, forest n in {50,100,200,500,1000}, 2000 reps, base seed 1, N=min(pool,10000), BOOT=1; appendix pools alphafold/census_healthcare/census_education n in {100,500}, 1000 reps). Methods: classical, ppi, ppi++, cf_{lin_f,iso_f,poly_f,gbm_f,lin_fX,gbm_fX}, each with Wald, `_t`, `_boot` (studentised bootstrap, 999 draws).
- `summary_rho_real.csv` — `code/grid_rho_main.sh`: census_income, n=200, N in {200,2000,20000}, 2000 reps, base seed 7.
- `summary_synth.csv` — `code/grid_synth.sh`: synthetic knob0/30/60/90 (n 50..1000, rho 1 and 0.1, 2000 reps) and the named scenarios (n 50/200/500, rho 1 and 0.1, 1000 reps), base seed 2, with the `oracle` interval; truth known.
- `summary_ols_real.csv` — `code/grid_ols_main.sh`: OLS coefficients on census_income (n 50..1000, N=10000, 2000 reps, base seed 3); column `coord` indexes the coefficient; baseline `ppi++_lib_c<j>` (ppi-python 0.2.3 `ppi_ols_ci`).
- `summary_plankton_noshift.csv`, `summary_plankton_shift.csv` — `python3 code/run_special.py plankton_{noshift,shift} n 2000 9` (see `code/run_special.py` header: within-2013 validity vs 2013->2014 shift stress test, N=10000), n in {25..1000}, 2000 reps, seed 9.
- `theory_vs_measured.csv` — `code/derived.py`: measured paired ratio of synthetic cells next to the asymptotic prediction of `theory_synth.csv`; `excess_over_prediction` = measured/predicted. `breakeven_synth.csv`, `breakeven_real.csv` — `code/derived.py --breakeven`: smallest n in the grid at which the adjuster's like-for-like ratio CI lies below (gain) / above (loss) 1; empty = not within the grid.

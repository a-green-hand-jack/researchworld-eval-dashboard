# Frozen plan and reporting protocol
Date 2026-11-02; specified before real response generation.

## Narrow story
The reported finite benchmark score is observable, but it is not an unbiased estimate or a calibrated confidence statement for the population accuracy of a configuration chosen on those same items. Separate winner accuracy, population maximum, selected improvement, and accuracy on an independent audit. No new general post-selection theorem or optimizer is claimed; contribution sought is a reproducible estimand-aware empirical diagnostic and practical reporting protocol using classical baselines.

## Data firewall and resources
- No GPU detected; API returned a successful real response under `gpt-5.6-luna`. This is a provider identifier, not verified underlying architecture. Freeze this model, temperature 0, max_tokens 16, no demonstrations, no training.
- Freeze 12 format/instruction candidates before inference: 3 instructions x 2 headers x 2 choice delimiters. Candidates do not depend on question labels or outcomes. Search is exhaustive argmax with first-index tie break; also predeclared successive halving within the same family.
- Sample 80 test items per each of 14 categories, seed 20261102, revision b189ec765aa7ed75c8acfea42df31fdae71f97be. Target is equal-subject mixture, NOT official micro-average. All real responses saved, parser frozen strict A-J letter, invalid/truncated counted wrong. Validation unused.
- Full bank score matrix permits iid with-replacement empirical-population replay with known finite-distribution means. This is internal calibration, NOT proof of coverage on genuinely novel-world questions. Independent disjoint tuning/audit splits separately test empirical optimism/new-item generalization. Repeated splits are correlated and their MC error bars are conditional split randomness, not new inference or uncertainty over benchmark construction.

## Stage 1: baseline/data audit
Scripts `src/prepare_data.py`, `src/infer.py --pilot`, `tests/test_statistics.py`. Gate: correct revision/hash, category counts, valid parsing, actual API generation, immutable prompt manifest. Runtime depends API latency. Save `data/manifest.json`, `data/items.jsonl`, `configs/prompts.json`, `artifacts/raw/*.jsonl`.

## Stage 2: primary experiments
- Synthetic: correlated Bernoulli outcomes with known means; independently vary family size, n, latent cross-prompt correlation and tied/separated means. At least 1000 iid replications per condition. Seeds specified in script/config. Primary metrics: signed optimism, selected-winner 95% coverage, interval width, false claims of improvement over fixed baseline; MC SE reported. Stress near-boundary Bernoulli and duplicate candidates. Vary one factor for plotted comparisons; full grid secondary.
- Real: 1120 x 12 single-item API generations, resume via immutable cache. Bounded at <15000 successful item calls; no model-search. Run iid empirical replay for n=32/64/128/256 and K=1/4/12; disjoint tuning/audit for same n with large untouched remainder, 1000 splits each. Show candidate uncertainty, response invalidity, correlations, and reference-pool limits.
- Primary interval baselines: naive Clopper-Pearson, Bonferroni CP (finite-sample iid Bernoulli), simultaneous Hoeffding (bounded fixed family), paired centered Gaussian multiplier max band (asymptotic), independent-coordinate Gaussian max ablation, independent half-split CP (different winner). Exact methods not claimed tight; bootstrap not claimed exact.

## Stage 3: ablations and decision audit
Dependence-aware vs independent-column calibration, K=1 vs K>1, tied vs separated, n and correlation stress, near-0/1 variance failure, full-family selection vs successive halving. Compare selected improvement to fixed prompt with paired item differences. No unadjusted multiple-testing scientific claim: simultaneous inference or descriptive estimates; no retrospective threshold tuning.

## Stage 4: paper and verification
Official NeurIPS2026 style, <=9 main content pages, references/appendix/checklist excluded. Main tables/figures generated from actual CSV results; manuscript numeric macros generated by script. Formal results proved directly for fixed families only, explicitly outside scope for unrestricted candidate creation using test labels. Source allowlist audit and limitations included. Self-review, PDF page checks, pytest, clean CPU regeneration of statistics/plots.

## Claim-to-evidence / rejection risks
- 'Known phenomenon, limited novelty': explicitly use classical inference; focus on empirical regime map and concrete reported decisions, not inventing new theorem.
- 'No real LLM': save all generated raw responses and usage under actual provider model id.
- 'Truth unknown on curated benchmark': distinguish synthetic true coverage, empirical-population coverage, disjoint audit agreement. No broad population or contamination-free claim.
- 'Candidate adaptivity': simultaneous guarantees only over predeclared family, candidate generation from inference labels deliberately excluded; independent audit supports arbitrary prior tuning if untouched.
- 'Variance / small n': MC uncertainties, boundary stress and finite-sample baselines; bootstrap failure not hidden.

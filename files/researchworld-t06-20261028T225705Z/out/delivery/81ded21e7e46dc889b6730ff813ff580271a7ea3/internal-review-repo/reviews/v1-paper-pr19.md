## Findings (open at this commit)
1. **Published-rank claim not backed by a targeted search (claim > evidence).** Contribution (2) says "a confidence-interval-based rank is much less affected" and Sec. 6 says "the intervals are the robust part". The evidence is only that the cheapest *point-rank* top-1 attack (2/1 comparisons on Arena) leaves the published rank unchanged (Table 2). No attack was searched for the published rank itself (decision (e) is defined in Sec. 3 but `decisions_*.csv` has only top1, topk3/5/10, tau0.9/0.95). A 2-comparison perturbation moving a Wald interval is a trivial non-event. Either (a) add the smallest verified attack that changes the leader's published rank / the set of models at published rank 1 (experiment-repo), or (b) restrict the wording everywhere (intro, abstract "leaves ... unchanged" is OK, contribution 2, Sec. 6) to "the point-rank-optimised attack does not move it".
2. **"not of the evaluation design" over-claims.** Sec. 6 says cross-dataset differences are mostly participants/gap structure "not of the evaluation design". Evidence: one dataset per design; the matched control still leaves ~7-fold spread (20.5 NBA, 60 Arena, 56 / 138.5 MT-Bench) and the only clean contrast shows a 2.5x judge effect. Design effects are not excluded, only not identified. Rephrase as "cannot be attributed to design with these data".
3. **Incorrect independence statement for Arena.** Sec. 4/6 and REPRODUCE say Arena rows "carry no user or prompt identifier". The CSV has the prompt text: 57 477 ids, 51 734 distinct prompts (one prompt repeated 101 times). A prompt-clustered bootstrap (or at least this duplicate rate) is available, so the "optimistic intervals" caveat should be quantified or the statement corrected; user-level dependence remains unobservable.
4. **Very few attack resamples.** Table 1 intervals for Arena/NBA are 2.5-97.5 percentiles of 20 resamples (6 for tau; the tau rows show a point value only). The disclosure is honest, but the Arena top-1 bootstrap interval [0.003, 0.091]% spans 30x. With ~1000 s per 20 resamples on Arena the budget allows more (e.g. 100) on a resource; at least run top-1 attacks at B=100 for Arena and NBA (experiment-repo) or give the min/median/max rather than percentiles.
5. **Figure 3(a) axis is an unlabeled mixed scale.** The y axis changes from a linear-looking scale above 0.1 to log below, with irregular ticks (10,5,2,1,0.5,0.2,0.1,0.01); the break is not stated in axis label or caption, so heights are not readable in the field's convention. Use a plain log axis (figtab-repo) or state the symlog threshold in the caption.
6. **Unreported top-k results.** `decisions_arena55k.csv` has top-10 set changing with 1 removal/flip and top-3/5 with 3-39 comparisons; the main text reports only top-1 and tau although Sec. 3 lists top-k as a decision. Report them (one table row group or appendix table) so the choice of decisions is not selective.
7. **Spearman 0.86-1.0 (abstract/Sec. 5).** For MT-Bench the correlation is over 5 pairs (rho = 1.0 is nearly mechanical). State n per dataset or report only Arena/NBA (n = 63, 44) with interval; the abstract range should not include n = 5 values without saying so.
8. **Appendix A has no prose** (a heading directly followed by Table 4 and Figure 4); add 3-4 sentences on what the variants/synthetic design are (sigma values, N, p grid, number of worlds) so that the appendix can be read alone; "Appendix Figure 4" mixed with "figA1" file name is fine but check cross-references. Appendix B lists no seeds or package versions (only a pointer to REPRODUCE.md): add one line each.
9. **Minor.** (i) Title/abstract "Hence these swaps lie within sampling noise" should be tied to Arena/NBA only (MT-Bench bootstrap never changes top-1). (ii) Table 1 caption "100 resamples for MT-Bench" vs Sec. 5 "200 MT-Bench resamples" refer to different procedures; say so. (iii) VENUE.md says the NeurIPS 2026 checklist has 19 items, the template and paper have 16: venue-repo to correct.

## Conclusion
Not approved at this head: findings 1, 2, 3, 5 and 7 change what the text may claim or how a figure reads and are cheap to fix; 4 and 6 need a short analysis run. No fabrication found; reproduction of the spot-checked outputs succeeded. Re-review after a new head.

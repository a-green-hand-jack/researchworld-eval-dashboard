Exploratory mechanism experiment added after observing the primary width64/256 divergence (not part of the frozen grid): freeze first-layer row directions after1000 or10000 steps at widths64/256, decay1, same five seeds, full30k horizon (20 additional runs). The initial segment exactly matches the reference. Thereafter each AdamW update is followed by orthogonal projection of each W1 row onto its frozen direction, with a nonnegative coefficient. Individual row magnitudes, W2, and weight decay continue to update. Hence the ReLU feature directions and gates are fixed while radial changes and readout learning remain possible. This is preferable to freezing all weights because it permits magnitude cleanup, but is still a constrained-optimization intervention and cannot identify a unique circuit. Predictions before these exploratory runs: early direction freezing suppresses width256 generalization if ongoing direction learning is necessary; late freezing may retain it if sufficient useful features already formed. Both outcomes will be reported.

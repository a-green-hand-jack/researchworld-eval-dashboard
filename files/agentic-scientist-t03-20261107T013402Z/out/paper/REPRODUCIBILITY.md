# Reproducing the fixed-game SHAP study

## Measurement and source files

`paper_data.json` is the immutable measurement registry. Final qualification is independently completed/qualified/true; this is an execution/integrity/control outcome, not deployment validity. Main results use final episodes separately from development selection. No downstream-study object or additional task list exists. No new training, explanations, independent validation routines, or evaluator execution occurred during writing.

- `source_evidence/selected/`: retained structure-aware estimator, dispatch, response interface, specification and unexecuted independent validation routines.
- `source_evidence/sampled/` and `source_evidence/forest/`: matched development implementation snapshots.
- `source_evidence/evaluation/`: final/development evaluators, acquisition code, pinned requirements and data provenance.
- `task/resources/{search,final}/`: frozen records accessible through the supplied task link.
- `analysis_summary.json`: descriptive reductions of recorded observations, not additional experiments.
- `claims_grounding.json`: registry claim mappings and readable implementation evidence locations.
- `source_evidence/MANIFEST.json`: hashes of copied evidence, for provenance rather than substantive implementation support.

## Environment and public data

The supplied scientific environment has Python 3.12.15. Recorded requirements include NumPy 2.1.3, SciPy 1.15.3, scikit-learn 1.6.1, SHAP 0.48.0, pandas 2.2.3 and folktables 0.0.12. Their installed metadata was inspected. The complete pinned requirements are preserved, but a fresh installation was not tested:

```sh
python3.12 -m venv /tmp/shap-study-env
/tmp/shap-study-env/bin/pip install -r source_evidence/evaluation/requirements.txt
```

The evaluator requires Linux isolation, CPU affinity and Landlock/seccomp. A non-Linux port was not tested. BLAS thread limits are set in the evaluator; forest fitting uses one thread.

Exact acquisition URLs, digests, licensing, release metadata and normalization are in `source_evidence/evaluation/data_provenance.json`. German is UCI Statlog German Credit, DOI 10.24432/C5NC77, under CC BY 4.0. ACS uses actual 2024 one-year CA and NY PUMS releases, with native `RELSHIPP` replacing absent historical `RELP`, without an invented crosswalk. This is not unmodified historical ACSIncome. All cross-state predictor-content overlaps are removed before ACS selection; one representative per content group is retained with duplicate/conflicting-label provenance.

Use the frozen resources for offline reproduction. To recapture independently, download every `sources[*].url` to `/tmp/public-source/<sources[*].file>`, verify the recorded SHA256, then run:

```sh
python source_evidence/evaluation/capture.py \
  --source_dir /tmp/public-source --output_root /tmp/new-resources
```

No recapture was performed during writing. The frozen resources suffice for evaluation if upstream archives change.

Primary records and available abstracts were read; citing/reference graphs and related pages were not traversed. `literature_evidence/` preserves the selected records. An incorrect initial Owen DOI returned unrelated tuberculosis metadata; it was rejected immediately, never cited, and corrected to *Multilinear Extensions of Games*.

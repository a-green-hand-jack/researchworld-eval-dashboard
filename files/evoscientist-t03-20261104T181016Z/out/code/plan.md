# Preregister-like plan: single-run reliability of stochastic SHAP

Status: prospective planning only, 2026-11-04 UTC. No experiments, environment inspection, downloads, implementation, or outcome-dependent decisions were performed in this planning turn. Numerical work counts below are design arithmetic, not measured runtimes or findings.

## 1. Assumptions, scope, and priority decisions

**Question.** For a fixed fitted binary classifier, instance, empirical background, feature grouping, and computational budget, how frequently does one stochastic attribution run meet prespecified accuracy criteria? The estimand is reliability over explainer randomness for a particular finite empirical interventional game. It is not causal validity, human usefulness, model correctness, or reliability under model/background/data drift.

**Smallest defensible contribution.** A reproducible reliability audit with exact low-dimensional anchors, reference-qualified higher-dimensional evidence, and a demonstration protocol for testing whether repeated-run agreement is reassuring. No new estimator, superiority requirement, universal safe budget, or claim to be the first study. Null, favorable, unfavorable, and inconclusive results are equally reportable.

**Priority adjustments to the proposed design:**
1. Specify the actual sampled Kernel objective and rank-deficiency policy; sampling proportional to the kernel must not be followed by a second kernel weighting.
2. Treat ACSIncome10/Pima8 exact-game results as the primary anchor; label German20 references approximate and qualify every German accuracy claim using independent reference diagnostics. Never discard difficult instances silently.
3. Freeze equal-request budgets, count duplicate requests, and measure uncached runtime separately. A cache accelerates this study; it is not the cost of a normal single explanation.
4. Separate explainer repeats, test-instance sampling, and fitted-model variation. Three nominal training seeds need not yield three distinct functions, especially for logistic regression and histogram boosting.
5. Define composite success, ties, near-zero normalization, agreement events, and CI denominators before seeing reliability outcomes. Report component metrics, not only the composite.
6. Protect a complete exact-reference core and reference audits before extra datasets, extra explainers, or broader sensitivity grids. Gates concern correctness, feasibility, and evidence completeness, never a desired result.

### Finite empirical interventional game

For raw feature set N, d=|N|, define

`v_x(S) = (1/B) sum_b f(T(x_S, z_b,not-S))`,

where T is frozen train-fitted preprocessing, f outputs positive-class probability, and z_b are training rows. Empty/full values are v(empty) and f(T(x)); the full value is background-independent. The Shapley reference satisfies `sum_j phi_j = v(N)-v(empty)`.

Uniformly sample 64 training background rows without replacement using background RNG 20261106; take the first 16 for the main game. The same ordered background is used across fitted-model seeds and estimator repetitions within a dataset. This fixes the game: background uncertainty is not being mixed with explainer randomness. Hybrid observations can be off manifold; record this as a semantic limitation, not a computational error. Identical raw/hybrid rows do not remove nominal charges.

### Compared stochastic estimators and matched budgets

Primary comparison is a **mechanistic, equal-coalition-request comparison**, not a contest against all SHAP implementations. Both estimators use 64 independent repeats per point, method, and budget. Use recorded, disjoint RNG substreams for selection, fitting, backgrounds, main estimators, references, audits, and diagnostics. Budget repetitions are independent across budgets; methods do not share a reference sampling stream.

For P in {1,4,16}, charge `M(d,P)=2+2(d-1)P` coalition requests, including both endpoints once per run. Thus d=8 gives 16/58/226, d=10 gives 20/74/290, and d=20 gives 40/154/610. Each request costs B model-row evaluations by convention, including repeated masks, endpoints, or duplicate hybrid rows. Report both M and B*M; actual work is separately instrumented.

**Sampled constrained Kernel regression.** Draw K=(d-1)P base masks independently with replacement. Each mask S has probability q(S) proportional to the SHAP kernel `(d-1)/(choose(d,|S|)*|S|*(d-|S|))`, excluding endpoints. Equivalently draw size s with probability proportional to `1/[s(d-s)]`, then a uniform size-s subset. Request S and its complement, retaining all multiplicities. Fix intercept to v(empty), constrain sum(phi)=v(N)-v(empty), and minimize the **unweighted** sum of squared residuals on these sampled rows. Since q is proportional to the target kernel, weighting sampled rows by that kernel again would change the target objective. If aggregating duplicates, weight by multiplicity only. No l1 penalty or hidden adaptive sampling.

Use a centered, minimum-norm efficiency-constrained solution: write `phi = Delta/d * 1 + U theta`, where U is a fixed orthonormal basis of the zero-sum subspace, then solve by SVD with frozen relative singular-value cutoff 1e-10. Minimum norm in theta defines an unambiguous extension when the sampled system is rank-deficient. Record effective rank, smallest retained singular value, and rank-deficient frequency; P=1 is especially exposed. This is the specified minimum-norm variant, not necessarily the installed SHAP library algorithm. Sensitivity on a frozen small subset may change the cutoff to 1e-8/1e-12 but must not replace the main solver after outcomes.

**Antithetic permutation average.** Independently sample P uniform permutations and pair each with its reverse. Average the 2P marginal-contribution vectors. Evaluate the d-1 interior prefixes of each direction plus common endpoints once per run. Count all repeated masks as requests even when retrieved from cache. Marginal paths telescope, giving exact efficiency up to floating-point error.

**Controls, not competitors:** exact Shapley vectors at d<=10; a prespecified feature-ID top-three guess as a weak selection control; all-zero and efficiency-only attribution controls for checking metric behavior. Do not call efficiency-only an accurate estimator. Synthetic additive, constant, null-feature, interacting, and symmetry games are correctness tests only, never empirical benchmark evidence. Probability-scale logistic models are nonlinear games and do not have the simple log-odds linear attribution formula.

### Reference protocol

- **Pima8 and ACSIncome10:** enumerate all 256/1,024 coalition values for every selected point/fit and B=16. Compute exact finite-game Shapley values by the factorial subset formula in float64, and independently cross-check full-coalition weighted regression on selected points. Exact means exact for this finite empirical game, up to numerical tolerance; it does not mean population or causal truth.
- **German20:** independently generate two reference streams, A and B, each with 1,024 antithetic permutation pairs per point. Their merged 2,048-pair vector is the nominal reference. Keep pair-level contributions for reference-only resampling. Caching deterministic v(S) values shared with the main study is allowed; sharing reference random draws with main estimator draws is not.
- Before inspecting main errors, publish per-point split diagnostics: normalized L1(A-B) using the primary floor below, max absolute coordinate discrepancy, top-three/top-one agreement, material-sign disagreement, and rank-3/rank-4 gaps. Reference qualification requires `||A-B||_1/max(||merge||_1,0.02) <=0.02`, max coordinate discrepancy <=0.005 probability, equal top-three sets, and no sign disagreement on the union of features material in A, B, or the merge. If the normalized gap `(|phi|_(3)-|phi|_(4))/max(||phi||1,0.02)` is <=0.02, flag a near tie even when qualified.
- Audit with an **additional independent 4,096-pair reference** on seed-11 first two selected points per model (six point-fit tasks), using the frozen selection-manifest order. Report both its standalone estimate and its union with the original streams. An audit-discordant point is unqualified even if its original split passed. If any audited point fails the above split-style tolerances against the merged main reference, or if >10% of German point-fit tasks fail qualification, trigger one prespecified reference escalation: add 4,096 independent pairs to every unqualified task, subject to the CPU cap. Requalify using two disjoint balanced stream halves, without reusing the same pairs in both halves.
- Freeze references and qualification before evaluating main reliability. Store main label sensitivity under A, B, merge, and available audit references. Reference-bootstrap bands obtained by resampling antithetic pairs are approximate diagnostics, not mathematical confidence certificates; split agreement is also not proof of convergence. Material membership near 0.02 and error-threshold crossing can remain uncertain even with stable top-three sets.
- Report the **full German denominator**, the qualification rate, and two views: qualified-reference results plus worst-case accounting that assigns all unqualified tasks success 0 versus success 1. Call these unresolved-task sensitivity bounds, not certified bounds against the unknown true vector. Report split-reference classification discordance on otherwise qualified tasks. No hidden exclusion, no substitution of a stable-but-small merged reference for an exact one. If >10% remain unqualified after escalation, German accuracy is exploratory/reference-limited and cannot anchor the main accuracy conclusion. Agreement-only results still stand without a reference.

### Primary and secondary metrics

For each point-fit run, let r be its exact or qualified approximate reference, and let `D=max(||r||_1,0.02)`. The 0.02 probability-unit floor prevents a nearly null attribution vector from generating unbounded relative error. Report how often it binds, absolute L1 error, and unfloored relative L1 when ||r||_1>1e-8.

**Primary per-run success:** all three hold:
1. estimated top-three set equals reference top-three set, ranked by absolute attribution;
2. `||estimate-r||_1 / D <= 0.20`;
3. no incorrect sign among features with `|r_j|>=0.02` probability.

Ties in |phi| within absolute 1e-12 use fixed raw-feature order, never random tie-breaking. Define a wrong material sign as `sign(estimate_j) != sign(r_j)`; an estimated numerical zero (`|estimate_j|<=1e-12`) counts as failure for a material reference feature. If the material set is empty, the sign condition is vacuously satisfied and its frequency is explicitly reported. Numerical errors/NaNs and solver exceptions count as failed runs; retain their logs, not successful reruns only. A systematic implementation bug invalidates the affected batch and triggers a documented full rerun, not selective repair.

The cell estimand is the mean single-run success probability, equally averaged over the selected test instances and the three nominal seed strata, conditional on their fitted models and main background. Display seed-specific results alongside dataset-model summaries. Report distributions of instance-level success probabilities, not only the pooled mean. With 64 repeats, worst-case within-instance binomial MCSE is 0.0625; this does not become small merely because there are many run pairs.

**Prespecified secondary summaries:** each component success rate; top-one identity; top-three overlap; normalized L1 median/90th percentile; material-sign error count; and normalized top-three mass regret

`[sum_top3(r) |r_j| - sum_estimated_top3 |r_j|] / max(sum_top3(r)|r_j|,0.02)`.

Also show absolute regret. Evaluate primary normalized-error cutoffs 0.10 and 0.40 as labeled sensitivity analyses, keeping other criteria fixed. Optional material cutoffs 0.01/0.04 are lower-priority sensitivities, not replacements of the main endpoint.

**Near ties:** freeze normalized top3 gap strata <=0.02, (0.02,0.10], >0.10; show raw probability gaps too. Report denominators, including empty strata. This distinguishes fragile set membership from large substantive errors; do not exclude near ties from the primary result. No post-hoc optimal tie threshold.

**Agreement and false reassurance:** within a point/method/budget, enumerate all unordered pairs of the 64 independent repeats; pairwise top-three Jaccard and exact set agreement are descriptive U-statistics. The main reassurance event A is equal estimated top-three sets. Define false reassurance as `Pr(at least one member fails primary success | A)` and also report `Pr(a randomly selected member fails | A)`. Give joint numerators/denominators and agreement prevalence. Pool these counts for a marginal conditional ratio with equal point/seed weights; do not average undefined per-point ratios or treat 2,016 pairs as independent. Zero agreeing pairs means undefined, not zero risk. A secondary stricter agreement event also requires matching signs on the shared top three. This two-run diagnostic is not a validated deployment decision rule and can be misleading if an estimator is consistently biased.

# Reproducing the manuscript

## Scope and entrypoints

The empirical evaluation was completed before manuscript writing. This paper step only reaggregates existing recorded observations. It does not rerun scientific evaluations, train models, or manufacture simulated measurements. `paper_data.json` is the immutable evidence registry. `source_evidence/downstream/program/src/program.py` is the evaluated solver; the adjacent `program_spec.toml` declares its entrypoint. The identical baseline source remains inspectable under `source_evidence/downstream/baseline/`.

All manuscript values are produced by `scripts/build_paper_artifacts.py`; claim mappings are produced by `scripts/map_claims.py`. Run from this directory:

```sh
python3 -m venv /tmp/leaderboard-paper-env
/tmp/leaderboard-paper-env/bin/pip install --index-url https://pypi.org/simple -r source_evidence/evaluation/requirements.txt Pillow requests beautifulsoup4 jsonschema
/tmp/leaderboard-paper-env/bin/python scripts/build_paper_artifacts.py
/tmp/leaderboard-paper-env/bin/python scripts/enrich_panel_reference.py
/tmp/leaderboard-paper-env/bin/python scripts/map_claims.py
/tmp/leaderboard-paper-env/bin/python scripts/write_provenance.py
```

The pinned scientific dependencies are NumPy 2.2.6, SciPy 1.15.3, PyArrow 19.0.1, and Matplotlib 3.10.3. The actual paper-analysis Python and additional package versions are in `derived/environment.json`. Install auxiliary dependencies only in a private directory outside the manuscript workspace. Figure/table regeneration is CPU-only and small compared with the original evaluation; its exact runtime depends on the environment. No unmeasured runtime is reported as an empirical result.

## Original evaluation reproduction

`source_evidence/evaluation/evaluate_final.py` is the exact evaluator source, not a manuscript-written approximation. It exposes `--program_path` and `--results_dir`, resolves `TASK_SOURCE_DIR/resources/final`, and requires Linux x86_64 process-isolation facilities and its documented RPC environment. A future full reevaluation can be invoked in a compatible environment with the original task bundle:

```sh
mkdir -p /tmp/leaderboard-eval-input/resources/final
cp source_evidence/data/records.json source_evidence/data/manifest.json /tmp/leaderboard-eval-input/resources/final/
TASK_SOURCE_DIR=/tmp/leaderboard-eval-input /tmp/leaderboard-paper-env/bin/python source_evidence/evaluation/evaluate_final.py \
  --program_path source_evidence/downstream/program/src/program.py \
  --results_dir /tmp/leaderboard-reevaluation
```

This is a new evaluation command, **not executed during manuscript preparation**, and is not required for replaying manuscript summaries. The final wall allowance is 1800 seconds, with per-episode matched method reservations and advisory per-decision node budgets specified in source. Results and timing can vary with CPU/process-isolation support. Do not confuse a failure to recreate the isolation environment with measured scientific nonattainment.

## References, prohibited-source boundary, and template

The initially staged bibliography contained many irrelevant metadata-only matches. It was replaced with 25 targeted, inspected canonical records; `literature/*.json` stores the abstracts actually consulted and complete metadata. Reading was limited to those abstracts and metadata, so no detailed literature theorem or uninspected full-text result is claimed. A focused citation-enrichment pass added the official Open LLM contents dataset card at the exact analyzed revision, for 26 references in total. Its complete schema is archived in `literature/OpenLLMContents.README.md`; it distinguishes the six `Raw` fields from their parallel score fields. Only that pinned dataset card was accessed, without following links. This attribution does not replace the input-acquisition manifest or change any numerical result. `scripts/curate_references.py` regenerates the original bibliography from cached records without new network access; run `scripts/enrich_panel_reference.py` afterwards to restore the official dataset citation and provenance. On an empty cache the latter downloads only the exact pinned card. No citation graph or broad strategic-leaderboard search was used in this writing pass. No prohibited-study exposure was identified. The unsuccessful publisher-abstract access for Huber was resolved through the exact DOI record in OpenAlex; no related works were followed.

The manuscript uses the official ICLR 2026 template from the ICLR Master-Template repository, not the NeurIPS template mentioned in the historical data-acquisition manifest. `template_provenance.json` records the exact archive and style-file hashes. ICLR 2026 does not supply a mandatory NeurIPS-style checklist in that template. The manuscript is anonymized and contains an explicit LLM Usage disclosure.

```sh
python .codex/skills/validate-paper/scripts/validate_tex_refs.py --tex paper.tex --bib references.bib
python .codex/skills/write-paper-standalone/scripts/validate_claims.py \
  --paper-data paper_data.json --references references_provenance.json \

bash .codex/skills/validate-paper/scripts/compile_latex.sh paper.tex
```

Compilation requires a LaTeX distribution, BibTeX, and Poppler `pdftotext`. The supplied canonical compile validator may reject a system TeX configuration symlink that crosses between two otherwise approved TeX installation roots in this container. The citation-enrichment container also lacks `pdftotext`, so its canonical wrapper stops at that prerequisite. These are environment issues, not unresolved manuscript inputs. `bash scripts/compile_paper.sh` compiles with `pdflatex -recorder -no-shell-escape`, BibTeX, and two further LaTeX passes; actual recorder inputs are audited separately by `scripts/audit_manuscript.py`. That audit resolves the system symlink to its real approved installation root without altering the validator or hiding an input. Rendered references, supplement ordering, and body occupancy are checked on the PDF using the canonical Python validators and PDF extraction. The concept placeholder is intentionally replaced by the orchestrator before its final compile; it is not a completed scientific figure.

## Redistribution and scope limits

No separate score-data redistribution license was identified. Public unauthenticated access, repository-code licenses, and model licenses do not settle permissions for these data extracts. Review permission before public redistribution. All conclusions concern frozen score-space counterfactuals, not training expenses, causal contamination, independent training replications, or universal aggregator rankings. Unsuccessful development alternatives have unknown qualification-failure causes; their retained proxy scores are not mixed with sealed final evidence.

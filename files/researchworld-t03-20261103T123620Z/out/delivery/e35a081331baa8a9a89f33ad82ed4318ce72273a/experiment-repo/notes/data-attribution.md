# Data acquisition, attribution and source-use context

The acquired bytes, URLs and retrieval times are in `data/manifest.json`. Dataset transformation code is `src/shap_reliability/data.py`; split/train-only preprocessing is `models.py`. Raw archives are fetched upstream, not bundled in the delivery.

- German: Hans Hofmann (1994), Statlog (German Credit Data), UCI Machine Learning Repository, DOI https://doi.org/10.24432/C5NC77, CC BY4.0 https://creativecommons.org/licenses/by/4.0/. We use original symbolic german.data,20raw features,1,000rows, and recode original2 as positive bad-credit. Our train-only encodings/split are study transformations, not a new UCI release. Source/archive retrieved2026-11-03.
- ACS: U.S. Census Bureau, American Community Survey2018 1-Year Public Use Microdata Sample, California person records, csv_pca.zip, https://www2.census.gov/programs-surveys/acs/data/pums/2018/1-Year/csv_pca.zip, accessed2026-11-03. ACSIncome is derived with folktables0.0.12 following Ding et al.(2021), Retiring Adult: New Datasets for Fair Machine Learning. Filter: age>16, income>100, hours/week>0, person weight>=1. Positive income>$50,000. Ten raw task features; survey weights are not used for fitting or summaries. Disclosures protect/modify source records; person-row benchmark inference is not population survey inference. Census is the source of original data only; these analyses/conclusions are the performing party's responsibility and imply no Census endorsement. The archive was acquired over HTTPS via the documented FTP-file route, not the Census API. No separate named license was located for the archive on the checked official pages. folktables software MIT is separate from Census data terms.
- Diabetes: OpenML dataset37/version1, https://www.openml.org/d/37 and the download URL in the manifest, accessed2026-11-03; source description attributes ownership to NIDDK and donor Vincent Sigillito. The OpenML metadata label is Public; separate upstream license wording was not verified, and this is not asserted to be a CC0/MIT grant. The768-row historical sample has8features and concerns women of Pima Indian heritage aged>=21 near Phoenix; it is not general clinical validation. Impossible zero values in five physiological measurements become missing, then train-only median imputation applies; pregnancy zero is retained. tested_positive is the positive label.

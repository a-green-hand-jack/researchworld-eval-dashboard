# Precision remaining in a frozen score

The study asks when identical labeled samples, unlabeled scores and a frozen predictor can support narrower mean intervals. Its evidence is conditional: nonlinear synthetic gains, no practical gain on three empirical populations, rare-event failures, and a separately guaranteed bounded-data comparison.

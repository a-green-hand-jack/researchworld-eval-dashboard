# Analysis code and provenance map

- `scripts/fetch_inputs.py`: pinned dataset/models; `provenance/downloads.json` gives URLs/hashes; gold rationale/answer are never passed to prompt renderer.
- `scripts/build_inference.sh`: native CPU backend flags; `provenance/build-source.json`, `conda-packages.json`, `environment-native.txt`: source/compiler/environment.
- `scripts/pilot_inference.py`: initial validation-only single-format timing; `scripts/pilot_scope.py`: representative main-context timing using four instruction/format families and long validation inputs.
- `scripts/prompt_bank.py`: frozen bank and exact model-input rendering; `provenance/prompt-bank.json`: bank manifest.
- `scripts/prepare_real.py`: outcome-independent question partition and candidate prefix order.
- `scripts/run_real.py`: deterministic actual response generation, parser/range diagnostics, content-hash-checked resumption, raw JSONL and cumulative cost/session records.
- `scripts/assemble_real.py`: complete-pair validation, no imputation, ordered score matrix, raw response CSV and generation accounting.
- `scripts/run_synthetic.py`: full known-truth synthetic protocols; `tests/check_synthetic.py`: analytic-law checks; `scripts/exact_null_reference.py`: independent exact binomial-maximum references; `scripts/summarize_synthetic.py`: full-grid validation and exports.
- `scripts/run_cache_calibration.py`: same protocol metrics with actual cached question-row dependence and exactly known empirical-population means; `tests/check_synthetic_unchanged.py` establishes that generalizing the generator did not change any existing pilot metric.
- `scripts/finite_population.py`, `tests/check_finite_population.py`: exact audit hypergeometric inversion and coverage enumeration for uniform questions drawn without replacement from the remaining benchmark population.
- `tests/check_parser.py`: declared strict parsing examples and rejection rules.

Figure/table rendering belongs to figtab-repo (`presentation/render.py`), whose package records its exact input revision, hashes and environment. This file maps analysis scripts; it does not replace that owner's figure/table mapping. `scripts/analyze_disjoint.py` exports the primary winner, finite complement-target intervals, paired comparison, conditional selections and dependence/category diagnostics; `scripts/bootstrap_disjoint.py` gives paired-row sensitivity; `scripts/summarize_real.py` validates the complete empirical calibration grid and exports explicit logical budget tables. Commands and target labels are in `docs/real-reproduction.md`. All main outputs are completed under the activated Tier C; docs/real-handoff.md maps their measured claims and limitations. scripts/diagnose_real.py supplies format/category/data diagnostics and the descriptive primary gap decomposition. scripts/validate_real.py checks full export identities, probability MCSEs, exact interval transformations and bootstrap completeness; results/real/validation.json records the pass. tests/check_assembly_subset.py checks parent-shard/subset accounting and rejection of corrupt excluded outputs, and tests/check_fetch_inputs.py verifies every downloader choice without network transfer.

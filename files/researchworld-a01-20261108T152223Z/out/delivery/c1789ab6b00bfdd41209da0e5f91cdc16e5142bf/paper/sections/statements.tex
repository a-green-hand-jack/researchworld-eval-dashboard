\section*{AI use statement}
This study was carried out by AI agents (large language models) working as separate roles---context and literature review, study planning, analysis and coding, figure and table production, writing, and internal and external review. The agents designed the study, wrote the code, ran the analyses, interpreted the results and wrote this paper. No human author took part in these steps, and we make no claim that a human reviewed them. Every number, table and figure was produced by the code released with the paper; references were checked by the agents against the sources named.

\section*{Ethics statement}
The study analyses publicly released evaluation scores; no human subjects or personal data are involved. It shows how cheaply a leaderboard can be gamed under some rules, which could inform strategic misuse as well as better benchmark design. We hold that quantifying the vulnerability is useful to benchmark designers and does not enable an attack beyond what training on test-related data already does. The score data carry no stated licence (HELM) or a per-model hub licence column (Open LLM Leaderboard); we use them for analysis and redistribute only derived tables and checksums; see \texttt{code/REPRODUCE.md}.

\section*{Reproducibility statement}
All results are computed from two public snapshots (HELM MMLU v1.13.0; the Open LLM Leaderboard \texttt{contents} dataset at a fixed commit), whose checksums and download commands are in \texttt{code/REPRODUCE.md} (Table~\ref{tab:validation_data}). The delivery contains the solvers, the processed score tables, a command for each result grid, all random seeds (bootstrap, noise and task resampling: seed 0; weights: seeds $1000+k$), the scripts that build every figure and table from the result files (each output has an \texttt{*.inputs.json} with the checksums of its inputs), and the solver tests. The exact solvers are validated against closed forms, linear programmes, an independent optimiser and enumeration (Table~\ref{tab:validation}); the runtimes are in the notes.

# Venue requirements for the leaderboard stability study

- `requirements/objective-matrix.md`: frozen-objective traceability, scope and evidence requirements.
- `requirements/venue.md`: verified NeurIPS 2026 main-track selection, nine-page rule, manuscript/checklist/build requirements and limits of verification.
- `requirements/checklist-guidance.md`: all 16 checklist questions' evidence needs; report owns the completed answers.
- `templates/neurips2026/`: unmodified official style, shell, checklist and checksums. Reference TODOs/dummy content are not study artifacts.
- `sources/`: retrieved official pages/archive, source provenance and frozen-input hashes.

Upstream venue-repo root `venue-artifacts.json` declares required paths allocated by paper-repo CODEOWNERS (merged from story-repo PR #4). Directory presence is only a coarse artifact check; objective compliance still requires the full code, instructions, actual-run provenance and completed manuscript checklist. No final study compliance, external conference submission, acceptance, asset license or ethics approval is asserted by these requirements.

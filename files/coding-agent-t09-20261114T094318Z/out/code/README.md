# Regression-based GATE estimation under network interference: reproduction guide

Everything in the paper is produced by the code in `code/`. Results are simulated
(synthetic outcomes) on public graphs; no proprietary or account-gated data is used.

## Environment

- Python 3.11.2; packages installed in `/work/venv` (created with `python3 -m venv`):
  numpy 2.4.6, scipy 1.17.1, networkx 3.6.1, scikit-learn 1.9.1, pandas 3.1.1, matplotlib (see `requirements.txt`).
- Platform: Linux, 40 logical CPUs reported by `nproc`, but the cgroup quota is 4 CPUs
  (`/sys/fs/cgroup/cpu.max` = `400000 100000`). Wall-clock times below are for that quota.
- LaTeX: `pdflatex` + `bibtex` (TeX Live). Style: NeurIPS 2026 `neurips_2026.sty`
  (downloaded from `https://media.neurips.cc/Conferences/NeurIPS2026/Formatting_Instructions_For_NeurIPS_2026.zip`).

## Steps

```bash
cd /work/code
/work/venv/bin/python prepare_graphs.py   # builds data/processed/*.npz and results/graph_stats.csv  (~5 min)
./run_all.sh                              # E1-E4, 500 reps per setting (~3.6 h on a 4-CPU quota)
/work/venv/bin/python analyze.py          # results/summary_E*.csv
/work/venv/bin/python make_tables.py      # paper/tables/*.tex
/work/venv/bin/python make_figures.py     # paper/figures/*.pdf
/work/venv/bin/python diag_omitted.py     # two-hop projection slopes (results/diag_omitted.csv)
/work/venv/bin/python diag_exposure.py    # exposure dispersion diagnostics (results/diag_exposure.csv)
cd /work/paper && pdflatex main && bibtex main && pdflatex main && pdflatex main
```

from `[BASE_SEED, crc32(setting_id), rep]`, so every replication is reproducible independently.

## Files

- `code/gate/graphs.py` graph loading, generation, Louvain partitions (resolution chosen so that #clusters >= n/60).
- `code/gate/dgp.py` treatment designs, exposures, mechanisms M0–M6, exact GATE.
- `code/gate/estimators.py` DiM, OLS (direct / 1-hop / 1+2-hop / quadratic), gradient boosting; HC1 and CR1 standard errors.
- `code/run_sim.py` experiment grid and runner; `code/run_all.sh` runs E1–E4.
- `code/analyze.py` coverage, bias, RMSE and summaries.
- `code/diag_omitted.py` projection slopes of the two-hop exposure (Section 5, two-hop identity); output `results/diag_omitted.csv`.
- `code/diag_exposure.py` exposure dispersion and the variance of the two-step exposure (Section 5.2); output `results/diag_exposure.csv`.
- `code/make_tables.py`, `code/make_figures.py` LaTeX tables and PDF figures.

## Literature access and checks

- Restricted material: the task's restricted paper (and any page discussing it) was **not** searched for, opened or used. Literature searches were limited to the starter list (`starter_literature.md`) and classic method references (Louvain, cluster-robust variance, Barabási–Albert, scikit-learn, White/MacKinnon–White). No restricted material was encountered.
- Metadata verified for every cited paper: arXiv abstract pages (Aronow–Samii 1305.6156; Ugander et al. 1305.6979; Eckles et al. 1404.7530; Chin 1808.08683; Karrer et al. 2012.08591; Cortez et al. 2205.14552; Han–Ugander 2302.04997; Blondel et al. 0803.0476; scikit-learn 1201.0490) and index records (Cameron–Gelbach–Miller 2011, Barabási–Albert 1999, Rossi–Ahmed 2015, McAuley–Leskovec 2012, White 1980 and MacKinnon–White 1985 as cited in indexed records). Traud et al. 2012 is the starter list entry (arXiv 1102.2166).
- The Erdős–Rényi (1959) reference was not found in the literature index and was removed from the paper; the random-graph model is named without a citation.

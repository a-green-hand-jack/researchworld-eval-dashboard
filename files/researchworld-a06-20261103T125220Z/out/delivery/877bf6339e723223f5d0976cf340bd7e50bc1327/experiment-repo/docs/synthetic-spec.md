# Synthetic specification before full runs

Each replicate has K frozen Bernoulli candidates with exact accuracy p. Candidate 0 is a frozen default at .4. Equal-quality cells have all p=.4. Heterogeneous cells put other p uniformly between .32 and .48 (K=2 has one .48 challenger). On each independent question, with probability rho, all candidates compare the same uniform U against their p; otherwise each compares an independent uniform. This yields Cov(Y_j,Y_k)=rho[min(p_j,p_k)-p_j p_k]. Equal-quality correlation is exactly rho; for unequal means rho is the shared-question mixture probability.

The simulator samples the sufficient joint counts exactly: the number of shared-uniform questions is Binomial(n,rho), the shared outcomes are multinomial over intervals between sorted p, and remaining counts are independent binomials. Uniform independent tie breaks remove default-index advantages. Repeats are independent and seeds are recorded per cell.

Primary grid: n in {16,32,64,128,256,512}; K in {1,2,4,8,16,32,64,128}; rho in {0,.5,.9}; quality spread in {0,.08}. This is 288 cells. Proposed 10000 independent repeats/cell, subject to timed pilot. Naive and Bonferroni simultaneous 95% Clopper–Pearson intervals are evaluated against known p of the selected winner, as are an independent same-size audit and split reporting under two budgets: equal question budget n (half search/half audit), and equal model-call budget nK (sK+h=nK with s approximately h). For K=1 the latter also splits the budget; the independent audit uses extra calls and is labeled accordingly.

Decision endpoint: the selected candidate is declared superior to the frozen default when its lower marginal CP bound exceeds the default's upper bound. Each one-sided marginal error is .025 before correction; corrected intervals use alpha/K. The unconditional false-superiority frequency counts claims when the selected candidate's true p is no greater than .4. This is deliberately conservative for a preselected comparison and must not be described as the usual paired test or as a false-discovery rate conditional on a claim.

Report Monte Carlo standard errors for every mean/proportion. With 10000 repeats, a coverage near .95 has MCSE about .0022. A null synthetic result is an outcome, not a failed experiment. This controlled mixture does not reproduce every dependence pattern of LLM prompts; the real score matrix assesses its limited relevance.

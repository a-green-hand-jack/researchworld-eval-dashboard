# 实验技术报告：单次置换 SHAP 在什么条件下可靠？

## 1. 摘要与目标

**结论是有条件的，而非“单次 SHAP 普遍可靠”。** 固定模型、输入、经验背景与原始特征分组后，增加成对正反置换预算能提高绝对贡献前三特征集合的恢复率；但模型间差异、第三/第四名近并列以及背景改变仍会造成失败。精确游戏宏平均在 P64 达到 **0.9656**，不等于每个实例或模型满足 0.95，更不是因果、临床、信贷或总体可靠性认证。

本研究是标准估计器的实证审计，不提出新算法，不宣称优于优化 SHAP/Leverage SHAP。论文 `paper.tex` 与本报告是诚实、可复查的研究产物，**不表示已获同行评审发表**；概念新颖性及主会接收可能性仍未解决，不能保证录用。

## 3. 设置、协议与数据 QC

- **目标游戏：** 正类预测概率、identity link，经验 interventional 混合；B=8 固定训练背景。分类变量所有编码列作为一个原始玩家共同切换，而非将 dummy-level TreeSHAP 求和。精确值只对应此有限经验游戏，不是总体或因果真值。
- **参考：** Pima d=8、ACS d=10 穷举；German d=20 用两个独立、各512成对周期池的均值。German 所有结果均为**近似参考一致率**，参考误差无正式上界。
- **模型：** 种子11/23/47；LR C=1；RF 40树、深6、最小叶4；MLP (32,16)、alpha=.01、训练内部早停。完整参数见 NPZ 同名 JSON。外部验证集不用于调参，预处理只在训练集拟合。
- **随机性：** 划分2026/2027，审计顺序9041，背景9042；20条流内取嵌套预算。完整流映射及命令见 `README.md` 和论文复现附录。
- **评估：** 主指标为无序绝对 top3 集合完全恢复率，精确并列按原始索引；另报集合重叠、L1、归一化L1、材料符号（参考绝对值≥0.01）、两次运行一致率及 Nogueira 子集稳定性。20次重复用于估计**单次运行**表现，不合并成展示输出。

**统计口径：** 先在游戏内平均重复，再在实例内平均固定种子，再平均实例；精确宏平均等权覆盖 Pima/ACS × 三模型，**不含German**。2,000次配对实例簇bootstrap保持种子/模型/方法/预算依赖，数据集间独立重采样；95%区间为描述性分位区间。三训练种子不是三次独立模型总体抽样，190个重复对不增加样本量。63个报告差值另给联合最大中心绝对偏差校正带；不能把边界退化区间[1,1]当有限样本认证。

## 4. 基线与成本公平性

成对正反置换每P周期的逻辑模型行数为 `B[2+2P(d−1)]`，单向控制用2P条独立路径匹配额度；约束Kernel不做L1特征筛选。**Kernel在P64对Pima/ACS均转为全穷举**，分别花2,048/8,192行，少于置换的7,184/9,232行。因此其1.0000是精确控制，不支持随机估计器或软件包优越性主张。相同路径重复分块再平均等于更长运行，只作恒等式检验。

## 6. 认证边界、成本与下一步

**阈值不是认证。** 0.95为用户定义的示例标准。即使120例观测全对，24单元Bonferroni-Hoeffding示例下界最多 **0.8396**；在其独立簇抽样假设成立且观测全对时，至少需1,235例才可能达到0.95。这不是功效保证，ACS现有抽样也不支持总体认证。bootstrap区间、参考近缝隙分层和重复性均不能自动替代这些假设。

**成本实测：** 原30+B16与扩展120（包括原30前缀重算）成功运行合计 **1,194.678566 CPU秒=0.3319 CPU小时**；不是用满24小时。未计不可恢复的失败/不完整运行、调度、安装下载、分析绘图和排版开销。扩展主单元wall合计1,615.335063秒，不是并行实际历时；后90是切片，不再加一次实验成本。共享缓存计时包括参考及控制，不能解读成单解释器部署延迟。

**复现规划估计（非实测端到端耗时）：** 已有依赖/数据时，离线分析约1–5分钟；类似多核CPU上完整小模型流程与检查/构建约5–30分钟，慢机可能更久；在线安装/下载另计，依赖网络。依据是约20 CPU分钟和约36累计单元wall分钟的记录。环境Python3.11及 `requirements.txt`；主实验8个worker，敏感性4个，每worker数值线程限制1。峰值内存/历史硬件分配未记录，`environment.json`只是事后宿主机检查。

主要局限：三类小模型、单一背景实现、ACS单州单年且家庭纳入不等、German参考误差未界定、看过探索结果后扩展；未验证因果合理性、校准、公平性、时间迁移、人类效用或安全性。优先下一步是预先规定等概率/设计加权ACS审计、更大独立样本及German参考池、验证不依赖参考的预算诊断，而不是把现有描述性结论升级为保证。

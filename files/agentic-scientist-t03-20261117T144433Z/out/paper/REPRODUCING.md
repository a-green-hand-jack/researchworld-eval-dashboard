# Reproducing the retained SHAP audit

## Scope and limitations

This package reconstructs manuscript figures, table reductions, and metric checks from `paper_data.json`. It does not run a new scientific experiment. The detailed final diagnostics are labeled unverified in the registry. Aggregate arithmetic checks do not authenticate execution or exact source identity. The supplied readable sampler snapshot and the sealed final evaluation have different recorded tree identifiers; no exact-identity claim is made. Final qualification is independently reported as completed/qualified, while development did not establish a qualifying improvement.

## Environment and figure reconstruction

Keep auxiliary package installations outside this manuscript directory. For example:

```sh
python -m venv /tmp/shap-paper-tools
/tmp/shap-paper-tools/bin/pip install numpy matplotlib pillow requests beautifulsoup4 jsonschema pymupdf
/tmp/shap-paper-tools/bin/python scripts/build_figures.py
/tmp/shap-paper-tools/bin/python scripts/build_claims.py
bash .codex/skills/validate-paper/scripts/compile_latex.sh paper.tex
```

Matplotlib/Numpy are writing-time dependencies, not replacements for the scientific evaluation's pinned dependencies. The scientific environment is recorded in `source_evidence/evaluation/manifest.json` and pinned in `source_evidence/evaluation/requirements.txt`. No random statistical analysis is added by figure reconstruction. The build checks all 288 non-replay scientific cells against the retained values and asserts consistency with final scalar aggregates.

`scripts/build_figures.py` produces all three numerical composite figures, in PDF and 300-DPI PNG, `derived_summary.json`, and `supplementary_rows.tex`, with adjacent provenance sidecars. It reads the stored within-fit intervals rather than generating new ones. Expected reconstruction cost is a short local plotting job, not model-evaluation time; it is not included in the reported scientific runtimes. The overview is owned by the external concept-figure workflow. Its reserved placeholder and prompt stub are self-guarding and are not overwritten once a real prompt log or completion marker exists.

## Original data and protocol

The supplied manifest includes exact source URLs and archive/member digests. German data are from the public UCI Statlog German Credit archive. ACS data are the public California 2024 one-year person-record archive. The manifest documents normalization, duplicate grouping, relationship-code adaptation and deterministic hash splits; do not replace them with a conventional random split and call the result identical. UCI terms identify CC BY 4.0; folktables code is MIT, whereas Census data use is subject to the original site terms rather than an invented separate license. Data records are not embedded in this manuscript package.

Model fitting and original evaluation are defined by `source_evidence/evaluation/evaluate_final.py`; source-reading is not equivalent to executing it. In its original environment the command shape is:

```sh
TASK_SOURCE_DIR=/path/to/original/task python source_evidence/evaluation/evaluate_final.py \
  --program_path /path/to/supplied/candidate-entrypoint \
  --results_dir /path/to/new-evaluation-output
```

This is documentation, not a command run during manuscript writing. Full execution requires the original `resources/final/data.json` snapshot and an execution environment compatible with the evaluator's isolation/service assumptions (or the original broker interface). No portable replacement broker is supplied or claimed. The supplied source snapshots make the protocol and sampler inspectable but do not close the sealed-source identity gap. The evidence has only one full mask/value/regression trace per case plus digests, not the full raw-mask history. Exact independent replication of every original call therefore requires more than the retained output package.

Fitted seeds are 7301 and 9109. Bootstrap seed 812 and the 200-draw percentile procedure belong to the retained evaluation; the plotting script does not recompute them. The six repetitions and four additional short calls use separate streams. The terminal deterministic replay is excluded from scientific means. No neural, conditional-game, background-resampling, or transfer experiment was completed in this package.

The final record has episode wall durations of 222.48 and 194.99 seconds. These are not an expected runtime guarantee or total campaign CPU accounting. Source ceilings and the original resource estimate are not reported as measured consumption.

## References and prohibited-content safeguard

`reference_consultation.md` records abstracts or bibliographic metadata actually consulted through exact permitted starter identifiers, known foundational methodological identifiers, or direct publication pages. Only the intended abstract/metadata content was extracted; citation chains and recommendation lists were not followed. Unrelated pre-existing bibliography entries were removed. No prohibited study was encountered or used during this writing pass. `scripts/prepare_sources.py` records the retrieval and snapshot-preparation logic, but is not needed for offline manuscript reconstruction. It requires the original task tree and an available `apply_patch` command (the writing environment used a temporary compatibility driver outside the workspace).

python .codex/skills/write-paper-standalone/scripts/validate_claims.py \

The host's figure validator imports its orchestration package, which may be absent in a standalone copy. Local JSON Schema validation plus rendered inspection is possible without that package; host validation remains authoritative for final venue-page and figure checks. Never modify `paper_data.json` to make a claim pass.

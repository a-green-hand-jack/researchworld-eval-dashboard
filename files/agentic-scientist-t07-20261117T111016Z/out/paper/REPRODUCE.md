# Reproducing the manuscript

## Scope

The paper analyzes the supplied, completed final evaluation. It does not report
a fresh estimator run. `paper_data.json` is immutable. Development scores are
not pooled with final results. No new component ablations were executed.
The evaluator records final status `completed` and outcome `qualified`; these
facts do not certify generalization. Exact identity between the available
selection source counterpart and the final source-tree digest is not independently
verified. See `source_evidence/inventory.json`.

## Analysis environment and commands

Python 3.12 is used. Install tools outside this workspace:

```sh
python3 -m venv /tmp/paper-reproduction
/tmp/paper-reproduction/bin/pip install -r requirements-paper.txt
/tmp/paper-reproduction/bin/python scripts/build_paper_artifacts.py
/tmp/paper-reproduction/bin/python scripts/build_claim_mapping.py
bash .codex/skills/scientific-evidence/scripts/scientific_evidence.sh verify --root-dir .
bash .codex/skills/validate-paper/scripts/compile_latex.sh paper.tex
```

LaTeX requires pdfLaTeX, BibTeX, the usual AMS/natbib/graphics/Times packages,
and `pdftotext`. The official ICLR 2026 style and bibliography style were retrieved
directly from `https://github.com/ICLR/Master-Template/tree/master/iclr2026`.
They retain the official single-column 5.5-inch by 9-inch text geometry.
The venue-specific brief selects ICLR 2026, even though newer template files
exist upstream. No author names, affiliations, acknowledgments or funding are added.

The reconstruction script reads all prediction arrays, recomputes metrics with
the evaluator's weighting, and asserts agreement with the recorded final scalar
metrics. It excludes the replay record and deduplicates the repeated bootstrap
object. No bootstrap is rerun. The CSV contains every retained cell and estimator;
the JSON also contains seed/budget/case means. Prior ranking artifacts are retained
in the numerical reconstruction for audit, but omitted from the paper because
constant predictions do not define meaningful rankings.

These are CPU-only postprocessing operations. No portable runtime estimate or
inference-speedup measurement is available; wall time depends on environment and
LaTeX installation. The evaluator itself declares a 10,800-second ceiling, not a
measured expected runtime for reproducing this manuscript. Do not interpret that
ceiling as an estimate or as new timing evidence.

## Artifact-to-script map

- Main aggregate table: `scripts/build_paper_artifacts.py` -> `tables/aggregate.tex`.
- Complete case/budget table: same script -> `tables/case_budget.tex`.
- Seed table: same script -> `tables/seeds.tex`.
- Paired interval figure: same script -> `figures/paired_error_comparison.{pdf,png}`.
- Case reversal figure: same script -> `figures/case_budget_reversals.{pdf,png}`.
- Supplemental budget figure: same script -> `figures/budget_sensitivity.{pdf,png}`.
- Concept overview: orchestrator-owned `generate-concept-figure` workflow,
  `figures/score_prediction_overview.png`, with its adjacent prompts log. The build
  script creates an explicitly non-data placeholder only when no render is present;
  it never replaces an existing figure, nonempty plan log, or completion marker.
- Claim mappings: `scripts/build_claim_mapping.py` -> `claims_grounding.json`.

Quantitative figures are exported to vector PDF and 450-DPI PNG (at least 2400
pixels wide); the LaTeX uses the PDFs. The full-width conceptual placeholder is at least 2400 pixels wide
and is reserved for replacement by the orchestrator, not an empirical diagram.
Derived artifacts have adjacent provenance sidecars.

The supplementary tables are embedded verbatim in `paper.tex` between named
generated-table markers because the strict supplementary validator disallows
external TeX imports. Their values are generated by the table scripts above;
`scripts/validate_local.py` verifies byte-equivalent content between the embedded
tables and generated table files. The main aggregate table is imported normally.

In this container the canonical figure CLI cannot import the unavailable
`src.orchestrator` package. The canonical manifest schema and the strategy's
density limits are checked directly instead. The canonical compile recorder
rejects a standard Debian TeX configuration symlink from `/usr/share/texmf` into
the separately approved `/usr/share/texlive` root. `scripts/compile_local.sh`
therefore runs the same sanitized pdfLaTeX/BibTeX steps, canonical bibliography
check and rendered-SI check separately. `scripts/validate_local.py` additionally
checks every resolved dependency against the union of the approved TeX roots.
These environment-specific fallbacks do not alter the supplied validation code
and do not replace the parent's authoritative venue/layout validation.
The local audit writes `paper_checks.json`; Poppler executables must be on PATH.

## Evaluated resources and optional independent rerun

The supplied task resources contain frozen binary NPZ matrices, content-column
JSONL, and provenance manifests in `task/resources/final`. A byte-for-byte copy of
each manifest is in `source_evidence/manifests`. The source data version is
`socialfoundations/benchmark-prediction` commit
`55faff496947789f94e6b5908c77cbc3e84f81ad`. Its packed `.jbl` files can be downloaded
without credentials using this exact commit, for example:

```sh
curl -L https://raw.githubusercontent.com/socialfoundations/benchmark-prediction/55faff496947789f94e6b5908c77cbc3e84f81ad/data/scores/bbh.jbl -o /tmp/bbh.jbl
```

The complete final matrix list is `bbh`, `gpqa`, `mmlu_pro`, `musr`,
`openllm_math`, `legalbench`, `math`, `med_qa`, and `mmlu`. Source/target lineage
assignments and cross-plane content removals must match the frozen manifests;
raw upstream downloads alone are insufficient. The provided
`task/resources/rebuild.py` describes reconstruction with the mounted column
metadata under `/extra/t07-open-llm-leaderboard-columns`. Do not claim reproduction
if these resources are unavailable or their hashes differ.

Estimator dependencies are copied verbatim to
`source_evidence/evaluator/requirements.txt`: NumPy 1.26.4, SciPy 1.12.0,
scikit-learn 1.4.2, joblib 1.4.2 and threadpoolctl 3.5.0. The selected counterpart's
entrypoint, full source and specification are under `source_evidence/selected`.
The final evaluator is standalone in `source_evidence/evaluator/evaluate_final.py`.

The following is an optional fresh evaluation command, **not executed during
writing**. It requires the original task resource tree and the evaluator's OS
isolation support; do not overwrite the sealed results:

```sh
TASK_SOURCE_DIR="$PWD/task" /path/to/evaluation-venv/bin/python \
  source_evidence/evaluator/evaluate_final.py \
  --program_path "$PWD/source_evidence/selected" \
  --results_dir /tmp/independent-benchmark-evaluation
```

Recorded final seeds are 1009, 2003 and 3001; budgets are 5, 10 and 25. The paired
bootstrap uses seed 1729 and 200 draws, retaining seed/checkpoint measurements
within lineage blocks. The ordinary BBH replay is excluded. Negative controls
are separate observations, not additional normal performance replications.

## Literature consultation and access restrictions

`scripts/retrieve_focused_references.py` uses direct identifiers only, including
explicitly permitted starter literature, dataset publications, old statistical
foundations and numerical-software sources. It does not expand citation graphs.
The final bibliography has 25 relevant references; off-topic preliminary entries
were replaced, not cited to fill a quota. `references_provenance.json` records
consulted source scope and locally cached HTML/JSON evidence. Related-work claims
are limited to the abstracts actually consulted, not a claim to full-text review.

Publisher pages for Hoerl and Kendall returned HTTP 403; the initial Euclid and
JSTOR pages did not provide useful substantive content. Direct OpenAlex DOI
lookups supplied abstracts for Hoerl and Elfving. Spearman and Kendall were
removed rather than cited on metadata alone. Two guessed direct Hugging Face blog
URLs returned 404; no such blog is cited. A direct textbook download did not
yield a PDF; the textbook is not cited. The first official-template URL returned
404; the correct official `iclr2026/` subdirectory supplied the style files.
No prohibited-study identity was searched for, inferred, or recognized as an
accidental encounter in this manuscript step. No citation-network expansion or
general research-question web search was performed.

# Figures and tables for benchmark score reuse

This repository owns presentation for the study of automatic configuration selection and benchmark reporting.

The completed synthetic presentation includes six vector figures, PNG previews, and a numerical comparison table. Start with [the generator and recreation instructions](presentation/README.md), [captions](presentation/captions.md), and [the acceptance check](docs/presentation-check.md). Inputs are pinned by upstream revision and SHA-256 in [provenance](presentation/provenance.json).

These are controlled synthetic measurements only. Required real-LLM presentation awaits the analysis owner's measured inputs. The settled ICLR 2027 artwork width is 5.5 inches; all figures follow it. Manuscript integration is tracked in paper-repo #2; the commitment is figtab-repo #3.

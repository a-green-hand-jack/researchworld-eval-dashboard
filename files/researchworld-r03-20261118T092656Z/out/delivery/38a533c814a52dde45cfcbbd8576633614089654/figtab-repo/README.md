# figtab-repo — figures and tables

`schema.md`: result files read. `figtab/style.py`: venue geometry (from `figtab/venue.json`),
palette. `figtab/check_pdf.py`: placed width and minimum font size of each figure PDF.
One script per artifact (`figtab/fig_*.py`, `figtab/tab_*.py`), listed in `REPRODUCE.md`
once artifacts exist.

# Prospective analysis protocol (proposal awaiting plan owner)

The initial pilot never evaluates locked target rows. After validating duplicate identities, keep the first occurrence of each exact repeated model name; repeated identities currently have equal full response vectors. HELM rows use opaque row IDs where name alignment is unverified. Use per-benchmark deterministic, label-independent random partitions with seed 20261103: 30% locked target rows, remaining 70% historical models split 80/20 into fitting and validation. This fixed target pool prevents pilot observations reappearing as targets in another random split. Report that inference concerns these finite model pools, not all future LLMs.

Before evaluating the lockbox, freeze methods, item budgets, development sampling seeds, final item-draw seeds and run configuration. Tune source-trained estimators on validation full scores using independent development item draws, then refit on all historical models. For a given budget and final repeat, share one uniform item sample across random-mean, source-difference, ridge, calibrated-mean, random-IRT and crossfit-difference methods. Cluster anchors use their own selected items at the identical budget. Include the zero-item source-prior predictor. A budget of 100 is 23% of the smallest matrix: include 10 and 30; any larger-budget curve must label the fraction and cannot substantiate 'very small subset' for small benchmarks.

Suggested primary budgets: 10, 30, 100; 20 or more independent final item draws; tune on 5 distinct development draws. A larger 300-item budget can be descriptive for large matrices only. Primary metrics are full-score MAE and RMSE in percentage points; Spearman and Kendall tau-b are secondary and retain ties. Undefined correlations (constant predictions/truth) must remain undefined with counts, not be assigned zero. Save every per-target prediction with source split, item IDs, full truth used only for evaluation, method/hyperparameters, timing, fit diagnostics and data hashes. Report bias, out-of-range predictions, close-pair inversion and source fit overhead as diagnostics.

Paired uncertainty must match the design. Across item draws, use paired per-repeat differences and Monte Carlo intervals conditional on the fixed target/historical model pools. Across benchmarks, show per-benchmark outcomes and macro-averages without treating target rows or repeated item draws as independent benchmark replicates. Bootstrap benchmarks as a descriptive uncertainty summary, with only 13 heterogeneous finite datasets and no claim they are a random sample of all benchmarks. For family stress tests, use only verified per-benchmark OpenLLM names and call grouping a string-based proxy, not verified ancestry. Source-size and exact-response-deduplicated sensitivities assess limits. Required robustness may change when the plan owner settles the study.

# Pairwise leaderboard sensitivity: analysis

In the delivered paper project, run `cd analysis` first. Every command below is relative to that directory. In this standalone analysis repository, its root already is the analysis directory.

Create an environment with Python 3.11 and `python3 -m pip install -r requirements.txt`; the exact package versions used are pinned.

Raw inputs are kept in ignored `data/`; pinned download URLs, versions, licenses and SHA-256 values are recorded in `results/provenance.json`. Source constraints are in `notes/independence.md`. See `notes/methods.md` for estimands and the intervention.

```sh
python3 scripts/fetch_data.py
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python3 scripts/check_methods.py
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python3 scripts/run_study.py --mode pilot --out results/pilot --random 10 --bootstrap 20
```

The pilot sizes final experiments; its output is not the full study. `scripts/run_study.py` records package versions, arguments, elapsed times, convergence diagnostics, exact refits and random replicates. The full commands below reproduce the delivered study; pilot results are retained as execution provenance.

Full-run commands (one BLAS thread; CPU only):

```sh
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python3 scripts/run_study.py --mode primary --out results/primary --random 500 --bootstrap 500
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python3 scripts/run_study.py --mode robustness --out results/robustness --random 100 --bootstrap 300
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python3 scripts/run_study.py --mode matched --out results/matched --random 0 --bootstrap 0 --replicates 100
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python3 scripts/run_study.py --mode matched_bootstrap --out results/matched_bootstrap --random 0 --bootstrap 0 --replicates 500
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python3 scripts/diagnostics.py
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python3 scripts/verify_witnesses.py
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python3 scripts/summarize.py
```

Install `requirements.txt` in Python 3.11+ (recorded actual Python version in `run.json`). Default seed is 20261102, with dataset/replicate offsets defined in the runner. The sum of measured per-dataset times is 99.4 seconds for primary, 33.1 seconds for robustness, 5.3 seconds for matched label selection, and 34.0 seconds for the matched joint bootstrap on the shared host. Full reproduction is expected to take a few minutes excluding downloads; file-level times are recorded and host contention changes runtimes. Raw inputs total about 204 MB. No paid API/GPU is used. This analysis code and its documentation were developed with AI assistance; no LLM was queried to generate experimental labels.

After the matched bootstrap run, generate the original-pair control with:

```sh
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python3 scripts/matched_fixedpair.py
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python3 scripts/nba_home.py
```

The matched runner's per-replicate directories are ignored to avoid thousands of duplicate files; consolidated audit/summary CSVs preserve all reported numbers. Full directories are regenerated by the commands above. `results/witnesses` contains processed row indices of the primary successful attacks; original inputs remain outside version control. The presentation owner supplies final figure/table generation scripts and the manuscript owner supplies their mapping in the delivered project.

Archived summaries can be regenerated without downloading data using `python3 scripts/summarize.py`. This reads full primary/robustness replicates and the consolidated matched audits. Recomputing the fixed-reference-pair control requires the regenerated matched-bootstrap per-replicate directories as shown above. Method checks require no data; exact witness verification requires the pinned raw files. The verification command prints a PASS message only after reconstructing every found primary attack and checking its recorded refitted margin.

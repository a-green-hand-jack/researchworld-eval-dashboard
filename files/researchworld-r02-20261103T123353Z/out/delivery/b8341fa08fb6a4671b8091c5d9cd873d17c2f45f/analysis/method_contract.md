# Analysis contract (frozen observed-composition study)

Target: a random **observed composition** Y in Delta^(K-1). The event is Y_test in C(X_test). A class label does not provide an observed latent probability vector; no latent-probability or classifier calibration claim follows from these experiments.

All transformations, location predictors and scale predictors must be fixed using proper training data before calibration. Split conformal uses q = the ceil((n_cal+1)(1-alpha))-th smallest calibration score, with the (n_cal+1)-th score equal to infinity. This must not be silently replaced by the maximum of the observed calibration scores. With exchangeable scalar scores, marginal coverage is at least 1-alpha. With continuous scores and no ties it is exactly ceil((n_cal+1)(1-alpha))/(n_cal+1), so finite-rank conservatism must be distinguished from experimental uncertainty. Group calibration applies the same rule to calibration data in each predeclared group; small groups can yield the whole simplex.

TV score: ||Y-mu(X)||_1/2. Euclidean score: ||Y-mu(X)||_2. Hellinger: ||sqrt(Y)-sqrt(mu(X))||_2/sqrt(2). ILR: ||B^T log(Y)-B^T log(mu(X))||_2 with K by K-1 orthonormal contrast matrix B. All scalar balls are intersected with the simplex. Coordinate intervals are similarly intersected with the simplex: using alpha per coordinate is a deliberately invalid *joint-coverage* control; using alpha/K is a union-bound joint-coverage baseline. Neither receives a claim of simultaneous conditional coverage.

At exact zeros, ILR without smoothing is undefined. The explicit sensitivity score is ILR(T_epsilon(Y)) with T_epsilon(y)=(y+epsilon)/(1+K epsilon). The reported region is the inverse image of a ball under this fixed map and contains the original Y event, including zero faces. Its exchangeable marginal coverage is retained; its shape and efficiency depend on epsilon. We do not impute and then claim a set for a different target, discard zero observations, or apply the interior guarantee unchanged under shift.

Do not compare raw radii across metrics. Efficiency comparisons require a common measure; the proposed main measure is simplex area/volume normalized by the simplex's own measure. Computational integration error must be checked separately from across-repeat sampling uncertainty. Coverage of predeclared groups and shifted tests is measured separately from marginal exchangeable coverage, without a distribution-free conditional or shift guarantee.

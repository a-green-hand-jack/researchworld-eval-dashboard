# Reliability beyond marginal coverage for observed compositions

The paper studies prediction regions for an **observed response vector** in the simplex. It does not cover a class label or infer a clean latent probability vector from one label. The result-bearing [paper.pdf](paper.pdf) includes the executed seven-method core, exact-ratio oracle, matched TV/forward-KL score supplements, rank/tie checks and boundary/replacement sensitivity. The complete ten-method figures and tables are integrated. Independent review remains required before final research release.

## Reproduce the evidence

[analysis/README.md](analysis/README.md) gives exact generation, calibration, sensitivity, summary, audit and evidence-map commands. The recorded environment is Python 3.11.2, NumPy 2.4.6, SciPy 1.17.1 and pandas 3.0.6. Install the pinned dependencies from `analysis/environment.txt` in a separate environment. Use `OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1` to avoid oversubscribing small CPU hosts.

There is **no dataset download**. The logistic-normal generator and all fixed coefficients/settings are in `analysis/benchmark.py` and `analysis/methods.md`. Main seeds 901000–901099 supply 100 independent train/calibration/test repetitions in each dimension/calibration/noise cell; boundary seeds 902000–902049 supply 50 fresh repetitions per dimension. Coefficients use seed 1729+K; the rank-grid seeds and 20,000 trials per cell are documented in `analysis/notes/sensitivity_freeze.md`. Pilot seeds 900000/900001 are excluded from every paper result.

Raw results and source hashes/manifests remain under `results/`. `analysis/evidence_map.md` identifies supported claims, exact cells and limits; `results/audit.json` records row counts, jobs, exclusions and measured compute. The core used 116.110 s running wall / 124.165104 CPU s, and the oracle/rank/boundary extension used 43.878 s wall / 45.080784 CPU s, excluding resource startup. The TV/KL supplement additionally used 45.631351 CPU s and resource-reported 44.498 s running time (its separately recorded per-cell duration sum is 59.927 s). The pilot took about three seconds; no resource run failed and no confirmatory repetition was excluded. A pre-main infinity serialization correction is disclosed in the retained notes. These experiments are CPU-only; resource containers have the sandbox ceilings of 2 CPUs and 4 GiB memory, and BLAS uses one thread in the documented commands. Peak memory was not measured. Reproduction should take a few minutes plus summarization on a similar CPU host; timings vary with shared-host load. No GPU or paid prediction API is needed.

[manuscript/claim_provenance.json](manuscript/claim_provenance.json) records every macro's exact source file, SHA-256, selected cell, column and rendered value. This script extracts owner-supplied estimates; it does not refit models or recompute their inference. Pointwise 95% t intervals use independent full-dataset repetitions; method/environment contrasts are paired. Wilson intervals describe the frequency of finite-test coverage estimates below a threshold, not certified population-conditional coverage. Area is a chosen Euclidean-simplex reference at K=3 only. The explicit original-response inverse-image region inherits measured transformed coverage by exact event identity, including zeros; this is distinct from direct original-clr membership, and its original-simplex area was not estimated.

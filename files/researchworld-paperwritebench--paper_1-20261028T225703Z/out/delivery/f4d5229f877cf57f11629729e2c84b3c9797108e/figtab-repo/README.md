# figtab-repo: presentation of figures and tables

- `tools/make_tables.py` generates `tables/table_{le,rr,im}.tex` from numbers transcribed from the supplied tables; bold/underline/delta rows are computed from the cells.
- `figures/src/make_foret_ablation.py` regenerates `figures/foret_ablation.pdf` from the numbers printed on the supplied figure.
- Supplied figures with no recoverable data (curves, histogram, schematic, example) are delivered unchanged from /initial-state/inputs/5.

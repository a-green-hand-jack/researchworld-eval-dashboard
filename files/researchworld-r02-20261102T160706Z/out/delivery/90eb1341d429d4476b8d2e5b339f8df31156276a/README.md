# paper-repo

Delivery root of the study "conformal evaluation on composition-valued predictions" (NeurIPS 2026 format).

- `paper/` LaTeX source (`main.tex`, `sections/`, `refs.bib`, template `neurips_2026.sty`, `checklist.tex`); build: `cd paper && latexmk -pdf main.tex`.
- `paper.pdf` the paper built from `main` (state: draft; sections are filled as results are merged).
- `figures/`, `tables/`, `figtab/` figure/table delivery (figtab-repo); `src/`, `scripts/`, `results/`, `REPRODUCE.md` code and results (experiment-repo); `venue/` template facts (venue-repo).

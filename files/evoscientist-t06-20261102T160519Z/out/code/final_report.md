# 研究报告：成对比较排行榜的稳定性

## 1. 摘要与目标

本研究完成了对**固定比较安排下的胜负翻转敏感性**的可复现审计，覆盖众包偏好、专家判断、模型裁判和体育比赛。研究对象是固定数据与拟合规则下原第一名/第二名的相对次序，不是平台生产排名、真实标签错误率或现实攻击成功率。

核心发现：**单一“改动占全部数据的比例”不足以解释稳定性**。需要同时给出目标比较量、原分差、随机扰动对照，以及平局/正则化敏感性。不同分母甚至会改变对数据集脆弱程度的描述性排序；这不能解释为评测设计的因果优劣。

交付：`paper.pdf`、`paper/` LaTeX 源文件与官方模板/完整 checklist、`reproducibility.zip`、`README.md`、全部代码与数值结果。论文采用 NeurIPS 2026 Main Track 官方匿名提交模式，正文 7 页，参考文献/附录/checklist 不计正文页限。

## 2. 实验计划

1. 预先规定目标、sum-loss ridge BT、翻转单位、指标、对照、种子和敏感性检查；保存于 `todos.md`。这是探索性研究，不是外部预注册。
2. 下载固定快照并验证校验和，检查图连通性、标签、重复游戏、比较单位和缺失。
3. 用初始影响分数排序候选翻转，通过完整数值重新拟合验证。比较等预算随机、目标相关随机、方向有利随机和按比较边匹配的随机翻转。
4. 运行 200 次经验重抽样、共享支持/样本量检查，以及固定目标的正则化、平局、主场效应消融；附加自适应翻转和同估计器删除对照。
5. 代码审计、论文自审、独立虚拟环境复现和 PDF 编译检查。所有重要修正保留在 `experiment_log.md` 和审计记录中。

成功信号已满足：至少两类真实评测设计、收敛拟合、逐行验证成功实例、重复随机对照、不同估计规则检查、可运行复现代码和完整论文。**全局最小预算、因果比较与主会接收保证未被设为或冒充已达成目标。**

## 3. 设置

- 数据：Arena55k 57,477 条/64模型；MT人类3,355条/6模型；MT GPT-4 2,400个导出结果/6模型；NBA 2013/2014/2015各1,314/1,319/1,311场/30队。固定版本、来源与SHA256见 `data/manifest.json`。
- 估计器：总 logistic loss + `lambda/2 * ||theta||²`，主实验lambda=1；平局记0.5。GPT导出中380个不一致结果也作为半标签，另做排除敏感性检查。所有平局不参与二元翻转。
- 编辑：翻转不同原始决定性结果，每条至多一次；原始比较对、协变量、权重和参赛者不变。GPT单位是导出成对结果，不是未公开的单次调用；NBA是记录结果的反事实变化。
- 主要终点：原第二名重新拟合分数超过原第一名，差值超过1e-7；不要求原第二名变成新的总第一名。
- 规模指标：k、k/N、k/E。E是涉及任一目标的比较并集，直接对战只算一次，含保留的平局。一般k/E仅为曝光参照成本；本研究六个主实例恰好全由目标相关记录构成。
- 计算：Python3.11.15，CPU单BLAS线程；可见Xeon Gold6230。主程序实测42.03秒；补充程序3.46秒。独立虚拟环境重跑主程序41.26秒、峰值RSS301.87MiB。峰值仅对应该重跑子进程；不是全研究资源总量。依赖直接版本及完整重跑锁定清单均已提供。

## 4. 基线与比较

- 每类对照在相同成功实例k下随机抽100次；另报告曝光参照预算网格的剂量曲线。Wilson区间描述给定数据上的Monte Carlo概率，不是跨排行榜总体推断。
- 自适应重线性化：每步重新拟合并重新选择候选；六个主面板的实例预算均未改善。
- 同估计器删除：成功实例分别为3/92/144/5/7/16条；删除与翻转是不同干预，不能据此声称相对已有删除方法算法更优，也不是对既有论文数字的复现。
- MT匹配1,232个相同有序问题/模型对/轮次单元；人类每单元选一条原始判断，共20个种子，GPT只运行一次。Arena从3,222条全数据拟合前六模型内部池中抽2,400条，共20个不同记录集合；这是样本量/队列描述性对照，不是模型身份、分差或因果匹配。

## 5. 实测结果

**以下k全部是重新拟合验证的充分实例，是未知最小预算的上界，不是已证明的最小值。**

| 数据 | k | k/N (%) | k/E (%) | 原分差在200次重抽样中为正 |
|---|---:|---:|---:|---:|
| Arena众包 | 2 | 0.0035 | 0.024 | 110/200 |
| MT人类 | 46 | 1.371 | 2.521 | 199/200 |
| MT GPT-4 | 61 | 2.542 | 4.236 | 200/200 |
| NBA2013 | 3 | 0.228 | 1.508 | 155/200 |
| NBA2014 | 4 | 0.303 | 2.041 | 163/200 |
| NBA2015 | 8 | 0.610 | 4.145 | 199/200 |

- 每面板等k的全局均匀与目标相关均匀对照均0/100成功；0/100的双侧95% Wilson上端为3.7%，不能解释为随机扰动永不成功。比较边匹配对照在Arena/NBA2013/2014/2015有17/27/1/15次成功，两MT面板均0次。
- MT共享支持上，GPT实例k=33；人类20次选择的k为14–21，中位16.5。曝光参照比例分别4.64%和人类中位2.32%。差异仍受分差等因素影响，不代表GPT裁判天然更可靠。
- Arena前六模型2,400条样本的k范围2–14，中位6；20份记录集合均不同且小于原池，不将重排全池误当重复实验。
- 固定原目标：Arena在lambda=.1/1/10下k=1/2/11；去掉平局即使原次序逆转，无需翻转。MT人类去平局k42；GPT去全部平局k40、只排不一致结果k47，主设置为61。NBA主场调整及所测ridge范围未改变3/4/8的实例预算。
- NBA2015与MT人类按全局比例为0.610%<1.371%，按目标曝光比例却为4.145%>2.521%。这是分母选择下实例描述排序的变化，而非真实“稳健性优劣”的因果结论。

主要证据：`artifacts/baseline.csv`、`controls.csv`、`uncertainty.csv`、`matched.csv`、`fixed_target_ablations.csv`、`witness_rows.csv`、`witness_verification.csv`。论文每张表图均由 `src/report.py` 生成；完整映射在 README 和论文附录。

## 6. 解释、局限与后续

### 应如何解释
Arena的两条翻转对应一个本来就难以区分、且对估计规范敏感的领先对，不能称为两票推翻“牢固确立的赢家”。小全局比例与小局部污染比例不是同一概念。预算只有在固定单位、目标、分母和估计器之后才有清楚含义。

### 重要限制
- 影响排序/前缀搜索不穷尽子集；即使验证k−1，也不证明最早前缀或全局最小预算。未找到实例不能认证稳健。
- 经验重抽样改变比较安排，保留原数据选择的目标；分位带仅为描述性。前30次辅助预算以原分差为正为条件，并允许重复原始ID的重抽样槽位，不是原始物理记录最小预算的置信区间。
- 众包用户依赖、NBA时间/球队依赖、交叉标注者依赖未被完整建模。共享支持、曝光归一化、20个种子均不足以消除评测设计混杂。
- 不复刻Arena生产端倾向加权、语言筛选等规则；不识别实际恶意投票、真实错误标签或现实存量数据修改权限。
- 已有允许文献包含删除审计、影响排序和完整重拟合。本研究没有“首次发现排行榜脆弱”或“首次使用精确重拟合”的贡献。独立自审认为**主会新颖性充分性仍是明显投稿风险**；该风险没有通过虚构新方法或弱化已有工作来掩盖。

### 复现与最终核验
原环境与新建锁定虚拟环境的七项测试均通过；13个确定性结果CSV在rtol1e-8/atol1e-9内一致，计时字段另计；六个原始记录翻转均独立重建并收敛验证。匹配文本表示检查为1,751个人类候选行中零不匹配，但不打印/打包对话。正文7页，16项官方checklist已填，编译无未解析引用或溢出框警告。原始数据独立存放且不进入复现压缩包。

已记录的失败包括初始解析不一致平局、无效全池重复、平局argmax指标和资源重跑设置；当前产物均已修正。没有未完成的实验被写成已完成。主会录用、因果设计结论、全局最小预算与上游标注合规认证均未被保证。

后续优先方向：验证真正最小预算的上下界、固定分差与比较网络的控制实验、依赖结构更完整的重抽样及更丰富现实噪声机制。这些不属于本次已完成实测。

# Pre-analysis protocol / plan
Written before data inspection or model runs, 2026-11-02. Exploratory audit, not preregistered confirmatory causal comparison.

## Narrow story and rejection risks
Task -> small fixed-schedule label changes -> separate global budget from local exposure, random from directed flips. No claim to first refit audit. Prior deletion work already has refits and cross-judge comparisons. Contribution sought: reproducible fixed-design finite-flip witness audit and empirical exposure-matched comparisons across domains.
Risks: (1) limited novelty: explicitly contrast deletion and injection, no state-of-art claim; (2) dataset confounding: matched MT human/GPT cells, subsampling, no causal attribution to design; (3) heuristic mistaken for minimum: only witness upper bounds, no robustness certificates; (4) uncertainty: repeated random flips, bootstrap; (5) regularization/ties/unit choice: ablations and limitations.

## Stage 1: data + baseline (experiment-pipeline, adapted audit gates)
Download pinned Arena55k, MT human and GPT4, NBA. Verify supplied hashes. Parse labels, retain ties as y=.5. MT GPT reciprocal judgments separately and clustered by question for uncertainty; matched exact question/model-pair/turn aggregate sensitivity if available. NBA seasons 2013, 2014, 2015 (year_id), deduplicate _iscopy==0, team codes within season, no home correction main, home-covariate sensitivity. Arena include participants with >=100 appearances, iterate once to eligible comparisons; document excluded rows. Connectedness check. Fit sum log-likelihood + lambda/2 ||theta||² with lambda=1, centered theta. No tuning to improve vulnerability. Unit tests: symmetric fit, closed form two-model, finite-difference influence, duplication invariance with scaled ridge, exact refit agreement, flip integer constraints.
Success: data manifests + EDA, convergence gradient <1e-7 (fallback documented), tests passing.

## Stage 2: baseline perturbations
Unit = one original judgment/game row; tie flip magnitude <=1 and cost row count. Decisive rows only eligible for binary flip y->1-y; ties held fixed. Fixed participants and comparison schedule. Primary target = baseline leader vs baseline runner-up. Primary outcome: k witnessed flips that make runner-up strictly exceed baseline leader, normalized by N and target-union exposure E (rows incident to either target). Also direction-specific dose-response at local E budgets 0.5%,1%,2%,5%,10%,20%; Kendall pair disagreement and top1 replacement secondary. Global results not comparable without E.
Baselines: (a) uniform random subset of decisive rows, (b) uniform random subset restricted to incident target rows, (c) target-incident direction-beneficial random order, (d) frozen influence sorted flips across all rows. For (c), eligible score computed exact local derivative >0, restricted incident to targets. Budget counts physical rows, no weights or fabricated rows. For witnesses restrict one-time flip per row. Upper bound censor at 20% of decisive rows. Search sorted prefixes at powers of two, then binary-refine first crossing bracket, verify final and k-1; no global minimality or monotonicity claims.
Success: all advertised successes refit-verified, random controls with 100 repeats, count/percentage/exposure denominators explicit.

## Stage 3: sensitivity / uncertainty
Conditional bootstrap fixed comparison schedule: binomial or row-resampling outcomes? Primary sampling bootstrap resample original rows N times preserving row pairing; MT cluster questions, NBA row games, Arena row votes. 200 repetitions for leader-vs-runner positive margin fraction and percentile interval; descriptive not simultaneous population CIs. Conditional uncertainty is not attack uncertainty. Witness recomputation on 30 bootstrap datasets (exploratory, selected-target conditioning). Ridge lambda 0.1,1,10; no ties vs half ties; Arena N matched to MT via random subsamples (3 seeds; only common top6 set if needed); matched MT question/model-pair/turn cells averaged to one soft label then decisive-row flip analysis main stays original rows. We will only run feasible, semantically valid ablations and label changes in experiment_log.md.
Success: at least two real designs; 3+ repeated subsample seeds; failure cases retained. No forced positive result.

## Stage 4: figures, paper, verification
Generate every table/figure from CSVs via src/report.py. NeurIPS2026 official 9-page submission content, references/appendix/checklist excluded. Write paper + supplementary protocol; compile; audit mathematical claims and code; smoke reproduce clean directory. Artifacts: data_manifest.json, eda.csv, baseline.csv, witnesses.csv, random_curves.csv, uncertainty.csv, ablations.csv, plots and generated .tex tables, paper.pdf, README.md, requirements.txt. No raw data in submission bundle.

## Time/resource budget
Fits aggregate by unordered participant pair, so optimization operates on <=M(M-1)/2 rows, not text. Read Arena CSV in chunks use only model/label columns. Small dense Newton with scipy Cholesky, single BLAS thread, four cores max. Initial target runtime <1 hour; background if >30 seconds. Cap repeats if evidence already stable; all deviations recorded. No hyperparameter fishing or superiority stopping rule.

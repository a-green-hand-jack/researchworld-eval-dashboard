# Regression estimators of the global average treatment effect under network interference

This tree holds the paper (`paper/`), the simulation code (`code/`), the raw and summarised results (`results/`), the figure and table scripts (`figures/`, `tables/`), and the reproduction notes (`REPRODUCE.md`: environment and versions, the two public graphs with their SHA-256 digests, seeds, one command per grid, run time, and the map from each figure and table to its script).

Outcomes are simulated; the only external data are two public Facebook graphs (Stanford3, ego-Facebook), downloaded by the commands in `REPRODUCE.md`.

The task reserves one published paper for judging the result. Nothing in this study read it, or anything citing or discussing it, and none was met by chance.

# Analysis of the experimental log: what it supports, and with what wording

Source: `[EXPERIMENTAL LOGS]` in the task (`/initial-state/inputs/0/INSTRUCTIONS.md`) and `figures/figure_1.png`.
Files: `results_ledger.csv` (every logged number, transcribed), `gap_check.csv` (stated gaps re-derived),
`digitized_fig1.csv` / `fig1_gaps.csv` (bars read off Figure 1, ±1 pt, **not log values**), scripts `build_ledger.py`, `digitize_fig1.py`.
No new experiments were run: the task supplies no code, data or models, and numbers outside the log may not be reported.
Everything is single-run: the log has no seeds, standard deviations or confidence intervals, and accuracies are mostly whole percents.

## Checks that pass
- All 12 "Performance Gap" rows reproduce from the table entries (`gap_check.csv`). Gaps are absolute differences.
- The CIFAR-10 default configuration (10 % forget, 500 perturbations, λ = 0) recurs with identical numbers (70/71/68/51.4) in the forget-size, perturbation, λ and baseline tables, so those tables are views of one run. It is an inference that this is the default; the log never says so. The Retrained row is 72/74/72/50 in all of them except the 15 % and 5 % rows (73/75/73/50 and 73/74/73/49.4), so Retrained was re-run (or re-measured) per forget size, as it must be.
- Figure 1 CIFAR-10 panel agrees with the logged linear-classifier values within digitization error.

## Discrepancies the writing must not paper over
1. **Mixed-linear table: the stated gap is Unlearned(−) vs Unlearned(+), not vs Retrained.** The 0.1 / 6.6 / 3.9 / 0.4 (20 %) etc. only match that reference. Against Retrained the gaps are larger: test 2.2 / 1.7 / 0.9 (20/15/10 %), remaining 4.3 / 1.2 / 1.9, forget 0.6 / 1.1 / 2.7, MIA 0.8 / 1.5 / 2.3. The log's sentence "gap remained low (0.1–0.5 % test accuracy)" is therefore a statement about agreement with the *exact-Hessian* model. Say so; a "comparable to retraining" claim must use the Retrained-referenced numbers.
2. **Remaining accuracy of Unlearned(−) in the mixed-linear table sits above Unlearned(+) by up to 6.6 pts at 20 %** (70.0 vs 63.4) and above Retrained (65.7) by 4.3. Unlearned(−) does not approximate the true Hessian solution on retain data there. At 20 % it is also the only setting where the remaining accuracy jumps (70, 70.1, 70.1 flat across 20/15/10 %, while Retrained/Unlearned(+) fall 72→65.7 as forget grows). Report as observed; do not explain it as "good approximation" without qualification. Candidate explanations (not tested): estimated Hessian under-regularises, so the update behaves differently from the exact Newton step.
3. **Figure 1 shows a systematic gap to Retrained outside CIFAR-10** (`fig1_gaps.csv`, digitized): test accuracy of Unlearned(−) is 4–5 pts below Retrained on CIFAR-100, Dogs and Caltech256, forget accuracy 6–7 pts below. It tracks Unlearned(+) much better (|Δ| ≤ ~3 pts), but both are below Retrained. The caption's "comparable to retraining from scratch" holds for CIFAR-10 (−2 test) and loosely elsewhere; the supported statement is "Unlearned(−) tracks Unlearned(+) closely; both lose a few points (about 4–7 on test/forget accuracy for the three harder datasets) relative to Retrained". Forget accuracy below Retrained is also ambiguous: Retrained forget acc ≈ test acc, so a forget accuracy *below* test accuracy (e.g. 68 vs 70 on CIFAR-10) suggests mild over-forgetting; the MIA scores (50.5–52) do not show it.
4. **Figure 1's CIFAR-100 panel is not the mixed-linear experiment**: Retrained test accuracy is ≈56 there vs 63.7 for the 10 % mixed-linear row. The log never states which classifier Figure 1 uses. CIFAR-10 matches the linear classifier, so the safest wording is "linear classifiers on frozen ResNet-18 features" for Figure 1 and a clear separate label for the mixed-linear table. Dogs and Caltech256 appear only in Figure 1 (no table): their numbers may only be quoted as approximate, read from the figure, or not quoted.
5. **Forget size 5 %**: Unlearned(−) and Retrained rows are identical in all four metrics (73/74/73/49.4). Report faithfully; a zero gap at the resolution of whole percents is not "exact equality of models".
6. **Non-monotone, non-interpolated trend**: gap in test accuracy 0 → 2 → 14 pts for 5 → 10 → 15 % forget. That is a sharp jump between 10 and 15 %, three points only. "Widens with forget size" is supported; "consistent with the bound" is a theory-side claim with no quantitative test in the log (no bound value is ever computed). Same for λ: three values, gaps 2→1→0 on test accuracy; the monotone direction is supported, the "inversely proportional to λ²" claim is not testable from the log and is not in idea.md's theory — attribute it to the (unseen) theory or leave it out. The λ trend holds for test/remaining/forget gaps (2→1→0, 3→2→1, 4→1→0) but **not monotonically for MIA** (1.4 → 0.2 → 0.9): λ = 0.0005 is closest to 50.
7. **Perturbation count**: 250 → 500 → 1000 gives test gap 15 → 2 → 0 (MIA gap 6.2 → 1.4 → 1.0). Supported as stated ("more perturbations help"). Note 250 perturbations is a regime failure (−15 pts), so the method is sensitive to the sampling budget; worth a limitations sentence. The perturbation count relative to the parameter dimension (≈ 512×10 for a ResNet-18 linear head on CIFAR-10, an inference, not in the log) is not given.
8. **MIA is not a differentiator in the baseline comparison.** All methods have MIA within 47–51.4 (NegGrad 48, RandomLabels 47, JiT 49.1, Adversarial 50.0, Unlearned(−) 51.4); Unlearned(−) is actually *farther* from 50 than JiT and Adversarial. The advantage is in utility: test 70 vs 51.5–52.1 (and 20.6 for Random Labels), remaining 71 vs 52.7–53.2, forget 68 vs 51.0–51.2 against Retrained at 72/74/72. Never write "best MIA". Baselines are singly-run at one setting (10 %, CIFAR-10, linear classifier).
9. **Metric semantics**: "MIA score" is the attack score where 50 % = indistinguishable; one number, no AUC/threshold description in the log. The log says "Performance Gap" = Retrained vs Unlearned, absolute (confirmed from the table).

# Evaluation protocol

This is an exploratory study, not a preregistered confirmatory evaluation. Data and implementation audits revised the initial cohorts before the final corrected suite; all changes and superseded runs are recorded in RUN_LOG.md.

The primary estimand is raw-score MAE for a held-out, fully observed model row after k exact benchmark measurements. RMSE and training-standard-deviation-normalized RMSE are secondary metrics. Scores are fractions; multiply raw errors by 100 for percentage points. Equal weights per unqueried task and then per unique evaluated model define reported means. Query budget is count, not runtime.

The primary MTEB cohort retains only explicitly English-labelled main scores (including English-involving crosslingual tasks), each task's modal English subset signature, one most-covered model revision, and its exact modal dataset revision. Coverage-only cohort construction uses no score values. It drops the CQADupstack composite to avoid its overlap with the individually counted components. `results/cohorts.json` is authoritative for row counts, task names, fixed task revisions, and cohort rules. The wider strict cohort and mixed-revision cohort are sensitivity analyses. Main conclusions condition on complete validation/test rows; sparse rows contribute training history. This is not evidence for poorly evaluated models excluded from the test cohort, arbitrary missingness, or deployment to different evaluation definitions.

For random partitions, 60/20/20 train/validation/test model rows are stratified by complete-row availability, with seeds 0–9. Validation and test retain only complete rows. All task means, standard deviations, covariance, selection, predictor fits and hyperparameter choices use training/validation rows only. Provider shift uses disjoint model-name namespaces across partitions; at least six complete validation/test rows are required, retrying deterministic group seeds if needed. Namespaces are provider proxies, not certified model lineages. Some related models may remain across provider partitions.

Covariance: pairwise-observed centered products divided by overlap count minus one, symmetric PSD projection, and shrinkage to its diagonal. Shrinkage {0.05,0.2,0.5,0.8} minimizes validation MAE averaged over nonzero k on A-optimal queries. Greedy A-optimal selection maximizes estimated whole-vector squared-error reduction; D-optimal maximizes conditional variance. Random (eight independent query orderings per split), marginal variance, and marginal mean squared correlation share the covariance predictor and the shrinkage tuned on A-optimal validation queries. This isolates query policy under that fixed predictor, rather than independently tuning every selector pipeline. Conditional prediction is clipped to [-1,1], preserving negative correlation metrics. Mean (k=0), rank-one ability, direct ridge and rank-four iterative-SVD factor covariance use the A-optimal query sets to isolate prediction differences. Ridge {0.001,0.01,0.1,1} is separately validation-tuned. Rank four and 20 imputation steps are fixed design choices. No method sees test targets while fitting or selecting.

Missingness stress removes 30%/60% of training cells independently, in addition to their natural missingness; it does not assert missing-at-random for public leaderboards. Dense-history uses only complete training rows. These retain identical validation/test rows for paired comparisons. Wider-cohort changes both tasks and evaluated models; compare sensitivity qualitatively rather than as a paired causal effect.

A fixed-target diagnostic reserves 20% of tasks (at least two), independently per split by seed 500+s, from every policy's query candidates and evaluates solely these common tasks. It uses the primary validation-chosen regularization. Its A-optimal rule still maximizes whole-vector variance reduction over the eligible query pool; it does not optimize target-only risk. This controls changing target composition in the deployment loss. Main all-remaining-target loss still answers the task's original estimand.

The Open LLM Leaderboard secondary cohort uses six raw benchmark scores, drops flagged entries, chooses one precision per model name, and deduplicates identical nonempty model-commit SHA aliases. Provider shift uses name namespaces. Chronological shift orders by submission date with deterministic ties and one 60/20/20 partition; this is submission chronology, not verified release chronology or ten independent temporal replications. It is deliberately a six-task scope check, not a high-dimensional replication of MTEB.

Uncertainty: average query draws within a model/split, then average each unique model's held-out appearances across seeds; bootstrap unique models 4,000 times with seed 20261102. Intervals are descriptive model-cluster percentile intervals conditional on the observed cohort and split ensemble; they do not establish population-valid significance given unknown lineage dependence and shared training sets. Paired effects match model/split, average query draws, then use the same unique-model bootstrap. Seed MAE ranges separately expose partition sensitivity. Report neither random draws nor repeated appearances as independent models.

# Boundary-rate uncertainty and claim guard

No extra experimental runs or changed adequacy threshold are involved. The mean of the30 run events per explained input is one bounded observation in[0,1]. Inference uses independent sampled inputs as clusters, conditional on the fitted model/split/background. Seeds or seed-pairs do not increase the number of independent cases.

Interior descriptive curves retain the prespecified pointwise percentile instance-cluster bootstrap. The raw bootstrap endpoints are always retained as `bootstrap_ci_low`/`bootstrap_ci_high`. A finite all-success/all-failure panel would make this bootstrap degenerate. For a statistic known by definition to lie in[0,1], if all case means are exactly0 or1, the displayed `ci_low`/`ci_high` instead use a two-sided95% Hoeffding interval for a bounded independent-instance mean: estimate +/- sqrt(log(2/.05)/(2*n_instances)), clipped to[0,1]. `boundary_adjusted` and `interval` identify the replacement. This does not claim a uniformly exact95% coverage theorem for the interior percentile approximation.

Separately, every bounded rate/overlap has `bounded_mean_low95` (one-sided95% lower) and `bounded_mean_high95`, using radius sqrt(log(1/.05)/(2*n_instances)); also both two-sided bounded endpoints. These are conservative finite-sample guards under the same independent-instance sampling assumption, with no assumption that all instances have equal run success probability. No survey-population or model-retraining inference follows. Sampling without replacement from the held-out rows and dependence in the original data remain limitations of population interpretation.

`certifies_mean_ge_0p95` may be true ONLY if the conservative one-sided lower bound clears.95. With60 inputs this guard cannot certify.95 even for zero observed failures. Therefore this study reports estimated/observed single-run adequacy and its uncertainty; it does not turn all-success cells into a population95% guarantee. This is an inference limitation, not a measured explanation failure or a changed target. Per-instance Wilson intervals over independent random seeds remain separately labeled and cannot certify each instance either.

Implementation: `cluster_bootstrap(..., bounded_01=True)` is used only for outcomes bounded by definition, not for normalized errors or cost. Pairwise repeatability also uses one bounded mean per instance; it never treats435 seed-pairs as435 independent cases. Difference/error contrasts preserve their descriptive bootstrap intervals and make no boundary certification.

Checks in `tests/test_metrics.py` independently derive the Hoeffding radius, require positive-width all-success/all-failure intervals, reject automatic95% certification, test the .01 denominator floor, and separate the signed-top3 primary event from top1-only agreement. Same-reference-denominator pairwise vector distance is primary; average-run normalization is retained under a separate field.

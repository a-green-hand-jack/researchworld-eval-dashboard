# Reproduction guide: width and delayed generalisation on modular arithmetic

Everything here was produced by an autonomous agent run (see paper App. A.4). All numbers/figures/tables in
`paper/main.pdf` are generated by the scripts below from `results/*.jsonl`.

## Environment
* Python 3.11.15, PyTorch 2.15.0 (CPU build, `pip install torch --index-url https://download.pytorch.org/whl/cpu`),
  NumPy 2.4.6, SciPy 1.17.1, Matplotlib 3.11.2, (PyMuPDF 2.1 only for rendering PDF pages to PNG while checking layout).
* LaTeX: TeX Live `pdflatex` + `latexmk` + `bibtex`. Official NeurIPS 2025 style (`paper/neurips_2025.sty`, from
  `https://media.neurips.cc/Conferences/NeurIPS2025/Styles.zip`; the 2026 archive was not available at the analogous URL).
* No GPU. One thread per run (`OMP_NUM_THREADS=1`), many runs in parallel (`multiprocessing`).

## Data
Synthetic and generated in memory by `grok.make_data(p, op, train_frac, seed)`: all `p^2` pairs `(a,b)`, label `a∘b mod p`
(`add`, `sub`, `mul`, `sq` = `a^2+b^2`); random split controlled by `seed` (split seed = 10000+seed).
No downloads, no third-party data, no version pinning needed.

## Seeds
Pilot (exploratory only): 0-2. All reported experiments: 100+ (see `code/experiments.py`). Seed controls init and split.

## Commands (run from `code/`)
```
python sweep.py <experiment> <n_procs>     # appends to results/<experiment>.jsonl, resumable
python analysis.py                         # all figures -> paper/figs, tables -> paper/tables, numbers -> results/summary.json
python compute_stats.py                    # number of runs / summed per-run wall-clock
python check_refs.py                       # sanity-check that cited arXiv IDs exist (needs internet)
cd ../paper && python make_checklist.py && latexmk -pdf main.tex
```

## Other files
* `PREREG.md`: registered hypotheses/predictions (written before the confirmatory sweeps; addendum for P8).

* `logs/`: stdout of every sweep.

## Honest notes
* Post-hoc additions: e8, e9, e10, e11, e12 (marked in the paper). P1-P7 were registered before e1-e7 ran.
* Aborted exploratory pilots are in `results/pilot*.jsonl` (partial; not used).
* Some transformer configs were queued twice after a restart; `analysis_lib.load` keeps the first result per key (duplicates are bitwise-identical in outcome).
* Restricted-content statement: no restricted paper/mirror/discussion was searched for, accessed or read; none encountered.
* Literature: only the arXiv abstract pages of the starter-list papers were fetched (to verify existence); their contents are described from the starter list and prior knowledge.

\section{Problem Setting and Reliability Protocol}
\label{sec:method}

\subsection{Target, estimator and budget}
Let $f:\R^d\to\R$ be a trained classifier's output (log-odds or probability; one choice is primary and the other is a sensitivity analysis), $x$ an instance and $D_b$ a background set of $m$ training rows. We use the interventional value function $v_x(S)=\mathbb{E}_{Z\sim D_b}[f(x_S,Z_{\bar S})]$, i.e.\ the ``true to the model'' reading of \citet{chen2020true}, and write $\phivec^\star(x)\in\R^d$ for its Shapley values. The players of the game are the \emph{original attributes} of the data (not one-hot columns): for non-linear models a group value is not the sum of one-hot values, and one-hot columns under interventional expectation create impossible encodings. A stochastic explainer $\mathcal{E}_B$ with seed $s$ returns $\hphi_s(x)$, an estimate of $\phivec^\star(x)$ that uses a budget of $B$ model evaluations (for Kernel SHAP, number of sampled coalitions $\times\, m$). The \emph{single-run practice} we study is: draw one seed, explain, and report $\hphi_s(x)$ as the attribution of the prediction. All randomness in $\hphi_s$ for fixed $(f,x,D_b)$ comes from $s$.

\subsection{Four notions of reliability}
``Reliable'' is not one number. For an instance $x$ and $R$ independent runs $\hphi_1,\dots,\hphi_R$ at the same budget, we separate:
\begin{description}
\item[N1 Repeatability.] Do two independent runs agree? We report, over all run pairs, Spearman and Kendall correlation of the rankings by $|\hat\phi_j|$, top-$k$ Jaccard overlap ($k\in\{1,3,5\}$), rank-biased overlap \citep{webber2010rbo}, sign agreement of the top-$k$ features, and the normalised distance $\|\hphi_a-\hphi_b\|_2/\|\phivec^\star\|_2$. Top-$k$ set stability over the $R$ runs is summarised with the chance-corrected index of \citet{nogueira2018stability}. A null reference is a random permutation of the features of the same attribution vector.
\item[N2 Accuracy.] Is one run close to the quantity it estimates? Relative $\ell_2$ error $\|\hphi_s-\phivec^\star\|_2/\|\phivec^\star\|_2$, maximum absolute error, and top-$k$ hit rate against $\phivec^\star$, which is exact where an exact algorithm for the same background exists and a converged high-budget reference with its own error bar otherwise.
\item[N3 Resolvability.] Is the noise small relative to the differences a reader would interpret? For adjacent features $(j),(j{+}1)$ in the reference ranking by $|\phi^\star|$, the gap-to-noise ratio is $\big(|\phi^\star_{(j)}|-|\phi^\star_{(j+1)}|\big)\big/\mathrm{SD}_s\big(|\hat\phi_{s,(j)}|-|\hat\phi_{s,(j+1)}|\big)$, together with the probability that a single run reproduces the reference order of the pair. The threshold $t{=}2$ is a convention; for Gaussian noise on the gap it corresponds to a pair-order error rate of about $2.3\%$. Gaps among small attributions are small in any attribution vector, so the fraction of resolved pairs is partly a property of the vector's spacing, and the order-reproduction probability is the more direct quantity.
\item[N4 Relative size of the noise.] Is explainer noise material next to other variation a deployed explanation already has? We compare the explainer-seed variance of $\hat\phi_j$ with (a) the variance from redrawing the background sample, (b) the variance across refits of the model with different seeds at comparable accuracy \citep{marx2020predictive}, as a decomposition into variance components. Disagreement between different explainers \citep{krishna2024disagreement} is a further reference scale that we do not evaluate.
\end{description}
Each verdict is a claim of the form ``at budget $B$, for this dataset and model class, the single-run metric is $\mu$ (95\% interval), and a fraction $q$ of instances meets threshold $\tau$''; thresholds are always swept rather than fixed.

\paragraph{Where a single run is trivially exact, and the shap default.}
Kernel SHAP enumerates all $2^d-2$ coalitions once the number of samples reaches that number; for $d\le 10$ the library default is therefore a deterministic computation and says nothing about sampling noise. The stochastic regime is $d$ large relative to the budget, so our core datasets have $d\ge16$ and low-dimensional data serve as a deterministic-regime control. Separately, \texttt{shap} 0.51.0 applies $\ell_1$ feature selection (\texttt{l1\_reg='num\_features(10)'}) unconditionally in \texttt{KernelExplainer}; this is a deterministic bias with exact zeros that disturbs rank metrics at any budget when $d>10$. We therefore report an $\ell_1$-off arm as primary for N1--N3 and the library default arm separately at the default budget.

\paragraph{Decision rule.}
Specified in the study plan before the main runs (we cannot ship its time stamps in an anonymous submission, so read it as a convention) and applied per cell (dataset $\times$ model $\times$ budget): a single run is called \emph{reliable for top-feature identification} if the lower 95\% bound of the mean top-3 hit rate against the target is $\ge0.9$, the median relative $\ell_2$ error is $\le0.1$ and the lower bound of the mean top-3 sign agreement is $\ge0.95$; \emph{unreliable} if the upper bound of the top-3 hit rate is $<0.7$ or the upper bound of the top-1 Jaccard agreement between runs is $<0.5$; \emph{conditional} otherwise. These thresholds are conventions, and the rule is not powerful: when the top few features dominate, hit rates sit at their ceiling and most cells pass. We therefore report how the verdicts change under stricter thresholds (Appendix~\ref{app:sens}); stricter notions (top-5 sets, the top-3 set in the target's order, shares of instances below Jaccard levels) are in Appendix~\ref{app:strata}, and we treat the rule as a summary, not as a test.

\subsection{Statistical treatment}
The unit of inference is the instance. Repeats within an instance are not independent draws of instances, so all intervals are from a nested bootstrap that resamples instances and then runs within instance; pairwise statistics over the $R(R-1)/2$ pairs are used as point estimates only. Datasets are reported separately (there are few). Contrasts between models, explainers and budgets are paired over the same instances, reported with effect sizes and bootstrap intervals, with the planned contrasts listed in advance.

# Historical timing and memory calibration

The pilot*, pilot_extension, pilot_memory and pilot_imbalance outputs precede the
count-before-division boundary correction. They are retained as the actual input
to the measured feasibility budget, not corrected study accuracy evidence. They
must not be pooled with production or interpreted as independent graph-population
samples. Pilot IDs can overlap across calibration panels. Corrected main-study
accuracy is exclusively production_core/noise/imbalance and their audited summary/
diagnostics outputs. No claim that current simulator bytes reproduce historical
pilot Parquet hashes is made; v1 source/provenance is preserved separately.

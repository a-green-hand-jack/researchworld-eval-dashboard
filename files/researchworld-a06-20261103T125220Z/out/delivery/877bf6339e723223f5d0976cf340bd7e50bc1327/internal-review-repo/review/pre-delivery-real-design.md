## Supported method logic and independent checks

The real design makes an important distinction between (a) a noisy disjoint audit of the selected system on the remaining pinned benchmark and (b) a fully known empirical-cache population used for iid calibration. Neither is described as known accuracy over all future natural-language questions. Conditional selection repetitions rerun search on cached rows; they are not new model-generation experiments. The primary full-search selection uses search labels and its own tie seed. Gold labels/rationales are excluded from prompt inputs by the renderer. These are implementation/design checks, not proof of the eventual run's exposure history.

For the primary finite target, a uniform search sample S supports simultaneous hypergeometric intervals for each full-benchmark success total. Subtracting the observed search successes and dividing by the remaining population size transforms the simultaneous event into coverage of each candidate's actual complement accuracy. Selection within the protected bank preserves that event. This is coverage over search sampling, not conditional coverage given every realized S. A fresh uniform audit from that complement has exact hypergeometric uncertainty conditional on S and the frozen winner. The paired audit contrast uses disjoint win/loss counts and a conservative union of exact marginal category intervals. Repeated candidate selection must not use audit outcomes.

`review/check_finite_target.py` / `review/finite-target-check.json` record independent software/theory diagnostics. They use artificial binary fixtures only; none is an LLM result. The script independently exhausts the accepted integer-population tail sets and agrees with production interval binary search in 192 cases. It also enumerates all 3003 search subsets of a 14-row, 3-candidate fixture, averaging empirical-max ties uniformly, and checks the simultaneous-to-remaining-target transformation at two error levels. At nominal .95 the selected-target coverage is .99534 and the minimum fresh-audit conditional coverage in this fixture is .97143. These are diagnostic properties of the fixture, not empirical reliability estimates for the planned LLM study and not a substitute for its required analyses.

The current code labels ordinary binomial primary intervals as inexact for the finite without-replacement target, provides exact finite-population alternatives, and labels audit sign disagreement/squared difference as descriptive proxies rather than population false decisions/MSE. Cache calibration resamples whole paired rows with replacement, retains its exact empirical target and reruns selection. Bootstrap output explicitly calls itself approximate question sensitivity without a population coverage claim. The scope/precision claims remain planning estimates until the actual run is completed.

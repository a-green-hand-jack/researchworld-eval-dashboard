# Frozen experimental design (pilot is not confirmatory)

See `configs/frozen.json` for the complete 19-cell matrix; the planning owner's `plan/STUDY_PLAN.md` defines the claim-level scope. No external data or prohibited-source search is used. All data are synthesized by `src/compbench/data.py` from explicit seeded NumPy distributions. Core sample sizes: 2,000 proper-training observations (1,500 location fitting, 500 scale fitting), 499 calibration, 2,000 test, 100 independent outer trials. The minority prevalence is 0.10. Trial methods share every partition. Trial seed is cell seed plus repeat; `SeedSequence(seed).spawn(4)` gives separate train/calibration/test/integration stream positions. Cell seeds and all dimensions are in the manifest. Different factors use common seed to pair sensitivity arms; whole data arrays need not be nested when sample sizes change.

For each observation, X=(u,v,g), u,v iid Uniform[-1,1], g~Bernoulli(p), independent. Features phi=(1,u,v,sin(pi*u),uv,g). Component j=0,...,K-1 has fixed coefficient vector (.4 cos(j), .7 cos(2pi j/K), .5 sin(2pi j/K), .3 cos(4pi j/K), .2 sin(4pi j/K), .2 cos(2pi j/K)). Base mu=softmax(phi coefficients). No coefficient is selected from outcomes.

Five mechanisms, all run at K=3 and K=10:

- Interior: ILR(Y)=ILR(mu)+.45 Z, Z~N(0,I_(K-1)).
- Heterogeneous: same, with noise scale .25 for g=0 and 1.25 for g=1. Group is observable and fixed before calibration.
- Boundary: add 3 to component-0 logit; logistic-normal noise scale .8.
- Dirichlet contrast: same shifted logits, mu_D=.8 mu+.2/K; independent component Gamma(15 mu_Dj,1) normalized to sum 1. This is positive Dirichlet(15 mu_D) noise and contrasts log-ratio Gaussian tails with a boundary-skewed shape.
- Zeros: unshifted logistic-normal noise scale .8, then independently with probability .25 select a component uniformly, set it exactly to zero and renormalize. These are actual face-valued observations, not numerical rounding. All target vectors remain in the original closed simplex.

Location predictor: ridge regression of ILR(Y) on phi with penalty 1e-3 and no intercept penalty, fitted to the first 1,500 proper-training observations. In the zero arm only, regression target uses T_.001(Y). Inverse ILR produces the common positive center for all scores. The training model therefore has deliberately stated parametric misspecification for non-logistic-normal mechanisms; validity does not require a correctly specified model. Scaled ILR uses groupwise RMS log-ratio residuals on the remaining 500 proper-training observations; a missing group uses overall RMS, and scales are floored at 1e-8. These are fitted group scales, not known DGP oracle scales.

Methods: scalar TV (half-L1)/L2/Hellinger/ILR joint scores; coordinatewise naive and Bonferroni intervals in every cell. Heterogeneous cells additionally include training-only scaled ILR and group/Mondrian ILR. Unsmooothed ILR is recorded inapplicable for the entire true-zero arm; the operative method is explicitly named ILR-smoothed and scores every candidate and center using T_epsilon. Primary epsilon=.001; sensitivity epsilon=1e-6 and .01, keeping the fitted location unchanged. Membership and all coverage denominators use original Y, including zero faces.

Selected sensitivities: ncal=99 and 1999 and alpha=.05 for interior/heterogeneous K=3; zero-transform epsilon sensitivity K=3. Stress: heterogeneous K=3 test prevalence changes from .1 to .4, retaining identical conditional Y|X. This is covariate shift (G is in X), not a conditional response shift; ordinary unweighted calibration has no guarantee there. There is no full factorial and no real-data arm.

Joint test coverage and predefined majority/minority coverage are computed for every cell. Zero-face versus positive coverage is additional descriptive response-defined slicing, with no conditional coverage theorem. Coordinate methods additionally store componentwise coverage. Infinite thresholds/full-domain rates, group calibration counts, fitted coefficients/scales, point RMSE and input hashes are retained. Empty regions cannot arise with these nonnegative-radius center-containing sets; undefined unsmoothed scores are applicability failures, never counted as false noncoverage.

Common efficiency measure is normalized original-simplex Hausdorff volume. K=3 only is primary; K=10 coverage and applicability retain their meaning without a volume ranking. For each trial estimate volume for the first 32 test centers in each X group; average within group, then weight by observed test-group prevalence. Final candidate (after the pilot accuracy check): scrambled Sobol transformed-region integration uses 2^14 points per region. Same Sobol seeds across methods induce numerical pairing, but integration maps differ. `volume.py` uses ball, spherical-cap or barycentric-box changes of variables, so narrow/near-boundary regions are not assessed by blind uniform-simplex zero-hit counts. Infinite regions have exact volume 1. Integration replicate and reference/quadrature errors are checked by `scripts/diagnostics.py`; the final candidate power/centers are 14 and 32, accepted after independent final feasibility GO.

Statistical unit is the independently regenerated/refitted outer trial. Report mean and standard deviation of per-trial coverage/area, Student-t 95% intervals for means plus percentile trial-bootstrap sensitivity intervals (5,000 draws, seed 90210), and paired trial mean-difference intervals for declared comparisons. These quantify outer resampling uncertainty and include finite test-sample noise; they are not pooled binomial intervals on 200,000 falsely independent predictions. Main comparisons are descriptive with effect sizes, not a large family of uncorrected significance tests. Define undercoverage frequency using true/empirical conditional coverage only in the separate continuous-score diagnostic; do not declare realized trial coverage below .9 a theorem violation.

## Frozen interpretation and precision policy (before confirmatory outcomes)

Use a minimum practically interpreted absolute difference of .01 for coverage and .005 for normalized simplex area. Differences below these margins are reported numerically but do not establish a useful method ranking. A claimed area advantage also requires uncertainty on the paired contrast and an independent higher-resolution integration check small enough to resolve it; a difference near .001 is numerically unresolved at the main resolution. For minority-coverage mean CI halfwidth >.02, mark that estimate imprecise for fine ranking; do not treat a wide interval as equivalence. No method is declared universally best, and no additional mechanism is tuned to force H2's ordering reversal. The final seed offset keeps every confirmatory observation independent of every pilot observation.

Area-location uncertainty is estimated by recording the 32 individual areas per group per trial. The outer-trial interval includes newly sampled location-subset variability, model/calibration variability and finite integration variability. It does not by itself bound common numerical bias; independent 4-scramble resolution/reference checks and a predeclared high-resolution sensitivity assess that separately. Sobol scramble keys include trial seed, group and center index, paired across corresponding methods only.

### Executable numerical allowance and missing-group policy

For an audited matched center and method pair A/B, calculate four independent high-resolution paired differences D_s (same scramble key across corresponding methods). Let D_main be the main-resolution difference for the identical center. The empirical allowance is max(.001, |mean(D_s)-D_main| + t_(.975,3) sd(D_s)/sqrt(4)). For each cell/group/pair take the maximum over the prespecified audited centers and repetitions; for the population contrast take the maximum of the two group allowances, which covers any convex combination under this empirical rule. Enlarge the independent-trial statistical interval on both sides by that allowance. Any enlarged interval containing zero is unresolved; useful area rankings also require abs(effect)>=.005. This is deliberately conservative empirical numerical sensitivity, not a uniform theorem or a calibrated simultaneous numerical confidence interval. Missing paired audits leave the ranking unresolved. `scripts/numerical_allowance.py` executes the rule and retains each matched-center contrast.

If a test X group is absent, its empirical prevalence is zero and its unavailable area contributes exactly zero. `aggregate_group_volumes` weights only observed nonempty groups; a positive-weight group with missing area propagates NaN, and an empty entire test sample gives an undefined mean. Direct branch tests include a real trial with no minority tests. Per-group n/area-center counts and observed test weights are retained.

For measured barycentric cases, preserve the original Y, X/group, center, fitted test scale, actual score threshold, method and source hashes for the first test observation of confirmatory trial 0 in each core K=3 scenario, common across methods. The rule is fixed before inspecting confirmatory shapes. These cases illustrate measured geometry; no case selection optimizes an efficiency ranking.

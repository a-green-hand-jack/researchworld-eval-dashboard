\section{Reproduction and resource record}
\label{app:reproduction}
The accompanying repository supplies all numerical and presentation code, a synthetic generator instead of a downloaded dataset, raw task-run outputs, summary tables, manifests, source hashes, exact commands and a figure/table inventory. The analysis environment records Python 3.11.2, NumPy 2.4.6, SciPy 1.17.1 and pandas 3.0.6. The rendering runtime is recorded with its input hashes. The official NeurIPS 2026 style is unmodified; the root PDF is rebuilt from the delivered LaTeX. Inline estimates are extracted by a paper-owned script, with exact file hashes, selection keys and columns in the accompanying claim-provenance record.

Runs were CPU-only in resource containers with ceilings of two CPUs and 4 GiB memory, on a shared host; the documented commands set BLAS/OpenMP to one thread. Core running wall/CPU times were 116.110/124.165104 seconds and the oracle/rank/boundary extension used 43.878/45.080784 seconds, excluding startup. The TV/KL supplement used 45.631351 CPU seconds and resource-reported running time 44.498 seconds; its per-cell wall-time sum is 59.927 seconds, a separately recorded timing measure. The implementation pilot took approximately three seconds; it and the separate score-implementation pilot are excluded from the empirical claims. No resource run failed and no final repetition was excluded. Peak memory was not measured. Exact per-cell times are retained, rather than treating these timings as hardware-independent promises. Reproduction requires a few minutes plus summarization on a comparable host, with no GPU or paid prediction API.

No external dataset or pretrained model was used. Existing dependency creators, versions and installed terms are listed in the accompanying asset inventory. Official venue-source hashes and their acquisition record are retained. No blanket license for all archived conference assets or general license grant for newly generated code/data is invented. Sources not obtained as originals are not represented as consulted originals. The supplied source-access logs report no prohibited-study encounter; the bounded permitted-source search is not an exhaustive novelty claim.

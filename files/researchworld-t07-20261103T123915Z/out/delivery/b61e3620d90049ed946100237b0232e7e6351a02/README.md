# Cross-fitting and learned regression for few-item benchmark prediction

This is the research delivery root. The completed study evaluates source-assisted prediction of a held-out model's unweighted binary-matrix mean and within-benchmark ranking. It covers all thirteen supplied matrices, three main budgets, eighteen main methods, and the planned source-size/proxy-family conditions. The candidate improves macro MAE over random means but trails score ridge at all three budgets; detailed heterogeneous outcomes and conditional uncertainty are retained.

The complete manuscript, all empirical displays and official checklist are integrated. The main paper is eight content pages; references, technical/evidence appendices and checklist follow in the same PDF. The source-replay timing supplement and its thread-sensitivity limitation are included. Independent final-version approval remains required. Development pilots are not final results.

Build from this root with `bash build/build_paper.sh` after installing TeX Live with latexmk/BibTeX, pdflatex, poppler tools and Python 3.11+. `make paper` is an optional equivalent when GNU Make is installed. It uses `venue/template/neurips_2026.sty`, writes intermediates to `build/latex/`, and refreshes root `paper.pdf` plus text/font diagnostics. The Courier monospace preamble avoids this environment's Type 3 EC font without modifying the official style. Build checks cover Letter size, font embedding, resolved references, official checklist wording/template hashes, declared display outputs and local links; scientific/visual inspection is recorded in [build/inspection.md](build/inspection.md). The first clean build took 4.52 seconds with pdfTeX 1.40.24 / TeX Live 2022; this is document build time.

For the experiments, follow [analysis/README.md](analysis/README.md) from `cd analysis`: install its exact requirements, source `scripts/env.sh`, acquire/audit inputs, then run `scripts/run_study.py develop`, `scripts/run_study.py predict`, and **`diagnostics/score_canonical.py`**. Retain the committed configuration/gate records and do not regenerate target membership. A fresh fit/tune run is budgeted at roughly 30–60 minutes on comparable hardware as an estimate; actual cached prediction/scoring and fit-component measurements are documented separately. The measured source replay used24.34 CPU minutes; combined with separately measured prediction/canonical-scoring phases, the workload proxy is29.41 CPU minutes, excluding setup/pilots/diagnostics/rendering. One source-development anchor loss grid is thread-sensitive with unchanged chosen alpha; original effective library pools were not measured. All78 final anchor selections/mean predictions reproduce exactly. See [compute accounting](analysis/notes/compute_accounting.md) and [source reproducibility](analysis/notes/source_reproducibility.md). Host contention can change elapsed times. No new LLM calls or paid APIs are required; raw matrices are fetched from the authorized public fixed revision and are not bundled.

The canonical scorer applies the disclosed post-scoring twelve-decimal rank/tie convention. It preserves raw predictions for all score errors; the archived original ranks must not feed final claims. Both the dated repair and nonzero 10/12/14-decimal sensitivity are included, as is the retrospective matched-alpha AIPW diagnostic. Rendering consumes saved results without refitting. Inspect [the presentation manifest](presentation/manifest.json) for figure/table commands and exact inputs.

For bounded integrated-document checks, run `python3 build/check_integration.py` from the root (PyMuPDF1.28.2 and Pillow13.0.0 were used); `--render` also regenerates page/contact-sheet inspection images. It verifies snapshot/evidence hashes, exactly-once display labels, PDF destinations and physical page bounds, and writes [the display/page index](build/display-index.json) and [integration audit](build/integration-audit.json). These checks do not replace visual inspection or scientific review.
